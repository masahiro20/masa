# 土地調査アシスタント（愛知・岐阜・三重）

住所を入れる（または現地で「現在地で調査」を押す）だけで、注文住宅の設計前に営業が確認すべき
**法令制限・ハザード・ライフライン**を一覧にし、AI が「プランへの影響」「要確認事項」をまとめるツールです。
スマホ・PC のブラウザで使えます（ホーム画面に追加も可）。

## できること

| 項目 | 取得方法 | 備考 |
|---|---|---|
| 用途地域・建蔽率・容積率 | 不動産情報ライブラリ API（自動） | APIキー必要 |
| 高さ制限（絶対高さ・斜線・日影） | 用途地域・容積率から自動判定 | 高度地区は近隣の地価公示地点から参考表示＋要確認 |
| 壁面後退 | 用途地域・地区計画から自動判定 | 地区計画区域内なら警告 |
| 前面道路の種別・幅員 | 手入力（指定道路図のリンクを表示） | 入力すると容積率の道路幅員制限・セットバック・概算ボリュームを自動計算 |
| 防火・準防火地域 | 不動産情報ライブラリ API（自動） | 指定なしの場合は法22条区域の確認を促す |
| 上水・下水・ガス | 手入力＋近隣の地価公示地点の供給状況を参考表示 | 台帳・配管図の確認先リンクを表示 |
| ハザード | 重ねるハザードマップ（洪水・高潮・津波・土砂）＋不動産情報ライブラリ（災害危険区域・急傾斜地・盛土・液状化） | APIキーなしでも洪水・高潮・津波・土砂は取得 |
| AI による見解 | Claude API | 総合評価（A/B/C）・プランへの影響・費用に効く項目・要確認事項・お客様への説明ポイント |
| その他（提案で追加） | 自動 | 市街化調整区域の警告、都市計画道路（法53条）、地区計画、立地適正化計画、液状化、標高、小・中学校区、近隣の地価公示 |

AI には計算させず、数値の判定（容積率の道路幅員制限、セットバック量など）は `public/shared/rules.js` で機械的に行います。
AI はその結果を読んで解釈・注意点を書くだけなので、データにない数値をでっち上げにくい構成です。

## セットアップ（自分の Windows PC で使う）

ウェブ公開はせず、PC の中だけで動かします（ブラウザで `http://localhost:3000` を開いて使います）。

1. **Node.js をインストール**：[nodejs.org](https://nodejs.org/ja) から LTS 版（22 以上）
2. **このフォルダを PC に置く**：GitHub の `claude/upbeat-edison-av0hg0` ブランチを「Code → Download ZIP」で取得して展開し、`tochi-chosa` フォルダを好きな場所へ
3. **法令制限確認書のテンプレートを置く**：`tochi-chosa/templates/法令制限確認書.xlsx`
   （会社の書式なので GitHub には入れていません）
4. **`起動.bat` をダブルクリック**
   - 初回だけ部品のインストールと `.env`（APIキーの設定ファイル）の作成が行われ、メモ帳が開きます
   - `REINFOLIB_API_KEY=` に不動産情報ライブラリのキーを貼り付けて保存
   - AI見解も画面から使う場合は `ANTHROPIC_API_KEY=` に Claude の APIキー（任意）
5. ブラウザが開いたら住所を入れて調査。次回からは `起動.bat` をダブルクリックするだけです

### いつでも使えるようにする（おすすめ）

`常に起動しておく.bat` を一度だけダブルクリックすると、Windows の起動時に裏で自動的に立ち上がるようになります。
以後はブラウザで **http://localhost:3000** を開くだけ（ブックマーク推奨）。やめるときは `常時起動をやめる.bat`。
動作ログは `server.log` に出ます。

## 法令制限確認書（Excel）の自動入力

画面下の **「法令制限確認書（Excel）を出力」** を押すと、テンプレートに次の欄を入れた Excel をダウンロードします。
お客様情報・仕様欄（断熱・サッシ・設備など）は空欄のままなので、営業が入力してください。

| 欄 | 入る内容 |
|---|---|
| 建築地住所・該当地（地番）・〒 | 調査した住所、手入力の地番・郵便番号 |
| 都市計画区域 | 内／外、市街化区域／市街化調整区域／未線引区域 にチェック |
| 用途地域・建蔽率・容積率 | 自動取得の値（敷地が2つにまたがる場合は右側にも） |
| 防火地域 | 防火地域／準防火地域 にチェック（指定なしは「22条区域 要確認」として備考へ） |
| 高度地区・壁面後退・建築協定 | 判定できるものだけチェック。不明なものは備考の「要確認」に列挙 |
| その他地区 | 地区計画、居住誘導区域、都市計画道路、災害区域、低層住居の絶対高さなど |
| 接道（2本まで） | 42条の項・号、方向、幅員、国道／県道／市道 のチェック |
| 上下水道・ガス | 引込有無、下水道／浄化槽、都市ガス／LP にチェック。本管口径は備考へ |
| 備考 | 実効容積率、セットバック、ハザード、要確認事項の一覧 |
| 申請スケジュール「防火指定」 | 防火／準防火地域 |

さらに **「調査結果・AI見解」シート** を追加し、判定結果・高さ制限・ハザード・近隣の地価公示・AI見解をまとめます。

コマンドで作ることもできます（Claude に住所を伝えて作ってもらう場合もこの方法です）:

```bash
npm run kakuninsho -- "愛知県○○市○○町1-2" --manual 手入力.json --insight 見解.md
# → output/法令制限確認書_住所_日付.xlsx
```

## ウェブで公開したくなったら（任意）

Vercel 等に `tochi-chosa` フォルダをデプロイし、環境変数 `REINFOLIB_API_KEY`・`ANTHROPIC_API_KEY`・`APP_PASSCODE` を設定します。
その場合はテンプレートの置き場所（`KAKUNINSHO_TEMPLATE`）も別途用意してください。

## 使い方のコツ

- 住所検索は街区（○丁目○番）単位の位置になることがあります。**地図をタップしてピンを敷地に合わせ、「この地点で再調査」**を押してください。
- 道路種別・幅員・上下水・ガスは、役所や事業者で確認した内容を入力欄に入れると、判定と AI 見解に反映されます（入力内容はその端末に保存）。
- 「印刷・PDF保存」で調査結果を1枚にまとめて設計担当に渡せます。
- 「履歴」から過去の調査（入力内容・AI見解を含む）を呼び出せます。履歴はその端末のブラウザにだけ保存されます。

## 構成

```
tochi-chosa/
├── api/            サーバー側の処理（Vercel の関数、server.js からも使用）
│   ├── geocode.js  住所 → 座標（国土地理院）
│   ├── survey.js   地点の法令・ハザード情報をまとめて取得
│   └── insight.js  Claude で見解を生成（ストリーミング）
├── lib/            データ取得（不動産情報ライブラリ・ハザードタイル・地理院・確認先リンク）
├── public/         画面（HTML/CSS/JS）。shared/rules.js は法規の判定ロジック
├── templates/      法令制限確認書のテンプレート置き場（Git 管理外）
├── output/         コマンドで作った確認書の出力先（Git 管理外）
├── scripts/        コマンドライン用（kakuninsho.js）
├── 起動.bat        Windows で起動（その都度）
├── 常に起動しておく.bat / 常時起動をやめる.bat   Windows 起動時に裏で自動起動
├── test/           テスト
└── server.js       ローカル用サーバー
```

## 注意・今後の拡張

- 結果は公開データによる**一次調査**です。重要事項説明・設計の根拠にする場合は必ず原本（市町村・事業者）で確認してください。
- 都市計画 GIS データは自治体によって未整備・更新遅れがあります。「データなし」は「指定なし」とは限りません。
- 今後の拡張候補
  - 営業エリアの主要市町村（名古屋市・岐阜市・四日市市など）の指定道路図・下水道台帳の Web GIS からの自動取得
  - 調査結果の社内共有（データベース化して、近隣の過去調査を表示）
  - 高度地区・日影規制の自治体別テーブル化
