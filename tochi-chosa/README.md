# 土地調査アシスタント（愛知・岐阜・三重）

住所を入れる（または現地で「現在地で調査」を押す）だけで、注文住宅の設計前に営業が確認すべき
**法令制限・ハザード・ライフライン**を一覧にし、AI が「プランへの影響」「要確認事項」をまとめるツールです。
スマホ・PC のブラウザで使えます（ホーム画面に追加も可）。

## できること

| 項目 | 取得方法 | 備考 |
|---|---|---|
| 用途地域・建蔽率・容積率 | 不動産情報ライブラリ API（自動） | APIキー必要 |
| 高さ制限（絶対高さ・斜線・日影） | 用途地域・容積率から自動判定 | 高度地区は近隣の地価公示地点から参考表示＋要確認 |
| 壁面後退 | 用途地域・地区計画から自動判定 | 地区計画区域内なら警告 |
| 前面道路の種別・幅員 | 手入力（指定道路図のリンクを表示） | 入力すると容積率の道路幅員制限・セットバック・概算ボリュームを自動計算 |
| 防火・準防火地域 | 不動産情報ライブラリ API（自動） | 指定なしの場合は法22条区域の確認を促す |
| 上水・下水・ガス | 手入力＋近隣の地価公示地点の供給状況を参考表示 | 台帳・配管図の確認先リンクを表示 |
| ハザード | 重ねるハザードマップ（洪水・高潮・津波・土砂）＋不動産情報ライブラリ（災害危険区域・急傾斜地・盛土・液状化） | APIキーなしでも洪水・高潮・津波・土砂は取得 |
| AI による見解 | Claude API | 総合評価（A/B/C）・プランへの影響・費用に効く項目・要確認事項・お客様への説明ポイント |
| その他（提案で追加） | 自動 | 市街化調整区域の警告、都市計画道路（法53条）、地区計画、立地適正化計画、液状化、標高、小・中学校区、近隣の地価公示 |

AI には計算させず、数値の判定（容積率の道路幅員制限、セットバック量など）は `public/shared/rules.js` で機械的に行います。
AI はその結果を読んで解釈・注意点を書くだけなので、データにない数値をでっち上げにくい構成です。

## セットアップ

### 1. APIキーを用意する

1. **不動産情報ライブラリ API キー**（無料・審査あり、数日かかります）
   [API利用申請](https://www.reinfolib.mlit.go.jp/api/request/) から申請します。キーがなくてもハザード・手入力・AI見解は動きますが、用途地域などは取得されません。
2. **Claude API キー**（従量課金）
   [Claude Console](https://console.anthropic.com/) で発行します。1回の見解生成でおおむね数十円程度です（モデルは環境変数 `ANTHROPIC_MODEL` で変更できます）。

### 2. 公開する（おすすめ：Vercel 無料プラン）

1. [Vercel](https://vercel.com/) に GitHub アカウントでログインし、「Add New → Project」でこのリポジトリを選ぶ
2. **Root Directory** に `tochi-chosa` を指定
3. **Environment Variables** に次を設定
   - `REINFOLIB_API_KEY`：不動産情報ライブラリのキー
   - `ANTHROPIC_API_KEY`：Claude のキー
   - `APP_PASSCODE`：社内で共有する合言葉（URL を知っている人が勝手に使ってAPI料金がかかるのを防ぎます）
4. Deploy。発行された URL をスマホで開き、共有メニューから「ホーム画面に追加」

### 3. 手元の PC で動かす場合

```bash
cd tochi-chosa
cp .env.example .env   # キーを記入
npm install
npm run dev            # http://localhost:3000
npm test               # 判定ロジックのテスト
```

## 使い方のコツ

- 住所検索は街区（○丁目○番）単位の位置になることがあります。**地図をタップしてピンを敷地に合わせ、「この地点で再調査」**を押してください。
- 道路種別・幅員・上下水・ガスは、役所や事業者で確認した内容を入力欄に入れると、判定と AI 見解に反映されます（入力内容はその端末に保存）。
- 「印刷・PDF保存」で調査結果を1枚にまとめて設計担当に渡せます。
- 「履歴」から過去の調査（入力内容・AI見解を含む）を呼び出せます。履歴はその端末のブラウザにだけ保存されます。

## 構成

```
tochi-chosa/
├── api/            サーバー側の処理（Vercel の関数、server.js からも使用）
│   ├── geocode.js  住所 → 座標（国土地理院）
│   ├── survey.js   地点の法令・ハザード情報をまとめて取得
│   └── insight.js  Claude で見解を生成（ストリーミング）
├── lib/            データ取得（不動産情報ライブラリ・ハザードタイル・地理院・確認先リンク）
├── public/         画面（HTML/CSS/JS）。shared/rules.js は法規の判定ロジック
├── test/           テスト
└── server.js       ローカル用サーバー
```

## 注意・今後の拡張

- 結果は公開データによる**一次調査**です。重要事項説明・設計の根拠にする場合は必ず原本（市町村・事業者）で確認してください。
- 都市計画 GIS データは自治体によって未整備・更新遅れがあります。「データなし」は「指定なし」とは限りません。
- 今後の拡張候補
  - 営業エリアの主要市町村（名古屋市・岐阜市・四日市市など）の指定道路図・下水道台帳の Web GIS からの自動取得
  - 調査結果の社内共有（データベース化して、近隣の過去調査を表示）
  - 高度地区・日影規制の自治体別テーブル化
