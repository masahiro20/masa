# ホームランディック請求書（お客様向け・Excel）

お客様に印刷して渡す請求書。**ひな形は1バイトも変えず、中身だけ差し替える**（理由と決まりは `../CLAUDE.md` の「3.」）。

## 道具

| ファイル | 役目 |
| --- | --- |
| `xls_patch.py` | ひな形(.xls)の文字・数値・数式の計算済み値だけを書き換える。図形・罫線・印刷設定は触らない |
| `verify_base.py` | ひな形と出来上がりをレコード単位で突き合わせ、変わったのが意図したセルだけか確認する |
| `render_preview.py` | 印刷範囲・A4・倍率・余白・図形を反映した確認用プレビュー(PDF/PNG)。ひな形と並べて見比べる |

実行は `python3 -I <script> ...`（`olefile` `xlrd` `reportlab` `pymupdf` が必要）。

## 設定JSON（作業用の場所に作る。コミットしない）

```json
{
  "src": "ひな形.xls",
  "dst": "出来上がり.xls",
  "strings": {"6,7": "○○　△△ 様,　□□", "14,18": "金0,000,000円也"},
  "numbers": {"24,6": 46305, "28,40": 12000000},
  "formulas": {"5,31": 46305, "48,40": 0, "52,40": 0},
  "blank_textboxes": ["前のお客様にだけ当てはまる注記の一部"],
  "forbid": ["前のお客様の名前", "前の住所"]
}
```

- キーは `"行,列"`（Excelの行・列番号、1始まり）。
- `numbers` は数値セル（整数）。日付はExcelのシリアル値（2026/10/10 = 46305）。
- `formulas` は数式セルの「計算済みの値」。数式は変えない。合計・小計・日付の連動セルは必ず合わせる。
- `forbid` に前のお客様の文字を入れておくと、残っていれば止まる。

## 配筋工事完了時金等のひな形のセル位置

| 内容 | セル |
| --- | --- |
| 日付（請求日） | R24C6 を入力、R5C31 は R24C6 を参照する数式 |
| 宛名 | R6C7（連名はここに）、R6C21 は「様」 |
| 件名 | R12C18 |
| 合計金額 | R14C18（文字列「金…円也」） |
| 品名行 | R24（工事名）、R26（現場住所）、R28/R30/R32（明細: 品名C11・数量C28・単位C32・金額C40） |
| 小計・合計 | R48C40 / R52C40（数式）、R40C47・R41C47 は枠外の作業用数式 |
| 融資の注記 | 行35〜45の枠（テキストボックス）。お客様ごとに内容が違う |
