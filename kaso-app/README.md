# 家相盤チェッカー

間取り図（PDF・画像）に家相盤を重ねて、鬼門・裏鬼門、張り・欠け、火と水回りの位置を判定するWebアプリです。
図面ファイルはブラウザの中だけで処理し、どこにも送信しません。

## できること

1. 図面を読み込む（PDF・PNG・JPG。PDFはページを選べる）
2. 縮尺を合わせる（任意。2点＋実寸mm）
3. 真北を合わせる（図面の方位記号を2点クリック、または角度入力。磁北・偏角、30°/60°区分と45°区分の切り替え）
4. 建物の外形をなぞる（階ごと。縦横スナップ、点のドラッグ修正、中心の取り方を選択）
5. 設備・部屋を置く（コンロ・シンク・トイレ・浴室・洗面・玄関・階段・吹抜・寝室。クリックで点、ドラッグで範囲）

判定は自動で更新されます。

- 建物の中心（外形の重心／外形を囲む長方形の中心／1階の重心）
- 張り・欠け（一辺の1/3ルール。外周から張りを取り除き、残った本体の凹みを欠けとして判定）
- 火と水回り・玄関の方位、正中線・四隅線・鬼門線へのかかり
- 「直すなら、ここから」の優先順位と、お客様への伝え方の例
- 判定シート（図面＋家相盤＋判定）のPNG・PDF書き出し、テキストコピー

## ファイル

- `src/app.html` … 本体（HTML・CSS・JSを1ファイルにまとめたもの）
- `index.html` … `src/app.html` を `build.sh` で包んだ公開用ファイル
- 外部から読み込むのは pdf.js と jsPDF（cdnjs）、Google Fonts のみ

## 公開のしかた

`index.html` 1枚で動く静的ページです。Vercel・Netlify・GitHub Pages など、静的ファイルを置けるサービスならどこでも公開できます。
`src/app.html` を直したら `./build.sh` を実行して `index.html` を作り直してください。

## 判定基準について

家相は流派によって方位の区切り・中心の取り方・吉凶の考え方が違います。判定は打合せのための参考情報です。
基準はアプリ内の「家相の基礎 → このツールの判定基準」に書いています。
