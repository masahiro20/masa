# ☕ 喫茶店のテーブル注文システム（cafe-order）

番号札のQRコードをお客様のスマホで読み取って席から注文 → オーナーのiPadに届く → 会計は番号札をレジへ、という流れの注文・会計システムです。
スマホを持っていないお客様はスタッフがiPadで受付・注文入力できます。

```
 受付で番号札を渡す ─▶ お客様がQRを読む ─▶ 席から注文 ─▶ iPadに「ピンポン」と届く
                                                          │
 番号札をレジへ ◀─ 「お会計をお願いします」ボタン ◀───────┘
   └▶ 番号を入力 → コーヒーチケット・割引 → まとめて / 割り勘 / 個別会計 → レシート
```

## 画面

| 画面 | URL | 使う人 |
|---|---|---|
| お客様の注文画面 | `/t/番号?k=鍵`（番号札のQR） | お客様のスマホ |
| オーナー画面 | `/admin` | オーナーのiPad（PINでログイン、初期PIN `1234`） |

オーナー画面のタブ：

- **ホール** … 番号札ごとの利用状況。新着注文は赤枠＋「NEW」、呼び出しは🔔。札をタップすると伝票の詳細（提供済にする・取消・サービス・札の移動・合流・追加注文）。
- **注文** … 未提供の品を古い順に並べたキッチン／ドリンク用ボード。品名タップで提供済。10分で黄色、20分で赤。「食後」指定の飲み物は後ろに回ります。
- **会計** … 番号札の番号をテンキーで入力して会計開始。
- **本日の準備** … 朝に開く画面。日替わり・期間限定の中身、売り切れ、残数、受付停止、お知らせをここだけで設定。
- **メニュー** … 商品・カテゴリ・オプションの編集。
- **売上** … 日別の売上・支払い方法別・商品ランキング・時間帯・会計履歴・CSV出力。
- **設定** … 店名、番号札とQR印刷、チケット、割引ボタン、支払い方法、税率、受付ルール、PIN、バックアップ。

## ご要望に対応した機能

### 注文
- 番号札のQRを**同じテーブルの全員がそれぞれのスマホで**読み取って注文できる（同じ伝票にまとまる）。
- 注文はリアルタイムでiPadに届き、通知音（ピンポン）とバナーで知らせる。
- スマホを持っていないお客様は、ホールで空いている札をタップ →「スタッフが注文を入力」。札なしの「カウンター注文」もあり、「確定してすぐ会計」で先払いにも対応。

### 日替わり・週替わり・月替わりメニュー（オーナーの手間を最小に）
- **プレーン / 日替わり** のような選択肢：例）本日のブランチのスコーン。
- **期間限定①②③の枠**：例）バスクチーズケーキ。枠だけ作っておき、中身は黒板に書く運用。
  - 中身を入れなければお客様には「①（黒板をご覧ください）」と表示。
  - 「本日の準備」で中身（例：和栗）を入れれば「期間限定① 和栗」と表示。
  - 使わない枠は「非表示」、なくなった枠は「売切」をワンタップ。
- **連動キー**：スコーン単品とブランチのスコーンのように同じ日替わりを使う枠は、1か所入れれば両方に反映。
- 売り切れ・本日休みは**その営業日だけ**有効で、翌朝は自動で元に戻るので「戻し忘れ」がない。
- 提供時間（モーニング 7:00〜11:00 など）、曜日限定、期間限定（開始日〜終了日）を設定すると自動で表示／非表示。
- 本日の残数を入れると、注文ごとに減って0で自動的に売り切れ（取消で戻る）。

### 会計
- 番号札の番号を入れるだけで会計開始。「お会計希望」の札は一覧の先頭に。
- **コーヒーチケット**：枚数を＋するだけ。対象商品1点につき1枚、上限額（例500円）まで値引き。高いドリンクに使った場合は差額をお支払い。
- **割り勘**
  - 均等割り：人数を選ぶだけ。1円・10円・100円単位、端数は幹事さん（1人目）に。
  - 個別会計：品ごとに誰が払うかをタップ。2人を選んだ品は等分。スマホで名前を入れて注文した人の品は自動で割り当て。
  - 金額指定：「5,000円だけカードで、残りは現金」など。
- 支払い方法を混ぜてOK（現金・カード・QR決済・交通系IC、設定で変更可）。現金はお預かり金額からおつりを計算。
- 割引ボタン（スタンプカード満了・10%OFFなど）を登録しておけばワンタップ。その場で任意の割引も可。
- レシート・領収書（宛名・但し書き）を印刷（iPadのAirPrint対応プリンタ）。インボイス登録番号・税率ごとの内消費税を印字。

## こちらで考えて追加した「喫茶店あるある」への対応

| よくある場面 | 対応 |
|---|---|
| お冷やが欲しい／店員を呼びたい／お会計したい | お客様画面の「呼ぶ」ボタン → iPadに🔔と音で通知（文言は設定で変更可） |
| 飲み物は食後に持ってきてほしい | ドリンクごとに「先に／食事と一緒／食後に」を選べる。キッチンボードに表示 |
| 氷少なめ・取り皿が欲しい | 品ごとの「ご要望」メモ |
| アレルギーが気になる | 商品ごとのアレルギー表示 |
| 混雑して手が回らない | スマホ注文の一時停止（スタッフ入力は可能）。お客様には停止中のメッセージを表示 |
| ラストオーダー | 時刻を過ぎるとスマホ注文を自動で締め切り |
| 通信が不安定で二重送信 | 同じ注文の再送は1回分として扱う |
| 画面を開いたまま会計が済んだ後に注文 | 「お会計は完了しています」と確認してから新規注文 |
| 注文した直後に売り切れた | 送信時に再確認し、カートの該当品に「売り切れ」を表示 |
| 後から連れが来た／席を移った | 伝票の「合流」「札を移動」 |
| 注文の間違い・お詫び | 品の取消（理由つき、在庫も戻る）、「サービス（0円）」 |
| 先にお会計して席で待つ | 会計済でも未提供の品は注文ボードに残り、提供すると消える |
| 持ち帰り | 伝票ごとに店内／持ち帰りを切替。税率8%で内税計算 |
| 会計を間違えた | 売上画面から「会計を取り消して修正」 |
| 札をなくした・持ち帰られた | その札だけQRを再発行（古いQRは無効に） |
| いたずら注文が心配 | 設定「スタッフが受付した札だけスマホ注文できる」をオン |
| 深夜0時をまたぐ営業 | 営業日の切替時刻（初期値4時）で売上を集計 |
| iPadの画面が消える | 画面のスリープを防止（対応ブラウザ）、ホーム画面に追加してアプリのように使える |
| 回数券・豆を売る | 「店内専用」商品としてレジでのみ販売（お客様のメニューには出ない） |

## 動かしてみる

Node.js 18 以上が必要です。

```bash
cd cafe-order
npm install
npm start
# → http://localhost:3000/admin を開いて PIN 1234 でログイン
```

ログイン後：

1. **設定** → PINを変更、店名・住所・インボイス登録番号を入力して保存
2. **メニュー** → サンプルのメニューを自分のお店のものに書き換え
3. **設定** →「お客様がアクセスするURL」を確認して「番号札（QR）を印刷」→ ラミネートして番号札に
4. 毎朝 **本日の準備** で日替わりの中身・売り切れを入力

試すだけなら、オーナー画面のホールで札の番号を確認し、ブラウザの別タブで `http://localhost:3000/t/1?k=…`（QR印刷画面に入っているURL）を開くとお客様画面になります。

## お店で使うための公開方法

お客様のスマホ（4G/5G）から開けるように、インターネットに公開する必要があります。どれか1つを選んでください。

### A. 店内のパソコン + Cloudflare Tunnel（無料・おすすめ）
店内の常時起動のPC／Mac／Raspberry Pi で `npm start` し、[Cloudflare Tunnel](https://developers.cloudflare.com/cloudflare-one/connections/connect-networks/) で `https://order.お店のドメイン` のようなURLに公開します。データは店内PCに残ります。

### B. クラウド（Fly.io / Railway / Render など）
同梱の `Dockerfile` でそのまま動きます。**データを保存するボリューム（永続ディスク）を `/data` にマウント**してください（ないと再起動で売上が消えます）。

```bash
docker build -t cafe-order .
docker run -p 3000:3000 -v cafe-data:/data cafe-order
```

公開後、オーナー画面の **設定 →「お客様がアクセスするURL」** に公開URL（例 `https://order.example.com`）を入れて保存し、番号札を印刷してください。

| 環境変数 | 意味 | 初期値 |
|---|---|---|
| `PORT` | 待ち受けポート | `3000` |
| `DATA_DIR` | データ保存先 | `./data` |

### データとバックアップ
- `data/state.json` … 設定・メニュー・営業中の伝票
- `data/checks/YYYY-MM-DD.json` … 営業日ごとの会計履歴
- `data/uploads/` … 商品写真

設定画面の「バックアップをダウンロード」で全データをJSONで保存できます。売上画面からCSV（会計別・商品別・月間）も出せます。

## 開発者向け

```
cafe-order/
├── server.js              起動スクリプト
├── lib/
│   ├── app.js             API・リアルタイム配信(SSE)・画面配信（フレームワーク不使用）
│   ├── store.js           JSONファイル保存
│   └── seed.js            初期メニュー・初期設定
├── public/
│   ├── shared/calc.js     料金・チケット・割り勘・提供可否の計算（サーバーと画面で共用）
│   ├── order.html/js/css  お客様画面
│   ├── admin.html/css     オーナー画面
│   └── admin/*.js         オーナー画面の各タブ
└── test/                  node:test によるテスト
```

- 依存パッケージは QRコード生成の `qrcode` のみ。ビルド不要。
- 金額はすべて税込の整数（円）。価格はサーバー側で再計算し、画面から送られた金額は使いません。
- テスト：`npm test`
