# 土地さがしナビ（land-finder）

お客様の希望条件（エリア・予算・広さなど）に合う土地を集めて **優先度：高／中／低** にランク分けし、
**ハザードの見解・戸建て設計の法令／条例の注意点・地域特性** まで含めた提案書を作る、住宅会社・不動産担当者向けのWebアプリです。

```
┌ 検索条件 ─────┐ ┌ 優先度:高 13 ┐┌ 優先度:中 10 ┐┌ 優先度:低 11 ┐
│ お客様名      │ └──────────────┘└──────────────┘└──────────────┘
│ エリア        │ ┌ 物件カード（価格・坪単価・駅徒歩・   ┐ ┌ 地図 ────────┐
│ 予算・面積    │ │ ハザードバッジ・条件の○△×）        │ │ ランク別ピン │
│ 駅徒歩・道路  │ │ クリック → 詳細（5タブ）             │ │ ハザード重ね │
│ 用途地域      │ └──────────────────────────────────────┘ │ 表示         │
│ こだわり      │   概要・条件 / ハザード / 法令・条例 /     └──────────────┘
│ 重要度の設定  │   地域特性 / 提案書（印刷・PDF）
└───────────────┘
```

## 主な機能

### 1. 検索（条件に合う土地を集める）
- 条件：エリア（都道府県・市区町村の複数選択）、予算、土地面積（㎡／坪切替）、駅徒歩、前面道路幅員、用途地域、南側接道、整形地、建築条件なし、市街化調整区域の除外、災害リスクの許容度
- 物件の取得元は **アダプタ方式** で追加できます（`server/sources/`）。標準で次の3つを搭載しています。
  - **サンプルデータ**：首都圏の架空物件42件（動作確認用。所在地は実在の町丁目の代表点）
  - **CSV取り込み**：土地バンク形式・各社の物件リスト・手入力の表など。列名の表記ゆれ（「所在地／住所」「土地面積／敷地面積」「建ぺい率･容積率」など）と Shift_JIS に対応
  - **物件ページURL取り込み**：SUUMO・LIFULL HOME'S・不動産ジャパン・各社サイトの物件詳細ページURLを貼ると、表（th/td・dt/dd）から価格・面積・交通・用途地域・接道・その他制限などを読み取ります
- 検索結果には、同じ条件で **SUUMO／HOME'S／不動産ジャパンの検索ページを開くリンク** も表示します
- 同一物件が複数の取得元にある場合は1件にまとめます（重複除去）

### 2. 優先順位付けとランク分け
各条件を「満たす／惜しい／満たさない／情報不足」で判定し、条件ごとの重要度（必須・重視・希望）で重み付けした **適合スコア（0〜100）** を計算します。

| ランク | 判定基準 |
|---|---|
| **優先度：高** | すべての条件を満たす |
| **優先度：中** | 必須・重視条件を満たす（「惜しい」は可）、スコア70以上 |
| **優先度：低** | 重視条件に未達がある、または必須条件が「惜しい」範囲 |
| 対象外 | 必須条件のいずれかが未達（「対象外も表示」で確認可能） |

「惜しい」の幅：予算超過10%以内、面積不足10%以内、駅徒歩+5分以内、道路幅員−0.5m以内 など（`server/search/scoring.ts` の `TOLERANCE`）。

### 3. 付加情報の提示
- **ハザード**：国土交通省「重ねるハザードマップ」のオープンデータ（国土地理院配信のタイル）を地点ごとに読み取り、
  洪水（想定最大規模）・浸水継続時間・家屋倒壊等氾濫想定区域・高潮・津波・土砂災害警戒区域（土石流／急傾斜地／地すべり）と標高を自動判定。
  浸水深や区域に応じて **戸建て計画の観点からの見解**（高基礎・設備の嵩上げ・垂直避難の可否・レッドゾーンの構造規制など）を表示します。地図にハザードを重ねて確認できます。
- **法令・条例**：用途地域・建ぺい率／容積率・前面道路による容積率制限・セットバック・角地緩和・防火指定・高度地区・接道義務・私道・旗竿地・市街化調整区域・農地転用・風致地区・地区計画・埋蔵文化財などを自動チェックし、
  **建築面積／延床面積の上限の目安** を計算。東京都建築安全条例・神奈川県／横浜市の建築基準条例（がけ条例・路地状敷地など）の論点も表示します（「要確認」タグ付き）。
- **地域特性**：交通・街並み（用途地域）・地形（標高）・価格水準（同じ市区町村の候補との坪単価比較）・徒歩圏の施設（小学校・保育園・スーパー・病院・公園など／OpenStreetMap）・市区町村の概要
- **提案書**：上記をまとめたお客様向け提案書を画面から印刷・PDF保存できます
- **AI提案コメント（任意）**：`ANTHROPIC_API_KEY` を設定すると、Claude が Web 検索で地域特性（子育て環境・自治体の支援制度・地価動向など）を調べ、提案コメントを作成します

## 使い方

必要なもの：Node.js 20.12 以上

```bash
cd land-finder
npm install

# 開発（APIサーバー :8787 と画面 :5173 を同時起動）
npm run dev
# → http://localhost:5173 を開く

# 本番（ビルドしてAPIサーバーから配信）
npm run build
npm start
# → http://localhost:8787 を開く
```

任意の設定は `.env.example` を `.env` にコピーして編集します（AI提案を使う場合は `ANTHROPIC_API_KEY`）。

| コマンド | 内容 |
|---|---|
| `npm test` | 単体テスト（パーサー・ランク判定・法令チェック・ハザード判定・取り込み） |
| `npm run typecheck` | 型チェック |
| `npm run build:sample` | サンプル物件の座標を取り直して `data/sample-listings.json` を再生成 |

### 画面の流れ
1. 左の検索条件で「お客様名」「エリア」「予算」などを入力 →「この条件で探す」（保存ボタンでお客様ごとに条件を保存）
2. 上部のランク別タイル（高・中・低）で絞り込み、並び替え・リスト／地図表示を切替
3. 物件カードをクリック → 詳細の5タブ（概要・条件／ハザード／法令・条例／地域特性／提案書）
4. 「提案書」タブから印刷・PDF保存
5. ポータルで見つけた物件は、右上「物件を取り込む」に詳細ページのURLを貼るかCSVで取り込むと、同じ基準でランク分けされます

## ポータルサイトとの連携について（重要）
SUUMO・LIFULL HOME'S・不動産ジャパン等は利用規約で **機械的な情報収集（自動巡回・スクレイピング）を制限** しています。
そのため本ツールは各サイトを自動巡回せず、次の方法で連携します。

- 条件に合う **検索ページを開くリンク** を表示（担当者がサイト上で確認）
- 担当者が指定した **物件ページ1件ずつのURL取り込み**（robots.txt で禁止されたページは取得しません）
- **CSV取り込み**（自社の物件データ、取引先から提供を受けた物件リスト、土地バンク形式のリストなど）

データ提供契約やAPI（業者向けフィード等）を利用できる場合は、`server/sources/types.ts` の `SourceAdapter` を実装して `server/search/service.ts` の `SOURCES` に追加するだけで、検索・ランク分け・ハザード判定の対象になります。

## 注意事項
- ハザード判定は物件の住所（通常は町丁目まで）の代表点で行う **概略判定** です。実際の敷地位置で必ず再確認してください。内水氾濫・液状化・地盤の強さは判定に含まれません。
- 法令・条例のチェックは一般則にもとづく目安です。条例は自治体ごとに異なり改正もあるため、「要確認」の項目は特定行政庁で確認してください。最終的な判断は重要事項説明・役所調査・建築士のボリュームチェックで行ってください。
- サンプルデータは架空の物件です。
- 外部サービス：国土地理院（地図タイル・住所検索・標高API）、ハザードマップポータルサイト（ハザードタイル）、OpenStreetMap Overpass API（周辺施設）。取得結果は `data/cache/` にキャッシュします。

## ディレクトリ構成
```
land-finder/
├─ shared/            画面とサーバーで共有する型・単位換算・用途地域マスタ
├─ server/
│  ├─ index.ts        APIサーバー（Express）
│  ├─ sources/        物件の取得元アダプタ（サンプル・取り込み）とポータルリンク
│  ├─ import/         CSV・URL取り込み、表記ゆれを吸収するパーサー
│  ├─ search/         集約・重複除去・条件評価・ランク分け
│  └─ insight/        ハザード判定・法令／条例チェック・地域特性・提案文・AIコメント
├─ src/               画面（React + Leaflet）
├─ data/              サンプル物件・取り込み物件・キャッシュ
├─ scripts/           サンプルデータ生成
└─ tests/             単体テスト（Vitest）
```
