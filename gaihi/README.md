# 外皮計算ツール

設計図書（平面図・立面図・仕様書など）の PDF を入れると、AI（Claude）が寸法を読んで外皮面積を方位別に拾い、
**UA 値・ηAC 値・ηAH 値と計算書（印刷/PDF・Excel）を一発で出力**する Web アプリです。
拾った数量はすべて画面で確認・修正でき、各行に「根拠（例：X0-X6 5,460mm × 5.80m）」が残ります。

## できること

| 画面 | 内容 |
| --- | --- |
| 図面から自動入力 | PDF（製本図面一式でも可）・画像をドロップ、または Google ドライブから選択 → 図面名から平面図・立面図・仕様書などのページを自動で選ぶ → AI が外壁・開口部・天井・床・土間・土間外周を読み取り、そのまま計算 |
| 物件情報 | 物件名・建設地・地域区分（1〜8）・構造・断熱構造・延床面積 |
| 仕様（U値） | 部位ごとの熱貫流率。直接入力か、材料構成（厚さ・λ・熱橋部 λ・面積比率）から面積比率法で計算。窓は U・ηd・取得日射熱補正係数 |
| 外皮面積 / 開口部 / 土間外周 | 方位・隣接空間（外気／床下 など）・面積・根拠を表で編集。開口部は取り付く外壁から自動で差し引き |
| 計算明細 | 部位ごとの A・U・H、η・ν・m と計算式 |
| 出力 | 計算書（印刷・PDF 保存）、Excel（結果／部位仕様／外皮面積／開口部／計算明細の5シート）、物件データ JSON |

判定は 省エネ基準（断熱等級4）・等級5（ZEH水準）・等級6・等級7 の UA・ηAC 基準値と比較します。

既定の仕様セットは社内の「重説+省エネ+簡易計算シート_6地域_Superior」の値
（天井 U0.23／外壁 U0.41（高性能GW16K 105mm を材料構成で計算）／床 U0.35／基礎壁 U0.50／窓 U1.47・ηd0.32／ドア U1.79／土間外周 ψ0.65）です。

## 計算方法

建築物省エネ法の住宅の外皮性能の評価方法（標準計算）に沿っています。

- UA = Σ(A・U・H) + Σ(L・ψ・H) を外皮面積の合計 ΣA で割る（小数第3位以下切り上げ）
- ηAC / ηAH = Σ(A・η・ν) ÷ ΣA × 100（ηAC は小数第2位以下切り上げ、ηAH は切り捨て）
- 不透明部位の η = 0.034 × U、窓の η = ηd × 取得日射熱補正係数（既定 冷房 0.93 / 暖房 0.51）
- 温度差係数 H：外気 1.0、床下・外気に通じていない空間 0.7、住戸と同様の空間 0.05（1〜3地域）/ 0.15（4〜8地域）
- 外気に接しない部位と下面（床）の方位係数は 0。8地域は ηAH を評価しない

係数表（方位係数・基準値・材料の λ）は `src/lib/gaihi/constants.ts` にまとめてあります。
**申請に使う前に、最新の告示・解説書の表と一度突き合わせてください。**

## セットアップ

```bash
cd gaihi
npm install
cp .env.example .env.local   # ANTHROPIC_API_KEY を記入
npm run dev                  # http://localhost:3000
```

| 環境変数 | 必須 | 内容 |
| --- | --- | --- |
| `ANTHROPIC_API_KEY` | 図面読み取りに必須 | Claude API キー（サーバー側だけで使い、ブラウザには出ません） |
| `GAIHI_MODEL` | 任意 | 読み取りに使うモデル。既定は `claude-opus-5-5` |
| `NEXT_PUBLIC_GOOGLE_CLIENT_ID` / `NEXT_PUBLIC_GOOGLE_API_KEY` / `NEXT_PUBLIC_GOOGLE_APP_ID` | Google ドライブ連携を使うとき | 下記参照 |

手入力・計算・計算書出力は API キーなしでも動きます。

### Google ドライブから図面を選べるようにする

1. Google Cloud コンソールでプロジェクトを作り、「Google Drive API」と「Google Picker API」を有効にする
2. 「OAuth クライアント ID（ウェブアプリケーション）」を作り、承認済みの JavaScript 生成元にこのアプリの URL（例 `https://xxx.vercel.app`、`http://localhost:3000`）を登録する
3. 「API キー」を作る（Picker API に制限しておくと安全）
4. `NEXT_PUBLIC_GOOGLE_CLIENT_ID`（クライアント ID）、`NEXT_PUBLIC_GOOGLE_API_KEY`（API キー）、`NEXT_PUBLIC_GOOGLE_APP_ID`（プロジェクト番号）を設定して再ビルド

権限は `drive.file`（ピッカーで選んだファイルだけ読める）です。未設定の間は、ドライブからダウンロードした PDF をドロップして使えます。

### Vercel に置く場合

Root Directory を `gaihi` にしてインポートし、環境変数を設定します。読み取りの API は最大 300 秒動くよう設定してあります。
Vercel の関数は 1 回のリクエストが 4.5MB までなので、送る前にブラウザ側で必要なページだけを切り出し、それでも大きいときは画像に変換して縮めます。

## データの保存先

物件データはブラウザの localStorage に保存します（サーバーには残りません）。
別の PC で使うときは「物件データを保存（JSON）」→ トップの「保存した物件（JSON）を読み込む」で移せます。
図面は読み取りのときだけ Claude API に送られ、アプリ側には保存しません。

## 開発

```bash
npm test          # 計算エンジン・読み取り結果の展開のテスト
npm run typecheck
npm run build
```

| パス | 内容 |
| --- | --- |
| `src/lib/gaihi/` | 計算エンジン（型・係数表・U値計算・UA/ηA 計算・既定仕様） |
| `src/lib/extract/` | 図面読み取りの指示文・出力スキーマ・物件データへの展開 |
| `src/app/api/extract/route.ts` | Claude API を呼ぶサーバー側の処理 |
| `src/lib/drawings.ts` | PDF のページ分け・種類推定・切り出し（ブラウザ側） |
| `src/lib/gdrive.ts` | Google ドライブ（Picker）連携 |
| `src/app/project/` | 入力画面と計算書 |
