# アフィリエイト自動運用システム

キーワード選定から記事の執筆、品質チェック、公開、検索エンジンへの通知、公開後のリライトまでを、GitHub Actions 上で**毎日自動で**回す仕組みです。
最初の設定が終われば、日々の運用に人間の作業は要りません。

```
毎朝 6:07 (JST)
  ├─ ① キーワード補充   在庫が15件を切ったら、最新動向を調べて報酬×検索意図で優先順位づけ
  ├─ ② 調査            Web検索で公式サイト・公的機関の最新情報を集め、出典URLを記録
  ├─ ③ 執筆            編集方針に沿って比較表・FAQ付きの記事を作成（1日2本）
  ├─ ④ 品質ゲート       文字数・構成・出典・誇大表現・体験談の捏造・重複を機械チェック
  ├─ ⑤ 編集長レビュー    AIが10点満点で採点。7点未満や④の不合格は自動修正し、直らなければ見送り
  ├─ ⑥ リライト         Search Console で「11〜20位」「クリック率が低い」記事を優先的に改善
  ├─ ⑦ サイト生成・公開   GitHub Pages に公開（sitemap / RSS / 構造化データ付き）
  └─ ⑧ 通知            IndexNow で Bing などに新しいURLを即時通知
```

## 月100万円について（正直な見通し）

このシステムがやるのは「良質な記事を出し続けて、検索から申込につなげる」ことを自動化することです。**収益を保証するものではありません。**

- 月100万円の例: 報酬1.5万円の案件（転職エージェントの無料登録など）が月70件成約
  → 記事から広告へのクリック率5%、クリック後の成約率1%とすると、**申込意図の強い検索流入が月14万PV前後**必要です。
- 新しいドメインは、Googleに評価されるまで**6〜12か月**かかるのが普通です。最初の数か月はほぼゼロ円です。
- 上位の成果が出るのは一部のサイトだけです。このため、仕組みは「量産」ではなく「1本ずつ審査を通った記事だけを公開する」設計にしています。
  AIで記事を大量生産して順位を操作するサイトは Google のスパムポリシー（大量生成コンテンツの不正使用）で順位を落とされます。

収益を伸ばすうえで効くのは、主に次の3つです。

1. **高単価案件との提携**（下の「人間がやること」の③）
2. **独自ドメイン**（ASPの審査と検索評価の両方に効きます）
3. **Search Console の接続**（伸びしろのある記事を実データで選んでリライトできるようになります）

## 人間がやること（最初の1回だけ）

本人確認・支払い・口座登録が必要な作業は、法律上も規約上も本人しかできません。以下だけお願いします。

| # | 作業 | 所要時間 | 必須 |
|---|---|---|---|
| ① | [Anthropic Console](https://console.anthropic.com/) でAPIキーを発行し、GitHub の **Settings → Secrets and variables → Actions** に `ANTHROPIC_API_KEY` として登録 | 5分 | 必須 |
| ② | GitHub の **Settings → Pages → Source** を **GitHub Actions** に変更 | 1分 | 必須 |
| ③ | 記事が10本ほど公開されたら、ASP（A8.net・もしもアフィリエイト・afb・バリューコマース）に登録してサイト審査を申請。提携できた案件の広告リンクを `config/programs.yaml` の `url` に貼る | 30分〜 | 必須 |
| ④ | [Google Search Console](https://search.google.com/search-console) にサイトを登録し、`sitemap.xml` を送信 | 10分 | 推奨 |
| ⑤ | 独自ドメインを取得し、`config/site.yaml` の `base_url` を変更して Pages のカスタムドメインに設定 | 15分 | 推奨 |
| ⑥ | Search Console の API 用サービスアカウントを作り、JSON キーを `GSC_SERVICE_ACCOUNT_JSON`（Secret）、プロパティURLを `GSC_SITE_URL`（Variable）に登録 | 20分 | 任意 |

①②が終われば毎朝自動で動きます。すぐに記事を増やしたいときは **Actions → affiliate-autopilot → Run workflow** で「今回生成する記事数」に `10` などを入れて実行してください。

提携前の案件は、記事中で「リンクなしの紹介」として表示されるだけなので、サイトが壊れることはありません。提携済みかどうかは `data/STATUS.md` で確認できます。

## 費用

- 記事1本あたりのAPI費用は、調査・執筆・レビュー・修正込みで概算 1〜1.5ドル（約150〜230円）です。
- 月の上限は `config/site.yaml` の `monthly_budget_usd`（初期値 150ドル）で、超えるとその月は生成を止めます。
- GitHub Pages と GitHub Actions は公開リポジトリなら無料です。

## 法令・ポリシーへの対応

| 項目 | 対応 |
|---|---|
| ステルスマーケティング規制（景品表示法、2023年10月施行） | 全記事の冒頭に「PR」表記、フッターに広告の説明、広告掲載ポリシーのページ |
| 優良誤認・有利誤認 | 「必ず稼げる」「業界No.1」などの断定・誇大表現を品質ゲートで自動的に弾く |
| 体験談の捏造 | 「受講してみた」「私が利用した」など、実体験を装う表現を自動的に弾く（編集部として第三者視点で書く） |
| 事実の正確性 | 料金・条件などは Web検索で集めた出典にあるものだけを使用。モデルが挙げた出典のうち、実際の検索結果にないURLは自動で除外 |
| 検索エンジンのガイドライン | 広告リンクに `rel="sponsored"`、1日の公開本数を制限、重複記事は類似度チェックで弾く |

## ファイル構成

```
affiliate/
├─ config/site.yaml        サイト名・ジャンル・投稿ペース・予算・品質基準
├─ config/programs.yaml    アフィリエイト案件（提携後に url を貼る）
├─ data/keywords.yaml      記事テーマの在庫（自動で補充・並べ替え）
├─ data/STATUS.md          運用状況レポート（自動更新）
├─ content/articles/       公開記事（Markdown）
├─ content/pages/          運営者情報・プライバシーポリシーなど
├─ engine/                 システム本体（Python）
├─ templates/ static/      サイトのデザイン
└─ tests/                  自動テスト
```

## ジャンルを変えたいとき

`config/site.yaml` の `niche`（テーマ・読者・カテゴリ）と `config/programs.yaml`（案件）を書き換え、`data/keywords.yaml` の `keywords:` を空のリスト `[]` にすれば、次回の実行から新しいジャンルでキーワード選定が始まります。

## 手元で動かす

```bash
cd affiliate
pip install -r requirements.txt
python -m pytest -q tests          # テスト
python -m engine build             # public/ にサイトを出力
ANTHROPIC_API_KEY=... python -m engine autopilot --articles 1   # 記事を1本生成
python -m engine status            # 運用状況
```
