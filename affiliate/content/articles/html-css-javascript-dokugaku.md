Webサイトを作れるようになりたいと思って調べ始めたら、HTML、CSS、JavaScriptと名前がいくつも出てきて、どれから手をつければいいのか分からなくなった。そんな場面を想定して書きました。最初にここで迷うのは、ごく自然なことです。

HTML・CSS・JavaScriptを独学するなら、**HTML → CSS → JavaScriptの順番**で学ぶのが基本です。HTMLでページの骨組みを作り、CSSで見た目を整え、JavaScriptで動きを加える、という役割の順番に沿って学ぶと、それぞれが何のためにあるのかを理解しやすくなります。

## HTML・CSS・JavaScriptの役割の違い

MDN Web Docsは、この3つの言語の役割を次のように説明しています。HTMLはウェブコンテンツに構造と意味を与えるマークアップ言語、CSSはHTMLコンテンツに適用するスタイリング規則の言語、JavaScriptは動的に更新されるコンテンツを作成したり、マルチメディアを制御したり、画像をアニメーションさせたりできるスクリプト言語です。MDNは、この3つを「レイヤーケーキ」にたとえ、JavaScriptをその3層目と表現しています。

| 言語 | 役割 | たとえると |
| --- | --- | --- |
| HTML | 段落・見出し・表・画像など、ページの構造と意味を作る | 家の骨組み |
| CSS | 色・文字の大きさ・レイアウトなど、見た目を整える | 内装や外観 |
| JavaScript | クリックに反応する、内容を書き換えるなど、動きを加える | 電気や水道などの設備 |

MDNの例では、HTMLでボタンを作り、CSSで見栄えを整え、JavaScriptでクリックしたときに名前を入力できるようにする流れが紹介されています。**一つの部品が、3つの言語を重ねることで完成していく**とイメージすると、学ぶ順番の意味が分かりやすくなります。

## 独学で学ぶ順番と、まず押さえたい範囲

検索では「html css 独学 どれくらい」もよく調べられています。かかる期間は目的や学習時間によって変わりますが、それぞれの言語で「まずここまで」という範囲を決めておくと、計画が立てやすくなります。

### 1. HTML：ページの骨組みを作れるようにする

最初は、見出し、段落、リスト、リンク、画像、表など、よく使う要素を使ってページを作れることを目指します。**見た目より「この文章は見出しなのか、段落なのか」という意味を正しく書くこと**を意識すると、あとでCSSやJavaScriptを使うときに役立ちます。

### 2. CSS：見た目とレイアウトを整えられるようにする

次に、文字の色や大きさ、余白、背景などを指定できるようにします。そのうえで、要素を横に並べるなどのレイアウトと、スマートフォンでも見やすく表示する方法を学びます。CSSは、思ったとおりに並ばないことが多く、最初に時間がかかりやすいところです。

### 3. JavaScript：簡単な動きを加えられるようにする

HTMLとCSSで一通りページを作れるようになったら、JavaScriptに進みます。MDNの「JavaScript とは」では、JavaScriptでできることとして、値を変数に格納すること、文字列を操作すること、ウェブページで起きるイベントに対処することなどが挙げられています。まずは、ボタンを押したら文字が変わる、といった小さな動きから始めましょう。

:::point 順番を守るとよい理由
- JavaScriptはHTMLの要素を操作する場面が多く、HTMLの理解が前提になる
- CSSで見た目を整える経験があると、JavaScriptで見た目を変える処理も理解しやすい
- 一つずつ「作れた」という手応えを得ながら進められる
:::

JavaScriptでつまずきやすいところは {{link:javascript-dokugaku-muzukashii|JavaScriptの独学が難しいと感じる理由は？}} で詳しく整理しています。

## 無料サイト・本・動画講座の選び方

検索では「html css 独学 サイト 無料」「html css 独学 本」も調べられています。教材は大きく3種類あり、それぞれ向いている人が違います。

| 教材 | 特徴 | 向いている人 |
| --- | --- | --- |
| 無料の学習サイト | 費用をかけずに始められる。内容や新しさはサイトによって異なる | まず試してみたい人 |
| 本 | 学ぶ順番が整理されていて、手元で読み返せる | 文章で順を追って理解したい人 |
| 動画講座 | 画面の操作を見ながら、同じように手を動かせる | 操作や手順でつまずきやすい人 |

無料で体系的に学びたい場合は、MDN Web Docsの「ウェブ開発の学習」が選択肢になります。MDNによると、このコースは、コードエディターをインストールしたこともコードを書いたこともない、まったくの初心者向けの入門モジュールから始まり、基本を学ぶコアモジュール、知識を広げる発展モジュールへと段階的に進めるよう構成されています。

文章で順を追って学びたい人は、{{aff:learning-books|HTML・CSSの入門書}}を一冊決めて最後まで進めると、学ぶ順番に迷いにくくなります。画面を見ながら手を動かしたい人は、{{aff:learning-online-course|オンライン動画講座}}で、HTML・CSSからJavaScriptまでを順に扱う講座を選ぶ方法もあります。

:::warning 教材を同時にいくつも進めない
無料サイト、本、動画を同時に進めると、同じ基礎を何度も学び直すことになり、かえって時間がかかります。メインの教材を一つ決め、分からないところだけ他の教材で調べる、という使い分けがおすすめです。
:::

## 独学でつまずかないための進め方

:::steps 3つの言語を学ぶ流れ
1. **ゴールを決める**：「自分のプロフィールページを作る」など、作りたいものを一つ決めます。
2. **HTMLで骨組みを作る**：見出し、段落、画像、リンクを使って、ページの中身を書きます。
3. **CSSで見た目を整える**：色や余白、レイアウトを整え、スマートフォンでの見え方も確認します。
4. **JavaScriptで動きを足す**：ボタンを押すと表示が変わるなど、小さな動きを一つ加えます。
5. **別のページで繰り返す**：テーマを変えて、もう一度1〜4を通して作ってみます。
:::

**同じ流れを、テーマを変えて何度か繰り返す**と、3つの言語の関係が体で分かるようになってきます。一回目は教材を見ながらで構いません。二回目、三回目と進むうちに、見なくても書ける部分が増えていきます。

### 作ったものは「確認」まで終わらせる

ページを作ったら、パソコンとスマートフォンの両方で表示を確かめ、リンクが正しく動くかも確認しておきましょう。MDNの学習コースには、学んだ内容を確かめる「確認テスト」や、複数の機能を組み合わせて作る「チャレンジ」も用意されています。**作って終わりにせず、確かめるところまでを一つの区切りにする**と、理解の抜けに気づきやすくなります。

## 独学でつまずきやすい場面と乗り越え方

3つの言語を独学で進めていると、多くの人が似た場面で手が止まります。前もって知っておくと、止まったときに「自分だけではない」と落ち着いて対処できます。

### 書いたのに表示が変わらない

CSSを書いたのに見た目が変わらない、という場面はとてもよくあります。ファイルの保存忘れ、読み込みの指定の書き間違い、セレクタ（どの要素に指定するか）の書き間違いなどが原因であることが多いです。**ブラウザの開発者ツールで、指定が要素に効いているかを確かめる**習慣をつけると、原因を探しやすくなります。

### レイアウトが思いどおりに並ばない

要素を横に並べる、中央にそろえるといったレイアウトは、CSSの中でもつまずきやすいところです。一度にページ全体を整えようとせず、まずは二つの箱を横に並べるだけ、のように小さく試して、仕組みを確かめながら進めましょう。

### JavaScriptでエラーが出る

JavaScriptでは、一文字の書き間違いでも動かなくなることがあります。エラーメッセージの行番号を手がかりに、教材のコードと見比べてみてください。エラーメッセージで検索すると、同じ問題の解決方法が見つかることもあります。

## 独学のメリット・デメリット

:::merit 独学のメリット
- 費用を抑えて始められる
- 自分のペースで、作りたいものに合わせて学べる
- 調べて解決する力が身につく
:::

:::demerit 独学のデメリット
- 分からないところで止まると、時間がかかりやすい
- 学ぶ範囲や順番を自分で決める必要がある
- 自分の書き方が正しいかを判断しにくい
:::

編集部としては、**最初は無料の教材で始め、続けられそうだと分かってから本や動画講座に費用をかける**順番をおすすめします。実際に手を動かしてみると、自分がどこでつまずきやすいかが分かり、教材を選ぶ基準がはっきりするからです。

## 迷ったときの次の一歩

何から始めるか迷ったら、今日は「自分の名前と好きなものを書いたページ」を、HTMLだけで一枚作ってみてください。見た目は気にしなくて大丈夫です。ブラウザで開いて表示されたら、それが最初の一歩になります。

その次にCSSで色を一つ変えてみる。そうやって少しずつ進めていけば、3つの言語は自然につながっていきます。本や動画講座は、必要だと感じてから選べば十分ですし、合わなければ見送って構いません。

## よくある質問

### HTML・CSS・JavaScriptはどの順番で学べばいい？

HTML → CSS → JavaScriptの順番がおすすめです。MDN Web Docsでも、JavaScriptを学ぶ前提知識としてHTMLとCSSの基礎を理解していることが挙げられています。

### HTML・CSSの独学はどれくらいかかる？

目的と学習時間によって変わるため、決まった期間はありません。「簡単なページを一枚作れる」など具体的なゴールを決め、進めた時間をもとに残りの期間を見積もると、自分に合った計画を立てやすくなります。

### HTML・CSSを無料で独学できるサイトは？

MDN Web Docsの「ウェブ開発の学習」は、まったくの初心者向けの入門モジュールから段階的に学べる無料の教材です。ほかにも無料の学習サイトはありますが、メインの教材は一つに絞って進めるのがおすすめです。

### HTML・CSSの独学におすすめの本は？

初心者向けと書かれた入門書から、発行年が新しく、サンプルを自分で書いて試せる構成のものを選ぶと進めやすくなります。書店や試し読みで、説明が自分に合うかを確かめてから選ぶと安心です。
