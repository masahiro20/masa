本業の合間に少しでも収入を増やしたいと思っていたところ、Claude Codeを使えばプログラミングの経験が浅くてもツールやアプリを作れると聞いた。これを副業につなげられないかと考えているものの、実際に何ができるのか、仕事として受けて大丈夫なのか、よく分からずにいる。そんな場面を想定して書きました。新しい道具で何か始めたいという気持ちは、とても前向きなものです。

Claude Codeを使った副業は、**できることの範囲を正しく理解し、小さな仕事から始めれば、十分に選択肢になります**。公式ドキュメントによると、Claude Codeは**コードベースを読み取り、ファイルを編集し、コマンドを実行し、開発ツールと統合する**AIコーディングツールで、機能の構築、バグの修正、開発タスクの自動化を支援するとされています（2026年11月時点）。

ただし、**AIが書いたコードでも、動作の確認や品質に責任を持つのは自分**です。また、会社員の場合は、**勤め先の就業規則で副業が認められているか**を最初に確認しましょう。

## Claude Codeでできること

公式ドキュメントでは、Claude Codeについて次のように説明されています。

:::check 公式ドキュメントで確認できること
- コードベース全体を理解し、複数のファイルとツールをまたいで作業できる
- 機能の構築、バグの修正、開発タスクの自動化を支援する
- ターミナル、IDE拡張機能、デスクトップアプリ、Webなど、複数の場所で使える
- ほとんどの利用方法で、Claudeのサブスクリプションか、Anthropic Consoleのアカウントが必要
:::

つまり、Claude Codeは**「指示を出すと、コードを書いたり修正したりしてくれる開発の相棒」**のような道具です。利用にはサブスクリプションなどの費用がかかるため、副業で使う場合は**利用料も経費として考えておく**必要があります。料金の考え方は {{link:claude-code-ryokin|Claude Codeの料金は？}} で整理しています。

## 副業につなげやすい使い方の例

検索では「claude code 副業 自動化」も調べられています。Claude Codeを副業に活かすなら、次のような使い方が考えられます。

| 使い方 | 内容の例 |
| --- | --- |
| 業務の自動化ツール | 表計算の集計、ファイルの整理、定型メールの作成などを自動化する小さなツールを作る |
| 小さなWebアプリ | 予約フォームや問い合わせページなど、シンプルなWebアプリを作る |
| Web制作の効率化 | ホームページの制作や修正の作業を、Claude Codeの支援で効率よく進める |
| 既存の仕事の時短 | 自分が受けている副業の作業そのものを自動化し、時間を生み出す |

結局のところ、**「身近な誰かの、手作業で困っていること」を解決する小さなツール**は、Claude Codeを使った副業の入口として考えやすい仕事です。

:::point 副業として始めやすい考え方
- まずは自分の本業や生活の中の作業を自動化して、作れるものを増やす
- 作ったものをポートフォリオとしてまとめ、何ができるかを見せられるようにする
- 最初は小さな仕事から受け、確認や修正に必要な時間を見積もれるようにする
:::

## 会社員が副業を始める前に確認したいこと

厚生労働省は、企業も働く人も安心して副業・兼業に取り組めるよう、**「副業・兼業の促進に関するガイドライン」**を作成しています。同省のページでは、モデル就業規則について、労働者の遵守事項から「許可なく他の会社等の業務に従事しないこと」という規定を削除し、副業・兼業についての規定を新設したと説明されています。

ただし、**実際に副業ができるかどうかは、勤め先の就業規則によって異なります**。

:::warning 副業を始める前に確認したいこと
- 勤め先の就業規則で、副業が認められているか（届け出や許可が必要か）
- 本業の会社の情報やコードを、副業で使わないこと
- 本業と同じ業界の仕事を受けることが、制限されていないか
- 副業で得た所得の確定申告が必要になるか
:::

**本業の会社の情報や、本業で書いたコードを副業に持ち込むことは、トラブルのもとになります**。迷ったときは、事前に勤め先へ相談しておくと安心です。Claude Codeに渡す情報も、副業の依頼主のものと、本業のものをはっきり分けて扱いましょう。

## 受注するときの注意点

:::merit Claude Codeを副業に使う良さ
- 一人でも、ツールやアプリを作れる範囲が広がる
- 作業時間を短くして、本業との両立がしやすくなる
- 作りながら学べるので、スキルアップにもつながる
:::

:::demerit 気をつけたいこと
- AIが書いたコードでも、動作の確認や不具合の修正は自分の責任になる
- 依頼主の情報をAIに渡してよいか、事前に確認が必要になる
- 利用料などの費用がかかるため、報酬とのバランスを考える必要がある
:::

**「AIが作ったから大丈夫」ではなく、「自分で動作を確認してから納品する」**ことが、副業で信頼を得るための基本です。依頼を受ける前に、何を作るのか、どこまで対応するのか、修正は何回までかを、書面やメールで取り決めておきましょう。

生成AIを使った副業全般の注意点（著作権など）は {{link:seisei-ai-fukugyo-shoshinsha|生成AIの副業は初心者でもできる？}} で整理しています。

## 始め方の流れ

:::steps Claude Codeで副業を始める流れ
1. **就業規則を確認する**：勤め先で副業が認められているか、届け出が必要かを確認します。
2. **Claude Codeに慣れる**：自分の作業を一つ自動化して、基本の使い方を身につけます。
3. **作品を作る**：小さなツールやWebアプリを作り、ポートフォリオとしてまとめます。
4. **小さな仕事から受ける**：知人の困りごとや、小さな依頼から始めます。
5. **振り返って広げる**：かかった時間や修正の回数を記録し、見積もりの精度を上げます。
:::

**最初の仕事は、報酬よりも「作り切って喜んでもらう経験」を重視する**と、次の仕事につながりやすくなります。

## 副業で迷いやすいポイント

ここで迷う方は多いので、考え方を整理しておきます。

### プログラミング未経験でもできるか

Claude Codeを使えば、経験が浅くても作れるものは広がります。ただ、**エラーの原因を調べたり、動作を確認したりするための基本的な知識**は必要になります。未経験から副業を目指すときの考え方は {{link:programming-fukugyo-mikeiken-muzukashii|プログラミング副業は未経験だと難しい？}} も参考にしてください。

### どれくらい稼げるか

報酬は、仕事の内容や依頼主、自分のスキルによって大きく変わります。**最初から大きな収入を目指すより、小さな仕事で実績を積み重ねる**ほうが、長く続けやすくなります。報酬を決めるときは、作業時間に加えて、確認や修正にかかる時間も含めて考えましょう。

### 本業との時間のバランス

副業に時間を使いすぎると、本業や生活に影響が出ることがあります。厚生労働省のページでは、副業・兼業の場合の労働時間の通算の考え方についての解説資料も公開されています。**平日は何時間、休日は何時間と、副業に使う時間を先に決めておく**と、無理なく続けやすくなります。

## よくある質問

### Claude Codeで副業はできる？

できる可能性はあります。公式ドキュメントによると、Claude Codeは機能の構築、バグの修正、開発タスクの自動化を支援するツールです。業務の自動化ツールや小さなWebアプリを作るなど、小さな仕事から始めるのがおすすめです。

### Claude Codeの副業にはどんな仕事がある？

表計算の集計やファイル整理などを自動化するツール作り、予約フォームなどのシンプルなWebアプリ作り、Web制作の作業の効率化などが考えられます。身近な人の手作業の困りごとを解決する仕事は、始めやすい入口です。

### 会社員がClaude Codeで副業をするときの注意点は？

勤め先の就業規則で副業が認められているかを最初に確認しましょう。また、本業の会社の情報やコードを副業で使わないこと、依頼主の情報をAIに渡してよいかを事前に確認することも大切です。

### Claude Codeの副業でかかる費用は？

公式ドキュメントでは、ほとんどの利用方法でClaudeのサブスクリプションか、Anthropic Consoleのアカウントが必要とされています。利用料は副業の経費として考え、報酬とのバランスを見ておきましょう。
