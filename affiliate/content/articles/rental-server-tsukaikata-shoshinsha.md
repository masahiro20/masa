ブログやホームページを作ろうと思って、レンタルサーバーを契約した。ところが、届いたメールにはサーバーIDやホスト名など見慣れない言葉が並び、管理画面を開いてもメニューが多すぎて、何から手をつければいいのか分からない。そんな場面を想定して書きました。初めて触る仕組みに戸惑うのは、まったく珍しいことではありません。

レンタルサーバーの使い方は、**「ドメインを設定する」「SSLを有効にする」「WordPressなどを入れる」**の3つから始めるのが基本です。そのうえで、必要に応じて**独自ドメインのメールを作る**、**データベース（MySQL）を使う**、**バックアップを確認する**といった作業を、管理画面（サーバーパネル）から行います。

最初からすべてのメニューを理解する必要はありません。**サイトを公開するのに必要な設定だけを先に済ませ、ほかの機能は必要になったときに使う**と考えると、迷わず進められます。

## 契約後にやることの順番

:::steps 契約してからサイトを公開するまで
1. **設定完了メールを保管する**：サーバーID、ホスト名、管理画面のログイン情報などが書かれています。
2. **ドメインをサーバーに設定する**：取得したドメインを、管理画面のドメイン設定で追加します。
3. **SSLを有効にする**：サイトを「https」で表示できるようにします。
4. **WordPressなどを入れる**：多くのサーバーでは、管理画面から簡単にインストールできます。
5. **表示を確認する**：ブラウザでサイトを開き、正しく表示されるかを確かめます。
:::

**最初に届く設定完了メールは、あとで何度も見返す**ことになります。エックスサーバーのマニュアルでも、メールソフトの設定などで「設定完了メールに記載されている」情報を使うよう案内されています。削除せず、すぐに見つけられる場所に保管しておきましょう。

ドメインの取得から公開までの流れは {{link:wordpress-blog-start-server-domain-steps|WordPressブログの始め方}} で詳しく整理しています。

## 管理画面（サーバーパネル）でできること

レンタルサーバーには、さまざまな設定を行うための管理画面があります。サービスによって名前やメニューは異なりますが、主に次のようなことができます。

| できること | 内容 |
| --- | --- |
| ドメイン設定 | 取得したドメインを、サーバーで使えるように追加する |
| SSL設定 | サイトを暗号化された通信（https）で表示する |
| WordPressのインストール | 画面の案内に沿って、WordPressを入れる |
| メールアカウントの作成 | 独自ドメインのメールアドレスを作る |
| データベース（MySQL）の設定 | データベースやユーザーを作成・管理する |
| ファイルの管理 | サーバー上のファイルを確認・アップロードする |
| バックアップ | サイトのデータを保存したり、元に戻したりする |

結局のところ、**初心者が最初に使うのは「ドメイン設定」「SSL設定」「WordPressのインストール」の3つ**です。ほかのメニューは、使う場面が来たときに開けば十分です。

## 独自ドメインのメールを作る

レンタルサーバーでは、**「info@自分のドメイン」のような独自ドメインのメールアドレス**を作れるものが多くあります。エックスサーバーのマニュアルでは、メールソフトを設定する前に**メールアカウントの追加**を行うよう案内されています。

:::check メールソフトに設定する主な項目（エックスサーバーのマニュアルより）
- POP/IMAPサーバー名・SMTPサーバー名：設定完了メールに記載されている「メールサーバー」（サーバーパネルの「サーバー情報」にあるホスト名と同じ）
- ユーザー名：追加したメールアドレス（ドメイン名を含む）
- パスワード：メールアカウントの追加で指定したパスワード
- ポート番号：受信・送信の方式ごとに決められた番号を入力する
:::

同じマニュアルでは、**POPとIMAPの併用は推奨していない**こと、メール送信時の認証方式として**SMTP認証（SMTP-AUTH）を推奨している**ことも示されています。スマートフォンとパソコンの両方でメールを見たい場合は、受信方式をどちらかに揃えておくと、トラブルを防ぎやすくなります。

:::warning パスワードは使い回さない
メールアカウントや管理画面のパスワードは、ほかのサービスと同じものを使わないようにしましょう。パスワードを忘れた場合は、管理画面から変更できることが多いので、手順を確認しておくと安心です。
:::

## データベース（MySQL）の役割

データベースは、サイトの記事や設定などの情報を保存しておく場所です。エックスサーバーのマニュアルでは、データベース環境として**MySQL**を提供しており、管理画面の「MySQL設定」から、**データベースやユーザーの作成・管理、アクセス権の設定、バックアップ**を行えると説明されています。

:::point 初心者が知っておきたいこと
- WordPressは、記事などの情報をデータベースに保存して動いている
- 管理画面からWordPressを自動でインストールする場合、データベースも自動で作られることが多い
- 手動でインストールする場合は、データベース・ユーザーの作成と、アクセス権の設定が必要になる
:::

**自動インストールを使えば、データベースを自分で作る必要がない**ことがほとんどです。データベースの画面は、手動でアプリを入れるときや、バックアップを確認したいときに開くものと考えておきましょう。

## 日々の管理で気をつけたいこと

サイトを公開したあとも、いくつか気をつけておきたいことがあります。ここで迷う方は多いので、基本を整理しておきます。

### バックアップの仕組みを確認する

多くのレンタルサーバーには、自動バックアップの機能があります。**どれくらいの期間のデータが保存され、どうやって元に戻すのか**を、早めに確認しておきましょう。

### WordPressやプラグインを更新する

WordPressやプラグインは、安全に使うために更新が配信されます。**管理画面に更新の通知が出たら、内容を確認して更新する**習慣をつけましょう。

### 契約の更新日を把握する

レンタルサーバーやドメインは、契約期間が終わると更新が必要です。**更新を忘れるとサイトが表示されなくなる**ことがあるため、自動更新の設定や、更新日をカレンダーに書いておくと安心です。

## サーバーの使いやすさで選ぶときは

:::merit 使いやすいサーバーを選ぶ良さ
- 管理画面が分かりやすく、迷わず設定できる
- WordPressのインストールやSSLの設定を、画面の案内に沿って進められる
- マニュアルやサポートが充実していると、困ったときに調べやすい
:::

:::demerit 確認しておきたいこと
- 料金は、契約期間やキャンペーンによって変わる
- 自動バックアップの範囲や、復元の方法はサービスごとに異なる
- メールの容量や、作成できるアカウント数に違いがある
:::

## 迷ったときの次の一歩

迷ったら、まずは設定完了メールを開き、サーバーID・ホスト名・管理画面のURLの3つにしるしをつけてみてください。そのうえで、管理画面にログインし、ドメイン設定のメニューがどこにあるかだけ確認してみましょう。

サーバーやドメインのサービスは、自分に合わなければ契約前に見送って構いません。無料のブログサービスから始める方法も含めて、自分に合ったやり方を選んでください。

## よくある質問

### レンタルサーバーを契約したら最初に何をする？

まずは設定完了メールを保管し、ドメインの設定、SSLの有効化、WordPressのインストールの順に進めるのが基本です。サイトを公開するのに必要な設定を先に済ませ、ほかの機能は必要になったときに使えば十分です。

### レンタルサーバーのメールはどうやって使う？

管理画面でメールアカウントを追加したあと、メールソフトにサーバー名やユーザー名、パスワード、ポート番号を設定します。エックスサーバーのマニュアルでは、POPとIMAPの併用は推奨されておらず、送信時はSMTP認証が推奨されています。

### レンタルサーバーのMySQLとは何？

サイトの記事や設定などの情報を保存しておくデータベースです。エックスサーバーのマニュアルでは、管理画面の「MySQL設定」から、データベースやユーザーの作成、アクセス権の設定、バックアップを行えると説明されています。

### レンタルサーバーの使い方が分からないときはどうすればいい？

各サービスの公式マニュアルやよくある質問を確認しましょう。設定の手順が画面付きで説明されていることが多く、困ったときはサポートに問い合わせることもできます。
