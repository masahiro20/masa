インフラエンジニアを目指して独学を始めようと、学習サイトを検索してみた。ところが、Linux、ネットワーク、クラウドとサイトがたくさん出てきて、どれから使えばいいのかが分からない。無料のもので足りるのかも気になっている。そんな場面を想定して書きました。分野が広い仕事なので、入り口で迷うのは当然のことです。

インフラエンジニアの独学サイトは、**「Linux」「ネットワーク」「クラウド」の分野ごとに、資格の実施団体や製品の提供元が公開している無料の公式教材から選ぶ**のが確実です。たとえば、LinuxならLPI-Japanの「Linux標準教科書」やLPIの「LPI Learning」、クラウドならAWSやMicrosoftの無料トレーニングがあります。

学ぶ順番は、**Linux → ネットワーク → クラウド**が進めやすい流れです。サーバーの多くはLinuxで動き、サーバー同士はネットワークでつながり、クラウドはその上に成り立っているからです。

- インフラの独学で学ぶ順番
- 学習サイトを選ぶときの確認点
- 無料サイトだけで足りないときの補い方
:::

## 分野別に見る、無料で使える公式の学習サイト

インフラエンジニアの独学に使える主な公式教材を、分野ごとに整理すると次のとおりです（2026年11月時点）。

| 分野 | 提供元 | 内容 |
| --- | --- | --- |
| Linux | LPI-Japan「Linux標準教科書」 | 初心者が基礎からLinuxを学ぶための教材。無料で公開 |
| Linux | LPI「LPI Learning」 | LinuxとOpen Source認定の取得を支援する学習教材。無料で提供 |
| ネットワーク | Cisco（CCNAの公式ページ） | 学習パスやシミュレーターなど、CCNAの学習方法を案内 |
| クラウド | AWS「AWS トレーニングと認定」 | 600を超える無料デジタルコースを案内 |
| クラウド | Microsoft Learn | 対話型のモジュールやラーニングパスを公開 |

表を見て迷ったら、**まずはLinuxの教材を一つ選び、そこから順に広げる**と考えてください。全部の分野を同時に始めると、どれも中途半端になりやすいからです。

### Linux：LPI-JapanとLPIの無料教材

LPI-Japanの「Linux標準教科書」は、初心者が基礎からLinuxを学ぶための学習用教材として無料で公開されています。最新版のVer. 4は「Linuxを初めて触る人のはじめの一歩」と位置づけられ、VirtualBoxのインストールと仮想マシンの作成から、基本的なコマンド、ユーザーとグループの管理、アクセス制御、ネットワークの設定と管理、プロセス管理までを扱っています。

LPIの「LPI Learning」では、LinuxとOpen Source認定の取得をサポートする学習教材を、教師と学習者向けに無料で提供していると案内されています。Linux EssentialsやLPIC-1の101試験・102試験の教材も並んでいます。

Linuxの勉強の進め方は {{link:linux-shoshinsha-benkyou-houhou|Linux初心者の勉強方法｜何から始めるかを5ステップで整理}} で詳しく整理しています。

### ネットワーク：Ciscoの公式情報とシミュレーター

ネットワークの代表的な資格であるCCNAについて、Ciscoの公式ページでは、ルーターやスイッチを使った実機演習や、Cisco Packet Tracer、Cisco Modeling Labsといったツールでの練習が勧められています。公式の学習パスや、CCNAの準備プログラムも紹介されています。

同ページには、本を読むだけでは合格できないという趣旨の記載もあります。**ネットワークの独学では、読む教材とあわせて、設定を試せるシミュレーターを用意する**ことが大切です。勉強時間の考え方は {{link:ccna-benkyou-jikan-mikeiken|CCNAの勉強時間は未経験だとどれくらい？}} で整理しています。

### クラウド：AWSとMicrosoftの無料トレーニング

AWSの「AWS トレーニングと認定」のページでは、AWSの専門家が監修した**600を超える無料デジタルコース**にアクセスできると案内されています。ラボ体験などは、AWS Skill Builderのサブスクリプションで利用できるとされています。職種や分野ごとに推奨されるラーニングプランも用意されています。

Microsoft Learnでは、対話型のモジュールやラーニングパスを通じて、自分のペースで学べると案内されています。空いた時間が15分でも1時間でも学べる、と説明されているように、短い単位で区切って進めやすいのが特徴です。

:::warning 無料と有料の範囲を確認する
公式の学習サイトでも、すべてのコンテンツが無料とは限りません。AWSのように、無料のデジタルコースとは別に、ラボなどをサブスクリプションで提供している場合もあります。また、クラウドのサービスを実際に操作すると、利用料金が発生することがあります。登録する前に、無料で使える範囲を公式ページで確認しましょう。
:::

## インフラの独学で学ぶ順番

:::steps インフラエンジニアの独学の進め方
1. **Linuxの基本操作を学ぶ**：練習環境を作り、コマンドやファイル、権限の扱いに慣れます。
2. **ネットワークの基礎を学ぶ**：IPアドレスやルーティングなど、通信の仕組みを理解します。
3. **サーバーを動かしてみる**：Linux上でWebサーバーなどを動かし、ネットワーク越しにアクセスしてみます。
4. **クラウドの基礎を学ぶ**：AWSやAzureの無料トレーニングで、クラウドの考え方とサービスの種類を知ります。
5. **資格や作品で区切りを作る**：LinuCやLPIC、CCNA、クラウドの資格などを、学習の区切りとして使います。
:::

**一つの分野で「できること」が増えてから次に進む**と、学んだ内容がつながりやすくなります。たとえば、Linuxでサーバーを動かせるようになってからネットワークを学ぶと、通信の仕組みを実際の操作と結びつけて理解できます。

## 学習サイトを選ぶときの確認点

:::check 独学サイトを選ぶときのチェックリスト
- 提供元が、資格の実施団体や製品の提供元など、信頼できる組織か
- 無料で使える範囲と、有料になる範囲がはっきりしているか
- 日本語で学べるか、英語の教材が中心か
- 読むだけでなく、手を動かす演習やラボがあるか
- 内容が更新されていて、現在の製品や試験に合っているか
:::

個人のブログやまとめサイトも参考になりますが、**情報が古くなっていることもある**ため、最終的には公式の教材やドキュメントで確認する習慣をつけましょう。インフラの技術は更新が多く、少し前の手順がそのまま使えないこともあります。

## 無料サイトだけで足りないときの補い方

無料の公式教材は質が高い一方で、一人で進めるとつまずきやすい点もあります。

:::merit 無料の公式教材の良さ
- 費用をかけずに、提供元の正確な情報で学べる
- 資格の出題範囲や製品の仕組みに沿って学びやすい
- 自分のペースで、短い時間から始められる
:::

:::demerit 無料の公式教材だけで進めるときの注意点
- 分野ごとにサイトが分かれていて、全体の順番は自分で決める必要がある
- 英語の教材が含まれることがある
- 分からないところを質問できる相手がいない
:::

分野をまたいで体系的に学びたい人や、画面の操作を見ながら進めたい人は、{{aff:learning-online-course|オンライン動画講座}}で、Linuxやネットワーク、クラウドの入門講座を一つ選び、無料の公式教材と組み合わせる方法があります。

{{aff:learning-online-course}}

仕組みを文章で順を追って理解したい人は、{{aff:learning-books|インフラやネットワークの入門書}}を一冊決めて、全体の地図として使うと、サイトをまたいで学ぶときも迷いにくくなります。

編集部としては、**独学サイトは「分野ごとに一つ」に絞り、Linuxから順番に進める**ことをおすすめします。サイトをたくさんブックマークするより、一つの教材を最後までやり切るほうが、インフラの基礎は確実に身についていくからです。

独学で基礎が身についてきたら、インフラエンジニアの求人を見て、求められているスキルを確認してみましょう。求人の探し方と見極め方は {{link:infra-engineer-mikeiken-tenshoku-kyujin|インフラエンジニア未経験転職｜求人の探し方と求人票の見極め方}} で解説しています。

## 迷ったときの次の一歩

迷ったら、まずはLPI-Japanの「Linux標準教科書」を開き、練習環境づくりの章を試してみてください。Linuxが動いてコマンドを打てたら、インフラの独学の一歩目は踏み出せています。そのあとで、ネットワークやクラウドの教材に少しずつ広げていきましょう。

学習サイトや講座は、自分に合わなければ見送って構いません。無料の教材から始めて、自分のペースで続けられる方法を選んでください。

## よくある質問

### インフラエンジニアの独学におすすめのサイトは？

分野ごとに、公式の無料教材から選ぶのが確実です。LinuxならLPI-Japanの「Linux標準教科書」やLPIの「LPI Learning」、クラウドならAWSの無料デジタルコースやMicrosoft Learnがあります。ネットワークは、Ciscoの公式ページで学習方法やシミュレーターが案内されています。

### インフラエンジニアは独学で何から始めればいい？

まずはLinuxの基本操作から始めるのがおすすめです。そのあと、ネットワークの基礎、サーバーの構築、クラウドの基礎へと順に広げると、学んだ内容がつながりやすくなります。

### インフラの勉強は無料サイトだけでできる？

基礎は無料の公式教材で学べます。ただし、サイトごとに分野が分かれていて全体の順番は自分で決める必要があり、ラボなどが有料のサービスもあります。足りない部分は、入門書や動画講座で補いましょう。

### クラウドの勉強をするとお金はかかる？

無料のトレーニングで学ぶだけなら費用はかかりませんが、クラウドのサービスを実際に操作すると利用料金が発生することがあります。AWSでも、ラボなどはサブスクリプションで提供されていると案内されています。始める前に、無料で使える範囲を公式ページで確認しましょう。
