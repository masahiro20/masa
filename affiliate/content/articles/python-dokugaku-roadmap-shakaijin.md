仕事が終わってから少しずつPythonを学ぼうと決めたものの、何をどの順番で進めればいいのか、全体の道筋が見えずに手が止まっている。そんな場面を想定して書きました。働きながらの独学は時間が限られるので、遠回りしたくないと感じるのは当然です。

社会人がPythonを独学するなら、**「目的を決める」→「環境を準備する」→「文法の基礎を学ぶ」→「小さな自動化を作る」→「目的の分野を学ぶ」→「作品や資格で力を確かめる」**の6つの段階で進めるのが、迷いにくいロードマップです。

大切なのは、**各段階で「ここまでできたら次へ進む」というゴールを決めておく**ことです。期間で区切るより、できることで区切るほうが、忙しい時期があっても計画を立て直しやすくなります。

## Python独学ロードマップの全体像

まずは全体の流れを一覧で確認しておきましょう。

| 段階 | やること | 次へ進む目安 |
| --- | --- | --- |
| 1. 目的を決める | Pythonで何をしたいかを一つ決める | 「毎週の集計を自動化したい」など一文で言える |
| 2. 環境を準備する | Pythonを動かせる状態にする | 簡単なコードを書いて実行できる |
| 3. 文法の基礎を学ぶ | 変数、条件分岐、繰り返し、関数、データ構造など | 教材の例を見ずに、短いプログラムを書ける |
| 4. 小さな自動化を作る | 身近な作業を自動化するプログラムを作る | 自分の作業で一度使える |
| 5. 目的の分野を学ぶ | 自動化・データ分析・Webなど、目的に合う分野を学ぶ | 分野の基本的なライブラリを使える |
| 6. 力を確かめる | 作品づくりや資格試験で理解を確認する | 作ったものを人に説明できる |

表の「次へ進む目安」は、あくまで編集部が考える目安です。**完璧に理解してから進む必要はなく、だいたいできたら次へ進み、分からなくなったら戻る**くらいの気持ちで大丈夫です。

## 段階1：目的を決める

最初に、Pythonで何をしたいかを一つ決めます。仕事で繰り返している作業の自動化、データの集計や分析、Webアプリづくりなど、目的によってその後の学ぶ範囲が変わるからです。

社会人の場合は、**今の仕事の中から題材を探す**のがおすすめです。「毎週の集計作業を短くしたい」のように具体的な目的があると、学ぶ理由がはっきりし、忙しくても続けやすくなります。

## 段階2：環境を準備する

次に、Pythonを動かせる環境を用意します。Pythonの公式ドキュメントのチュートリアルによると、Python Webサイトでは、Pythonインタープリタと標準ライブラリのソースコードや、主要プラットフォーム向けのコンパイル済みのバイナリファイルが無料で配布されています。

インストールでつまずきそうなときは、ブラウザ上でPythonを動かせるサービスから始める方法もあります。無料で始める方法は {{link:python-dokugaku-muryo|Pythonは独学で無料で学べる？}} で整理しています。

:::warning 環境構築で長く止まらない
環境構築は、初心者がつまずきやすいところです。ここで何日も止まってしまうと、肝心の文法に進めず、やる気がなくなってしまいます。うまくいかないときは、いったんブラウザで動かせる環境を使い、文法の学習を先に進めましょう。
:::

## 段階3：文法の基礎を学ぶ

文法の基礎として学ぶ範囲に迷ったら、資格試験の出題範囲が参考になります。一般社団法人Pythonエンジニア育成推進協会の「Python 3 エンジニア認定基礎試験」は、文法基礎を問う試験で、主教材であるオライリー・ジャパン「Pythonチュートリアル」の掲載内容が出題範囲とされています。章ごとの出題数を見ると、制御構造ツール（9問）、データ構造（7問）、気楽な入門編（6問）の順に多くなっています。

:::point 文法の基礎で押さえたい範囲
- 変数と、数値・文字列などの基本的なデータ
- 条件分岐（if文）と繰り返し（for文など）
- 関数の定義と呼び出し
- リスト・辞書などのデータ構造
- エラーと例外の扱い
:::

なお、公式ドキュメントのチュートリアルは、**Python言語を初めて使うプログラマー向けで、プログラミングが初めての初心者向けではない**と明記されています。同協会も、プログラミング未経験者がいきなり主教材を読むとつまずくことがあるとして、入門向けの参考図書を先に読むことを勧めています。未経験の人は、まず入門書や動画講座で基礎を学びましょう。本の選び方は {{link:python-dokugaku-osusume-hon|Python独学のおすすめ本の選び方}} で解説しています。

## 段階4：小さな自動化を作る

文法の基礎を一通り学んだら、身近な作業を自動化する小さなプログラムを作ってみましょう。フォルダ内のファイル名をそろえる、テキストファイルから必要な行だけを取り出す、といった小さなもので十分です。

この段階は、**「学んだ文法を、自分の課題に当てはめて使う」練習**です。教材の例をなぞるだけでは身につきにくい「どう組み立てるか」を考える力が、ここで少しずつ育っていきます。うまく動かなくても、エラーを調べて直す経験そのものが、次の段階で役立ちます。

## 段階5：目的の分野を学ぶ

小さな自動化ができるようになったら、段階1で決めた目的に合わせて、分野ごとの学習に進みます。

| 目的 | 学ぶ内容の例 |
| --- | --- |
| 業務の自動化 | ファイル操作、表計算ソフトやメールを扱うライブラリ |
| データ分析 | データ処理や可視化のライブラリ、統計の基本 |
| Webアプリ | Webフレームワーク、データベース、HTMLの基本 |

分野ごとの学習は、文法の基礎より情報量が多くなります。**目的に必要な部分から学び、使いながら広げていく**ほうが、働きながらでも続けやすいはずです。

## 段階6：作品や資格で力を確かめる

最後に、学んだ力を確かめる段階です。作ったプログラムを整理して、何のために作り、どう工夫したかを説明できるようにしておきましょう。

文法の理解度を確かめたい場合は、資格試験を目標にする方法もあります。同協会によると、Python 3 エンジニア認定基礎試験は、問題数40問（すべて選択問題）、試験時間60分、合格ラインは正答率70%とされています。ただし、**資格の合格だけをゴールにせず、実際に使えるプログラムを作れるかを大切にする**ことをおすすめします。

## ロードマップの途中でよくある迷い

段階を進めていくと、多くの人が同じような迷いにぶつかります。ここで迷う方は多いので、あらかじめ考え方を知っておくと安心です。

### 文法を全部覚えてから次に進むべき？

全部を覚える必要はありません。よく使う文法は、プログラムを作る中で何度も出てくるので、自然と身についていきます。**忘れたら調べればよい、くらいの気持ちで段階4に進む**ほうが、結果として理解が深まることも多いです。

### 目的が途中で変わってもいい？

学んでいくうちに、最初に決めた目的とは別の分野に興味がわくこともあります。それは自然なことです。段階3までの文法の基礎はどの分野でも共通なので、目的を変える場合は段階5から選び直せば大丈夫です。

### 仕事が忙しくて何週間も空いてしまったら？

しばらく空いたあとは、一つ前の段階の内容を軽く見直してから再開すると、スムーズに戻れます。記録を残しておけば、どこまで進んでいたかもすぐに思い出せます。

## 働きながら続けるための進め方

:::steps 社会人が続けるための工夫
1. **段階ごとのゴールを書き出す**：ロードマップの各段階で「できたら次へ」の目安をメモしておきます。
2. **平日は短く触れる**：短い時間でも、前回のコードを読み返すなど、毎日少しでも触れるようにします。
3. **休日は作る時間にあてる**：まとまった時間が必要な、プログラムづくりは休日に進めます。
4. **進み具合を記録する**：学習した日と内容を記録し、計画を見直す材料にします。
5. **止まったら一つ前の段階に戻る**：分からなくなったら、無理に進めず前の段階を復習します。
:::

働きながらの独学は、計画どおりに進まない時期が必ずあります。そんなときも、**ロードマップのどこにいるかが分かっていれば、焦らずに再開できます**。独学にかかる時間の見積もり方は {{link:python-dokugaku-nanjikan|Python独学は何時間かかる？}} で整理しています。

## 独学で行き詰まったときの選択肢

:::merit 独学のメリット
- 費用を抑えて、自分のペースで進められる
- 仕事の課題に合わせて、学ぶ内容を選べる
- 調べて解決する力が身につく
:::

:::demerit 独学のデメリット
- 分からないところで長く止まりやすい
- 自分の書き方が正しいか判断しにくい
- 一人だとモチベーションを保ちにくい
:::

同じところで何度もつまずく場合は、教材を変えるのも一つの方法です。画面を見ながら手を動かしたい人は、{{aff:learning-online-course|オンライン動画講座}}で、段階3の文法から順に扱う講座を選ぶと、ロードマップに沿って進めやすくなります。文章で体系的に学びたい人は、{{aff:learning-books|Pythonの入門書}}を一冊決めて最後まで進めましょう。

## 迷ったときの次の一歩

全体像が見えても、どこから手をつけるか迷うかもしれません。そんなときは、今週中に段階1の「目的」を一文で書き出すことだけを目標にしてみてください。目的が決まると、段階2以降で選ぶ教材や題材が自然に絞られていきます。

動画講座や本は、段階3で必要だと感じたら選べば十分です。内容が自分に合わなければ、見送って構いません。自分の仕事と生活のペースに合わせて、一段ずつ進めていきましょう。

## よくある質問

### 社会人がPythonを独学するロードマップは？

目的を決める、環境を準備する、文法の基礎を学ぶ、小さな自動化を作る、目的の分野を学ぶ、作品や資格で力を確かめる、の6段階で進めるのがおすすめです。各段階で「できたら次へ」の目安を決めておくと、迷いにくくなります。

### 働きながらPythonを独学するコツは？

平日は短い時間でも毎日触れ、休日にまとまった時間でプログラムを作るなど、メリハリをつけると続けやすくなります。今の仕事の中から題材を選ぶと、学ぶ目的がはっきりします。

### Pythonの独学で資格は取ったほうがいい？

必須ではありませんが、文法の理解度を確かめる目標として役立ちます。Python 3 エンジニア認定基礎試験は文法基礎を問う試験で、出題範囲も公開されています。合格だけでなく、実際に使えるプログラムを作れるかを大切にしましょう。

### Pythonの独学が難しいときはスクールを使うべき？

同じところで何度もつまずく、質問できる相手がほしい、といった場合は、動画講座やスクールを検討するのも一つの方法です。まずは教材を変える、段階を一つ戻って復習するなどを試し、それでも進めない場合に検討すると、費用を無駄にしにくくなります。
