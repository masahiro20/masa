WordPressでブログを始める流れは、大きく「サーバーを借りる → 独自ドメインを取る → サーバーとドメインをつなぐ → WordPressをインストールする → SSL化と初期設定をする」の5段階です。

最近はレンタルサーバー各社が、ドメイン取得からWordPressのインストールまでをまとめて済ませる申し込み方法を用意していることが多く、**初めてなら「まとめて設定できる手順」を選ぶのが最もつまずきにくい**選択です。

一方で、サーバー選びの基準や公開前のセキュリティ設定は自動化されない部分です。この記事では、手順そのものに加えて「どこで判断が必要か」「どこで失敗しやすいか」を順番に整理します。

:::summary
- WordPressブログ開設の全体像と、作業の正しい順番
- レンタルサーバーを選ぶときに確認したい公式の推奨動作環境
- 独自ドメインの種類の違いと、個人情報を守るWhois公開代行の考え方
- 公開前にやっておきたいSSL化・更新・バックアップなどの初期設定
:::

## WordPressブログの全体像：必要なのは「サーバー」と「ドメイン」

まず混同しやすいのが、WordPressには2種類あるという点です。WordPress.org日本語版の解説によると、WordPress.orgは「個人や企業が所有していない無料のオープンソースのWebパブリッシングソフトウェアプロジェクト」で、自分でサーバーに設置して使うものです。一方のWordPress.comは、Automattic社が運営するホスト型のブログサービスです。

「ブログ 始め方 WordPress」で検索して出てくる多くの解説は、前者の**自分でサーバーを借りて設置するWordPress（セルフホスト型）**を指しています。この記事もこちらを前提に進めます。

セルフホスト型で必要になるものは次の3つです。

| 必要なもの | 役割 | たとえると |
|---|---|---|
| レンタルサーバー | ブログのファイルやデータを置いておく場所 | 土地・建物 |
| 独自ドメイン | ブログのURL（example.jpなど） | 住所 |
| WordPress本体 | 記事を書き、デザインを整えるソフト | 家具・内装 |

WordPress本体は無料ですが、サーバーとドメインには費用がかかります。料金はサービスや契約期間、キャンペーンで変わるため、申し込み時に各社の公式サイトで最新の金額と、**2年目以降の更新料金**まで確認してください。

### 無料ブログやWordPress.comとの違い

セルフホスト型の利点は、テーマ（デザイン）やプラグイン（機能追加）を自由に選べ、広告の掲載やサイトの引っ越しも自分の判断でできる点です。反対に、サーバーの管理や更新、セキュリティ対策も自分の責任になります。

「まず書く習慣をつけたい」「費用をかけずに試したい」段階なら、無料のブログサービスから始めるのも十分に合理的です。収益化やポートフォリオとしての利用、Web制作の練習を見据えるなら、セルフホスト型のWordPressを選ぶ意味が大きくなります。

## 手順の全体と作業の順番

作業の順番を先に押さえておくと、途中で迷いにくくなります。

:::steps WordPressブログ開設の5ステップ
1. **レンタルサーバーを契約する**：WordPressの推奨動作環境を満たすプランを選ぶ。
2. **独自ドメインを取得する**：サーバー会社の同時取得か、ドメイン取得サービスで取る。
3. **ドメインとサーバーをつなぐ**：ネームサーバー（DNS）の設定と、サーバー側へのドメイン追加。
4. **WordPressをインストールする**：サーバーの管理画面にある簡単インストール機能を使うのが一般的。
5. **SSL化と初期設定をする**：https化、パーマリンク、更新・バックアップ・パスワードの設定。
:::

最近の多くのレンタルサーバーでは、1〜4（場合によっては5のSSL化まで）を申し込みフォームの中でまとめて行える仕組みが用意されています。サービスによって名称や対応範囲が違うため、申し込み前に公式サイトで「ドメイン取得」「WordPressインストール」「SSL設定」まで含まれるかを確認しましょう。

## ステップ1：レンタルサーバーを選んで契約する

レンタルサーバー選びでまず確認したいのは、WordPressを快適かつ安全に動かせる環境かどうかです。

2026年9月時点のWordPress.org日本語版「必須要件」ページでは、推奨する動作環境として次の3点が挙げられています。

- PHP バージョン8.3以上
- MariaDB 10.11以上、またはMySQL 8.0以上
- HTTPS（すべてのインストールに必須とされています）

ページではこれらを、パフォーマンスとセキュリティにおける安全で現代的な基準として示しています。国内の主要なレンタルサーバーの多くはこうした環境に対応していますが、プランや提供時期によって選べるバージョンが違う場合があるため、**契約前に仕様表でPHPとデータベースのバージョンを確認**しておくと安心です。

:::check レンタルサーバー比較時のチェックリスト
- PHP・MySQL（MariaDB）のバージョンがWordPressの推奨環境を満たしているか
- 無料の独自SSLに対応しているか
- WordPressの簡単インストール機能があるか
- 自動バックアップと、復元の方法・費用はどうなっているか
- 初回料金だけでなく、更新時の料金はいくらか
- 最低契約期間と、途中解約時の返金の扱い
- サポートの窓口（メール・チャット・電話）と対応時間
:::

### 契約期間と料金の見方

レンタルサーバーは、契約期間が長いほど月あたりの料金が下がる料金体系が多く見られます。ただし長期契約は、ブログを続けられなかった場合に使わない期間分の費用が発生しやすくなります。

初めてで続くか分からない場合は、長期割引の大きさだけで決めず、途中解約や返金の条件まで読んだうえで期間を選んでください。「ドメイン永久無料」のような特典も、サーバー契約の継続が条件になっているケースがあるため、適用条件は申し込み画面で確認が必要です。

## ステップ2：独自ドメインを取得する

ドメインはブログの住所になるもので、一度決めると後から変えるのが大変です。変更するとURLが変わり、それまでの検索評価や外部からのリンクを引き継ぐための作業が必要になるためです。

### ドメインの種類をどう選ぶか

ドメインの末尾（.com や .jp など）には種類があり、登録できる人の条件が違います。JPRSの「種類と対象」ページによると、主なJPドメインの条件は次のとおりです。

| 種類 | 例 | 登録できる者（JPRSの説明より） | 登録数 |
|---|---|---|---|
| 汎用JPドメイン | example.jp | 日本国内に住所を持つ個人・団体・組織 | 制限なし |
| 都道府県型JPドメイン | example.tokyo.jp など | 日本国内に住所を持つ個人・団体・組織 | 制限なし |
| 属性型JPドメイン（CO.JP） | example.co.jp | 日本国内で登記している会社など | 1組織1つが原則 |

個人ブログであれば、汎用JPドメイン（.jp）か、.com・.net などのgTLDから選ぶのが一般的です。CO.JPは登記した会社などが対象のため、個人では原則として取得できません。

名前を決めるときは、短く覚えやすいこと、ブログのテーマが変わっても使い続けられることを意識すると、後悔しにくくなります。

### 個人情報の公開に注意する

ドメインを登録すると、登録者の情報がWhois（ドメイン登録情報の検索サービス）で公開される仕組みがあります。個人で登録する場合、名前や住所がそのまま公開されるのは避けたいところです。

そのため、多くのドメイン取得サービスには「Whois情報公開代行」の仕組みがあります。たとえばJPRSのプロキシサービスでは、gTLDドメイン名の登録者名・住所・電話番号・メールアドレスなどの代わりに、JPRSの情報を公開すると説明されています。

:::warning ドメイン取得で多い失敗
- Whois情報公開代行を設定せず、個人の住所や氏名が公開されてしまう
- 初年度の安さだけで末尾を選び、更新料金が想定より高くなる
- 自動更新を切ったまま更新期限を過ぎ、ドメインが失効する
- 登録メールアドレスを普段見ないアドレスにして、重要な通知を見落とす
:::

公開代行を利用できるドメインの種類や、取得後に設定できるかどうかはサービスごとに違います。取得前に確認しておきましょう。

## ステップ3・4：ドメインとサーバーをつなぎ、WordPressを入れる

サーバーとドメインを別々の会社で契約した場合は、2つを結び付ける設定が必要です。

- **ドメイン側**：ネームサーバー（DNS）を、契約したレンタルサーバーが指定するものに変更する
- **サーバー側**：管理画面で、取得したドメインを「ドメイン追加」する

ネームサーバーの変更は、反映されるまでに時間がかかることがあります。反映前にWordPressを入れようとしてエラーになるのはよくあるつまずきなので、表示されなくても慌てず、しばらく待ってから確認しましょう。

同じ会社でサーバーとドメインをまとめて申し込んだ場合は、この設定が自動で済むことが多く、手間を減らせます。**管理画面とログイン情報が1か所にまとまる**ため、初心者には管理面でもメリットがあります。

WordPressのインストールは、サーバーの管理画面にある簡単インストール機能を使うのが一般的です。ブログ名、管理者のユーザー名、パスワード、メールアドレスを入力すれば完了します。

:::merit サーバーとドメインを同じ会社でまとめる
- DNSの設定がほぼ不要で、つまずきにくい
- 請求や更新の管理が1か所で済む
- セット特典が用意されていることがある
:::

:::demerit まとめる場合の注意点
- サーバーを乗り換えるとき、ドメインの管理移管も検討が必要になる
- 特典の適用に、サーバー契約の継続が条件になっていることがある
- ドメインの料金をほかのサービスと比べにくい
:::

## ステップ5：SSL化と公開前の初期設定

WordPressが表示されたら、記事を書く前に済ませておきたい設定があります。

### SSL化（https化）

前述のとおり、WordPress.orgの必須要件ページではHTTPSがすべてのインストールで必須とされています。https化すると、閲覧者とサイトの間の通信が暗号化されます。

多くのレンタルサーバーは、Let's Encryptなどの無料SSL証明書に対応しています。Let's Encryptの公式サイトによると、同団体は非営利団体ISRGが運営する「フリーで自動化されたオープンな認証局」で、ドメインを持っていれば誰でも費用なしで証明書を取得できると説明されています。

サーバー側でSSLを有効にしたあと、WordPressの「設定」→「一般」にあるWordPressアドレスとサイトアドレスが https になっているかも確認しましょう。

### セキュリティの基本設定

WordPress.org日本語版の「WordPressの安全性を高める」では、主に次の対策が挙げられています。

- WordPressを常に最新バージョンに更新する（自動アップデートの活用）
- WordPressのインストール全体を含めて定期的にバックアップし、信頼できる場所に保管する
- 辞書にある単語や個人情報を避けた、強力なパスワードを使う

WordPressは利用者が多い分、古いバージョンや更新されていないプラグインが狙われやすい面があります。**本体・テーマ・プラグインの更新とバックアップ**は、公開前に仕組みを決めておくことをおすすめします。

:::point 公開前に最低限やっておきたいこと
- https で表示されることを確認する
- 管理者パスワードを推測されにくいものにする
- 更新とバックアップの方法を決めておく
- パーマリンク（URLの形式）を決める（公開後の変更は影響が大きい）
- 使っていないテーマ・プラグインを削除する
:::

### パーマリンクとテーマ

パーマリンクは記事ごとのURLの形式です。公開後に変えると既存記事のURLが変わるため、記事を書き始める前に決めておきましょう。

テーマは無料のものでも十分にブログを始められます。有料テーマを検討するのは、書き続けられると分かってからでも遅くありません。WordPressの仕組みを体系的に学びたい場合は、{{aff:learning-books|WordPressの入門書を探す}}のもひとつの方法です。

## WordPressブログが向いている人・向いていない人

最後に、セルフホスト型のWordPressが合うかどうかを整理します。

| 向いている人 | 向いていない人 |
|---|---|
| 収益化やポートフォリオとして長く育てたい | まずは費用ゼロで書く習慣だけ試したい |
| デザインや機能を自分で調整したい | 更新やバックアップの管理をしたくない |
| Web制作やサイト運営の練習もしたい | 数か月で終える短期の発信だけが目的 |

WordPressの運営は、サーバー・ドメイン・DNS・HTMLやCSSなど、Web制作の基礎に触れる機会にもなります。ブログを足がかりにWeb制作やエンジニアの仕事を本格的に目指したくなった場合は、{{link:programming-school-choice-for-workers|社会人向けプログラミングスクールの選び方}}も参考にしてください。

また、WordPressでの構築経験を副業や独立に生かしたい人は、{{link:freelance-engineer-how-to-get-projects|フリーランスの案件獲得方法の比較}}で、経験が浅い段階での実績の作り方を確認しておくと見通しが立ちやすくなります。

## よくある質問

### サーバーとドメインは同じ会社で契約したほうがいいですか？

初めてなら、同じ会社でまとめると設定の手間が少なく、つまずきにくくなります。一方で、将来サーバーを乗り換える可能性がある人や、ドメインを複数まとめて管理したい人は、ドメインを別のサービスで管理する方法もあります。どちらが正解というより、管理のしやすさで選ぶとよいでしょう。

### 独自ドメインなしでもWordPressブログは始められますか？

サーバーによっては初期ドメイン（サーバー会社のサブドメイン）で動かすことも可能です。ただし、後から独自ドメインに移すとURLが変わり、移行作業が必要になります。長く続けるつもりなら、最初から独自ドメインで始めるほうが手戻りが少なくなります。

### 個人でもドメインを取得できますか？住所は公開されますか？

JPRSの説明では、汎用JPドメイン（.jp）は日本国内に住所を持つ個人でも登録できます。.comなどのgTLDも個人で取得可能です。登録情報はWhoisで公開される仕組みがあるため、個人の場合はWhois情報公開代行を利用できるかを取得前に確認してください。

### SSL化に費用はかかりますか？

Let's Encryptのような無料の証明書を利用できるサーバーであれば、証明書そのものの費用はかかりません。多くのレンタルサーバーが無料SSLに対応していますが、対応状況や設定方法はサービスごとに違うため、契約前に確認しましょう。

### 作業にはどれくらい時間がかかりますか？

まとめて申し込める仕組みを使えば、申し込みからWordPressの管理画面に入るまでの作業自体は比較的短時間で済むことが多いです。ただし、ドメインやSSLの設定の反映に時間がかかる場合があるため、公開までは余裕を持ったスケジュールにしておくと安心です。
