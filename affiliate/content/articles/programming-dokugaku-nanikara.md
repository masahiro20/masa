プログラミングを独学で何から始めるか迷ったら、**最初にやるべきことは言語選びではなく「何を作りたいか」を決めること**です。目的が決まれば、学ぶ言語と教材は自然に絞れます。目的がまだ曖昧なら、結果が画面ですぐ見えるHTML/CSSから始めるのが取り組みやすい選択肢です。

そのうえで、**「入門教材を1つ決めて最後まで進める → 小さな作品を作る → 分からないことを調べて直す」**の繰り返しが、独学の基本の流れです。教材をあれこれ乗り換えるより、1つをやり切るほうが早く身につきます。

:::summary この記事で分かること
- 独学で最初に決めるべきこと（目的と作りたいもの）
- 目的別に最初に学ぶ言語の選び方
- 無料サイト・本・動画講座の使い分け
- 挫折しにくい独学ロードマップと、独学が向かない人の判断基準
:::

## プログラミング独学は何から始める？まず「目的」を決める

独学で挫折しやすい原因の一つが、「とりあえず人気の言語から」と始めて、何のために学んでいるのか分からなくなることです。最初に、次のどれに近いかを考えてみましょう。

| 目的 | 最初に学ぶ候補 | 最初の作品の例 |
| --- | --- | --- |
| Webサイトを作りたい・Web制作の副業をしたい | HTML/CSS → JavaScript | 自己紹介ページ |
| 仕事の作業を自動化したい | Python | ファイル整理やデータ集計の小さなスクリプト |
| エンジニアに転職したい | HTML/CSS・JavaScript、またはPython | 自分で考えた小さなWebアプリ |
| まだ決まっていない・とりあえず試したい | HTML/CSS | 好きなテーマの1ページ |

**目的が決まらないうちは、HTML/CSSで「書いたものがすぐ画面に表示される」体験をする**のがおすすめです。ブラウザとテキストエディタがあれば始められ、成果が目に見えるので続けやすくなります。

:::point 最初に決める3つのこと
- 何を作りたいか（Webページ、自動化ツール、アプリなど）
- 最初の3か月で作りたい作品を1つ
- 1週間に学習に使える時間（平日・休日それぞれ）
:::

## 独学の教材は何から選ぶ？無料サイト・本・動画講座の違い

独学の教材は大きく分けて、無料の学習サイト・公式ドキュメント、本、動画講座の3種類があります。

| 教材 | 向いている人 | 注意点 |
| --- | --- | --- |
| 無料サイト・公式ドキュメント | 費用をかけずに始めたい人、自分で調べながら進められる人 | 対象者や前提知識がページごとに違う |
| 本 | 順番に体系立てて学びたい人 | 内容が古くなっていないか、発行年を確認 |
| 動画講座 | 手元の画面を見ながら真似して進めたい人 | 見るだけで終わらず、手を動かす必要がある |

### 無料サイト・公式ドキュメント

Web開発なら、MDN Web Docsの「ウェブ開発の学習」が、新人フロントエンド開発者に必要な基本スキルを学べる構造化されたチュートリアルとして公開されています。MDN自身が、学習者を「初心者」から「慣れ親しむ」ところまで導き、より高度な資料を使えるだけの知識を提供するものだと説明しています。

一方で、公式ドキュメントがすべて初心者向けとは限りません。たとえばPythonの公式チュートリアルは、冒頭で**「Python言語を初めて使うプログラマー向けに設計されており、プログラミングが初めての初心者向けではない」**と明記しています。プログラミング自体が初めての人は、入門書や動画講座で基礎を押さえてから公式チュートリアルに進むほうがスムーズです。

また、経済産業省とIPA（情報処理推進機構）が運営する「マナビDX」では、デジタルリテラシーから実践レベルまでの講座を探せて、受講料無料の講座も掲載されています。

### 本

本は、学ぶ順番が整理されていて、全体像をつかみやすいのが利点です。初心者は、図解が多く、サンプルを動かしながら進める入門書を1冊選びましょう。発行年が古いと、ツールの画面や手順が変わっていることがあるため注意が必要です。{{aff:learning-books|プログラミングの入門書・参考書}}を探すときは、対象レベルと発行年を確認してから選んでください。

### 動画講座

動画講座は、講師の画面を見ながら同じ操作を真似できるため、環境構築などで手が止まりやすい初心者に向いています。買い切り型の講座なら、月額料金を気にせず自分のペースで進められます。{{aff:learning-online-course|初心者向けのオンライン動画講座}}は、本で理解しにくかった部分を補う使い方もできます。

## 挫折しにくい独学ロードマップ

教材を決めたら、次の流れで進めましょう。

:::steps 独学の5ステップ
1. **環境を準備する**：テキストエディタとブラウザ（Pythonならインストールも）を用意し、最初のコードを動かします。
2. **入門教材を1つ最後まで進める**：教材は1つに絞り、サンプルを自分の手で打ち込みながら進めます。
3. **小さな作品を作る**：教材の内容を使って、自分で考えた小さな作品を1つ作ります。
4. **調べて直す**：エラーや分からないことを、公式ドキュメントや検索で調べて解決します。
5. **作品を少しずつ大きくする**：機能を追加したり、別の作品を作ったりして、できることを増やします。
:::

**最も大事なのはステップ3**です。教材のサンプルを写すだけでは、「分かったつもり」で止まりがちです。小さくても、自分で考えたものを作る過程で、本当に理解していない部分が見えてきます。

## 目的別：最初の3か月の進め方の例

目的によって、最初の数か月で目指す到達点は変わります。あくまで一例ですが、次のように「作るもの」から逆算すると、学ぶ範囲を絞りやすくなります。

### Webサイトを作りたい人

最初はHTMLでページの構造を、CSSで見た目を整える方法を学びます。自己紹介ページを1枚作れたら、スマートフォンでも見やすくする工夫や、JavaScriptでボタンを押したときの動きを加えてみましょう。MDNの学習コースのように、HTML、CSS、JavaScriptを順番に学べる教材を1つ選ぶと迷いにくくなります。

### 仕事の作業を自動化したい人

Pythonの基本（変数、条件分岐、繰り返し、関数）を押さえたら、身の回りの小さな作業を題材にします。たとえば「フォルダ内のファイル名を一括で変える」「表のデータを集計する」などです。業務のデータを使う場合は、勤務先のルールを確認してから試しましょう。

### エンジニアへの転職を考えている人

基礎を学んだあと、自分で考えた小さなWebアプリを作るところまで進めるのが目安です。転職では作品が評価の材料になるため、作るものの目的や工夫した点を説明できるようにしておきましょう。

## 学習時間を確保して習慣にするコツ

独学では、学習時間を自分で確保しなければなりません。社会人の場合、まとまった時間を取ろうとすると、忙しい週に学習が途切れがちです。

- **短くても毎日触る**：平日は短い時間でもよいので、毎日コードに触れる時間を作る
- **やることを前日に決める**：「明日は教材の第3章を進める」のように、次の作業を決めてから終える
- **記録を残す**：学んだことやエラーの解決方法をメモしておくと、後で見返せる

学習の記録は、続けられているかを振り返る材料にもなります。

## 独学でつまずきやすいポイント

独学では、次のような場面で手が止まりやすくなります。

:::warning 独学でよくある失敗
- 教材を次々に乗り換えて、どれも途中で終わる
- 環境構築（インストールや設定）でつまずき、そこで止まる
- エラーメッセージを読まずに、すぐ諦めてしまう
- 教材を写すだけで、自分で作る段階に進まない
- 学習時間を決めておらず、忙しい時期に習慣が途切れる
:::

エラーが出たら、まずエラーメッセージを最後まで読み、そのまま検索してみましょう。最近は、生成AIにエラーの意味を説明してもらう方法もあります。AIを使った学び方は {{link:ai-coding-shoshinsha-roadmap|AIコーディング初心者の学習ロードマップ}} で整理しています。

## 独学とスクール、どちらが向いている？

独学は費用を抑えられる一方で、学習の計画や問題の解決をすべて自分で行う必要があります。

:::merit 独学のメリット
- 費用を抑えられる（無料の教材だけでも始められる）
- 自分のペースで、好きな時間に学べる
- 調べて解決する力が身につく
:::

:::demerit 独学のデメリット
- 質問できる相手がおらず、つまずいたときに時間がかかる
- 学ぶ順番や到達点を自分で決める必要がある
- 転職を目指す場合、何をどこまで作ればよいか判断しにくい
:::

**「3か月独学してみて、学習が続いているか・作品が1つ作れたか」**を判断の目安にするのが現実的です。続いていればそのまま独学を進め、何度も同じところで止まるなら、質問できる環境を検討しましょう。動画講座とスクールの違いは {{link:online-course-vs-programming-school|オンライン講座とプログラミングスクールの違い}} で比較しています。

スクールが必要かどうかの判断は、{{link:programming-school-yametoke|プログラミングスクールはやめとけ？}} も参考になります。

## よくある質問

### プログラミング初心者は何から独学すればいい？

作りたいものが決まっていれば、それに合う言語から始めましょう。決まっていない場合は、書いた結果がすぐ画面に表示されるHTML/CSSから始めると、成果が見えて続けやすくなります。

### プログラミングは独学の無料サイトだけで学べる？

MDN Web Docsのような無料の学習資料や、マナビDXに掲載された受講料無料の講座など、無料で学べる教材はあります。ただし、資料によって対象者や前提知識が違うため、初心者向けかどうかを確認してから使いましょう。

### 独学におすすめの本の選び方は？

対象が「プログラミング初心者」と明記され、サンプルを動かしながら進める入門書を選ぶのがおすすめです。発行年が古いと手順が変わっていることがあるため、できるだけ新しい版を選びましょう。

### プログラミング独学で就職・転職はできる？

独学で学んで就職・転職する人もいますが、学んだことを示す作品（ポートフォリオ）が重要になります。どんな作品を作ればよいか分からない場合は、転職支援のある講座やスクールの無料カウンセリングで相談するのも一つの方法です。
