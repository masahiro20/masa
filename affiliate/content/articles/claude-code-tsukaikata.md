Claude Codeを使えば、AIと会話しながらコードを書いたり直したりできると聞いて、試してみたいと思った。ただ、ターミナルの操作に慣れていないし、何をインストールして、最初に何をすればいいのかが分からない。そんな場面を想定して書きました。新しい道具を使い始めるとき、最初の一歩でつまずくのはよくあることです。

Claude Codeの使い方は、公式ドキュメントのクイックスタートに沿って進めると分かりやすくなります。基本の流れは、**インストールする → プロジェクトのフォルダで起動してログインする → プロジェクトについて質問する → 小さなコード変更を頼む**の順です。

公式ドキュメントによると、Claude Codeは**コードベースを読み取り、ファイルを編集し、コマンドを実行し、開発ツールと統合するAIコーディングツール**で、ターミナル、IDE、デスクトップアプリ、ブラウザで利用できるとされています（2026年11月時点）。この記事では、クイックスタートで紹介されているターミナルでの使い方を中心に整理します。

:::summary この記事で分かること
- Claude Codeを始める前に必要なもの
- インストールとログインの方法
- 最初の質問とコード変更のやり方
- 安全に使うためのポイントと、学び方の選び方
:::

## 始める前に必要なもの

クイックスタートでは、始める前に次の3つを確認するよう案内されています。

:::check 始める前に確認すること（クイックスタートより）
- ターミナルまたはコマンドプロンプトが開いている
- 作業するコードのプロジェクトがある
- Claudeのサブスクリプション（Pro、Max、Ultra、Team、Enterprise）、Claude Consoleのアカウント、または対応するクラウドプロバイダー経由のアクセスがある
:::

**ターミナルを使ったことがない場合は、公式の「ターミナルガイド」から始める**よう案内されています。また、ターミナル以外にも、Web、デスクトップアプリ、VS CodeやJetBrainsのIDEなどで使えるとされています。利用に必要なプランの考え方は {{link:claude-code-ryokin|Claude Codeの料金は？}} で整理しています。

## インストールとログイン

:::steps インストールからログインまで（クイックスタートより）
1. **インストールする**：ターミナルを開き、公式ドキュメントに記載されているOSごとのインストールコマンドを実行します。
2. **インストールを確認する**：新しいターミナルを開いて `claude --version` を実行し、バージョン番号が表示されるかを確かめます。
3. **プロジェクトのフォルダに移動する**：作業したいプロジェクトのフォルダに移動します。
4. **Claude Codeを起動する**：`claude` と入力して起動します。
5. **ログインする**：初回はログインを求められるので、表示される指示に従ってブラウザで認証します。
:::

公式ドキュメントでは、インストール方法として**ネイティブインストール（推奨）のほか、HomebrewやWinGetなど**が紹介されています。ネイティブインストールはバックグラウンドで自動的に更新される一方、HomebrewやWinGetでのインストールは自動更新されないため、定期的にアップグレードのコマンドを実行するよう案内されています。

:::warning インストールのコマンドは公式ドキュメントからコピーする
インストールのコマンドは、必ず公式ドキュメントに記載されているものを使いましょう。検索で見つけた別のサイトのコマンドを実行すると、意図しないソフトが入るおそれがあります。`claude` が見つからないと表示される場合は、公式ドキュメントのPATHの設定方法を確認しましょう。
:::

## 最初の質問をする

起動すると、Claude Codeのプロンプトが表示されます。クイックスタートでは、まず**プロジェクトについて質問してみる**ことが勧められています。

:::point 最初に試せる質問の例（クイックスタートより）
- このプロジェクトは何をするものか
- このプロジェクトはどんな技術を使っているか
- メインの入り口（エントリーポイント）はどこか
- フォルダの構成を説明してほしい
:::

クイックスタートでは、**Claude Codeは必要に応じてプロジェクトのファイルを読み取るので、コンテキストを手動で追加する必要はない**と説明されています。また、`/help` で使えるコマンドの一覧、`/resume` で以前の会話の再開ができるとされています。

## 最初のコード変更を頼む

次は、小さなタスクを頼んでみます。クイックスタートでは、メインのファイルに簡単な関数を追加する例が紹介されています。

Claude Codeは**適切なファイルを見つけ、変更内容を表示**します。変更の前に確認を求められた場合は、内容を確かめてから承認します。

:::point 権限モードを理解しておく
クイックスタートでは、セッションの「権限モード」が、Claudeが事前に確認せずに実行できる操作を決めると説明されています。Shift+Tabで、いつでも権限モードを切り替えられるとされています。最初のうちは、変更のたびに内容を確認できる状態で使うと安心です。
:::

## Gitやバグ修正での使い方

クイックスタートでは、さらに次のような使い方が紹介されています。

| 使い方 | 頼み方の例（クイックスタートより） |
| --- | --- |
| Gitの操作 | 変更したファイルを確認する、分かりやすいメッセージでコミットする、新しいブランチを作る |
| バグの修正 | 空のフォームを送信できてしまうバグを直してほしい、と自然な言葉で説明する |
| 機能の追加 | 登録フォームに入力チェックを追加してほしい、と頼む |
| その他 | リファクタリング、テストの作成、ドキュメントの更新、変更内容のレビュー |

結局のところ、Claude Codeは**「やりたいことを言葉で説明すると、ファイルを探して変更案を出してくれる」**道具です。ただし、**最終的に変更を受け入れるかどうかを判断するのは自分**です。

## 安全に使うためのポイント

:::merit Claude Codeを使う良さ
- プロジェクトのファイルを読み取り、全体を理解したうえで作業してくれる
- 質問、コードの変更、Gitの操作、テストの作成など、幅広い作業を頼める
- ターミナルだけでなく、IDEやデスクトップアプリでも使える
:::

:::demerit 気をつけたいこと
- 変更内容は、自分で確認してから受け入れる必要がある
- 利用にはサブスクリプションなどの費用がかかる
- 仕事のコードで使う場合は、会社のルールで利用が認められているかを確認する必要がある
:::

**最初は、壊れても困らない練習用のプロジェクトで試す**のがおすすめです。慣れてきたら、Gitで変更を管理しながら、実際のプロジェクトに使っていきましょう。

## 初心者がつまずきやすいポイント

ここで迷う方は多いので、よくあるつまずきを整理しておきます。

### ターミナルの操作に慣れていない

フォルダの移動やコマンドの実行に慣れていない場合は、公式の「ターミナルガイド」で基本を確認してから始めましょう。デスクトップアプリやIDEの拡張機能から使う方法もあります。

### 何を頼めばいいか分からない

最初は、**「このプロジェクトを説明して」「この関数は何をしている？」**のような質問から始めると、Claude Codeの答え方に慣れることができます。

### 変更が多すぎて確認しきれない

一度に大きな作業を頼むと、変更の量が多くなり確認が大変になります。**小さな作業に分けて、一つずつ頼む**ようにしましょう。

## 迷ったときの次の一歩

迷ったら、まずは練習用のフォルダを一つ作り、その中で Claude Codeを起動して「このフォルダに簡単なメモ帳アプリを作って」と頼んでみてください。できあがったファイルを開いて、何が書かれているかを一つずつ確かめると、Claude Codeの動きがつかめてきます。

研修やスクールは、自分に合わなければ見送って構いません。公式ドキュメントで学びながら、少しずつ使い方を広げていく方法も含めて、自分に合ったやり方を選んでください。

## よくある質問

### Claude Codeの使い方は難しい？

公式のクイックスタートに沿えば、インストール、起動、ログイン、質問、コード変更の順に進められます。ターミナルに慣れていない場合は、公式のターミナルガイドから始めるか、デスクトップアプリやIDEの拡張機能から使う方法もあります。

### Claude Codeを使うには何が必要？

クイックスタートでは、ターミナル、作業するコードのプロジェクト、そしてClaudeのサブスクリプション（Pro、Max、Ultra、Team、Enterprise）やClaude Consoleのアカウントなどが必要とされています。

### Claude CodeはVS Codeでも使える？

公式ドキュメントでは、ターミナルのほか、VS CodeやJetBrainsのIDE、デスクトップアプリ、Webでも利用できると案内されています。自分が使い慣れた環境から始めると、操作に迷いにくくなります。

### Claude Codeが勝手にファイルを変更しないか心配

クイックスタートでは、セッションの権限モードが、Claudeが事前に確認せずに実行できる操作を決めると説明されています。最初は変更のたびに確認できる状態で使い、内容を確かめてから承認するようにしましょう。
