給付金を使ってスクールに通いたいとき、最初に決めるべきは「どの制度を使うか」と「転職エージェントをどう使うか」の2点です。この2つは独立した論点ではなく、片方の選択がもう片方の金額に影響します。

**厚労省の教育訓練給付金と、経産省のリスキリング事業は、同一講座では併用できません**（複数スクールの公式FAQで明示）。別の講座でそれぞれの要件を満たすなら、両方を使う余地はあります。

そして**リスキリング事業を使う場合、外部の転職エージェント経由で転職すると追加20%（上限16万円）が受け取れません**。転職支援まで事業の枠内で完結させる設計だからです。一方、教育訓練給付（専門実践）には「どこ経由で就職するか」の指定は見当たらず、外部エージェントとの相性は比較的良好です。

:::summary この記事でわかること
- 教育訓練給付とリスキリング事業の違いと、選び分けの基準
- 外部エージェント経由の転職で追加20%を逃す仕組みと回避策
- 給付は「後払い」という資金繰りの前提と、手続きの順番
- 受講前にカウンセリングで確認すべき質問と、給付金を使わない代替ルート
:::

※制度は改正や公募状況の変更があります。本記事は2026年9月26日時点で確認できた情報をもとにしています。申込前に必ず厚生労働省・経済産業省および各スクールの公式ページで最新条件を確認してください。

## 給付金の「2大ルート」はまったく別の制度

プログラミングスクールで語られる給付金は、実質的に2系統に分かれます。所管省庁も対象者もお金の出方も違います。

### ルート1：教育訓練給付制度（厚生労働省／雇用保険）

雇用保険の被保険者（または離職後一定期間内の人）を対象に、厚生労働大臣が指定した講座の受講費用の一部を支給する制度です。区分は3つあります（政府広報オンライン、および2024年10月施行の改正内容より）。

- **専門実践教育訓練**：受講中は6か月ごとに受講費用の50%（年間上限40万円）。資格取得等をしたうえで修了翌日から1年以内に雇用保険の被保険者として就職した場合（または在職のまま取得した場合）に+20%＝計70%（年間上限56万円）。さらに**2024年10月1日以降に受講を開始**し、修了後の賃金が受講開始前と比べて**5%以上上昇**した場合は+10%＝**最大80%（年間上限64万円）**。給付期間は最大3年。
- **特定一般教育訓練**：受講費用の50%（上限25万円）、修了後に支給。
- **一般教育訓練**：受講費用の20%（上限10万円）。

注意点として、2024年10月1日より前に受講を開始した人は、賃金上昇による+10%の対象になりません（政府広報オンライン）。給付率の引き上げは雇用保険法・同施行規則の改正（令和6年10月1日施行）によるものです。

対象者の細かい条件は{{link:programming-school-kyufukin-conditions|給付金の対象条件を整理した記事}}にまとめています。自分が該当するか怪しい人はそちらを先に確認してください。

### ルート2：リスキリングを通じたキャリアアップ支援事業（経済産業省）

「キャリア相談 → リスキリング講座 → 転職支援」を一体で提供する事業です（事業公式サイト）。補助の構造は次のとおりです。

- 受講費用の**50%（上限40万円）**
- **本事業の職業紹介による転職**をし、転職後**1年間継続して就業**した場合に**追加20%（上限16万円）**
- 合計で**最大70%（上限56万円）**

対象者は、登録時・初回キャリア相談時に企業と雇用契約がある在職者です。契約社員・派遣・パート・アルバイトも対象になりますが、**経営者・役員・業務委託・フリーランスは対象外**です（日経リスキリング、スキルアップAI解説）。個人名義での申込・支払いが条件で、複数講座の同時申請はできないとする案内もあります（ヒューマンアカデミー公式）。

事業は令和4・5年度補正予算で850億円規模とされ、2025年8月には六次公募の開始が告知されています（経済産業省の公募ページ）。補正予算にもとづく事業のため、受付状況や終期は変動します。

## 比較表：2制度のどちらを選ぶか

| 項目 | 教育訓練給付（専門実践） | リスキリング支援事業（経産省） |
|---|---|---|
| 所管 | 厚生労働省（雇用保険） | 経済産業省（補助事業） |
| 対象者 | 雇用保険の被保険者等（在職・離職どちらも要件次第） | 申込時点で雇用契約のある**在職者限定** |
| フリーランス・役員 | 雇用保険の要件で判断 | **対象外** |
| 上限・率 | 最大80%／年間上限64万円 | 最大70%／上限56万円 |
| 追加分の条件 | 修了後1年以内の就職＋賃金5%以上アップ | **事業の職業紹介による転職**＋1年間継続就業 |
| 転職先の紹介元指定 | 制度上の指定は見当たらない | **事業経由であることが追加20%の条件** |
| 支給タイミング | 受講中6か月ごと＋要件達成後 | 受講後・転職後（段階払い） |
| 外部エージェント併用 | 相性は比較的良い | 追加20%を逃すリスクあり |

:::point 判断の軸はここ
上限額だけ見れば専門実践が有利。ただし+10%は「賃金5%以上アップ」が条件のため、年収が下がる未経験転職では届かないことがあります。**求人の選択肢を広く取りたいなら専門実践、事業の紹介求人で納得できそうならリスキリング事業**、という切り分けが現実的です。
:::

## 最大の落とし穴：外部エージェント経由の転職で16万円が消える

リスキリング事業の追加20%（上限16万円）は、**本事業の職業紹介による転職**であることが条件です（日経リスキリング）。事業と無関係の転職エージェント、スカウトサイト、知人紹介、直接応募で内定を取った場合、追加分は支給対象になりません。

厄介なのは「転職してはいけない」わけではない点です。どこに転職するかは自由で、追加20%だけが落ちます。受講費用が80万円なら16万円の差です。

:::warning 経路の扱いは事前に確認する
「どの経路での内定が追加20%の対象になるか」の線引きは事務局の運用に依存します。受講前のキャリア相談の段階で、外部で内定が出た場合の扱いを事務局・スクールに直接確認してください。ここを曖昧にしたまま走り出すのが一番危険です。
:::

### 現実的な選択肢は3パターン

**パターンA：リスキリング事業に乗り切る**

事業のキャリア相談・紹介求人だけで納得できる転職先が見つかりそうなら、追加20%まで取りにいく戦略が合理的です。紹介求人の質や業種の偏りは事前に確認しておきます。

**パターンB：専門実践を選び、外部エージェントは自由に使う**

求人の選択肢を最大化したい人はこちらが素直です。専門実践には紹介元の指定が見当たらないため、スクールの就職支援と外部エージェントを同時並行で使っても、修了後1年以内の就職・賃金5%以上アップという要件さえ満たせば問題になりにくい構造です。

**パターンC：応募は事業経由に寄せ、情報収集だけ外部で行う**

内定経路は事業に寄せつつ、市場の相場や求人動向は外部エージェントの面談で把握する折衷案です。これも線引きの確認が前提になります。

## 同一講座では併用不可。では使い分けはどうする

教育訓練給付とリスキリング事業を同じ講座で二重に使うことはできません。これは複数のスクール公式FAQで明示されています（LINEヤフーテックアカデミー、ヒューマンアカデミーほか）。一方でヒューマンアカデミーの公式ページには、別講座でそれぞれの要件を満たせば両制度を利用すること自体は可能という趣旨の記載があります。

ただし「別講座で両方取る」は簡単ではありません。受講期間が重なれば学習負荷が跳ね上がり、リスキリング事業側は複数講座の同時申請不可とされています。**未経験からの転職を目指す段階では、まず1つの制度に絞って完遂するほうが失敗が少ない**と考えられます。

### 状況別の簡易判定

制度要件から導いた整理です。最終判断は必ず公式・ハローワーク・事務局で確認してください。

| あなたの状況 | 有力な選択肢 | 理由 |
|---|---|---|
| 在職中・転職して年収を上げたい | リスキリング事業 or 専門実践 | どちらも要件を満たしやすい |
| すでに退職している | 専門実践（要件次第） | リスキリング事業は在職者限定のため |
| 副業・独立が目的 | 専門実践も要件確認が必要 | リスキリング事業はフリーランス・役員が対象外。専門実践も「就職」「賃金上昇」要件との整合を要確認 |
| 年収を下げてでも未経験転職したい | 慎重に判断 | 専門実践の+10%は賃金5%上昇が条件のため衝突しうる |
| 求人の選択肢を最大化したい | 専門実践＋外部エージェント | 紹介元の指定が見当たらない |

副業・独立志望の人は特に注意が必要です。リスキリング事業は在職者向け・転職支援とセットの設計なので、会社を辞めずに副業だけしたいというゴールとは噛み合いません。その場合は給付金にこだわらず、動画講座や書籍で費用を抑えて学ぶほうが総コストで有利なこともあります。

## お金の流れ：給付は「後払い」だと理解しておく

よくある誤解が「最初から割引価格で払える」というもの。実際は**いったん全額を自己負担し、あとから戻ってくる**のが基本構造です。

専門実践の場合、受講中は6か月ごとに50%分が支給され、残りの追加分（+20%、+10%）は就職や賃金上昇が確認できたあとに支給されます（政府広報オンライン）。受講開始時点では受講料の全額を用意する必要があり、最終的な70〜80%が手元に戻るのは転職して賃金が確定してからです。

:::steps お金が動く順番（受講料90万円クラスの場合）
1. **申込時**：約91万円を自己負担（ローン利用可の場合あり）
2. **受講中（6か月ごと）**：50%分が段階的に戻る
3. **修了・就職後**：+20%分が戻る
4. **賃金5%上昇の確認後**：+10%分が戻る（年間上限64万円）
5. **最終的な実質負担**：約27万円前後
:::

二次情報として、DMM WEBCAMPのエンジニア転職 専門技術コース（4か月）が910,800円で、専門実践の対象として最大64万円の給付により実質270,800円との解説記事があります（CloudInt）。同スクールの短期集中コース（3か月）は専門実践の対象外で、リスキリング事業側の対象という整理を示す記事もあります（HonNe）。

これらは二次情報であり、料金・対象区分・ブランド名は変更されている可能性があります。実際、旧DMM WEBCAMPのブランド変更を示す記載も見られました。金額は必ず公式サイトと無料カウンセリングで確認してください。

### 手続きの順番を間違えない

専門実践教育訓練では、受講開始前にジョブ・カードの作成と訓練前キャリアコンサルティング、ハローワークでの手続きが必要とされています。申請の期限や必要書類の詳細は、居住地を管轄するハローワークで直接確認してください。本記事では一次情報を取り切れていないため具体的な日数は記載しません。

「先に申し込んでしまい、手続き期限を過ぎて給付が受けられなかった」は、避けられるのに起きやすい失敗です。

## データで見る：リスキリング事業の転職実績

経済産業省 産業人材課の資料（2024年11月15日）には次の数値が示されています。

- 事業経由の**転職完了者の62.3%が年収増**（一般的な転職者で賃金が上昇した割合は37.2%）
- **25.7%が3割以上の年収増**

これは転職を完了した人を分母とした数値で、受講者全員がこうなるという意味ではありません。学習前のスキルや前職の年収水準によって結果は大きく変わります。それでも一般的な転職者の賃金上昇率と差があるのは、キャリア相談から転職支援までが一体という制度設計の効果と読むことはできます。

なお、スクール各社が公表する転職成功率は、**分母の定義（全受講者か、転職希望者のみか、一定期間内の内定者か）が各社で異なる自己申告値**です。数字そのものより、定義とサポート期間を確認するほうが実態に近づけます。

## 2025年10月新設「教育訓練休暇給付金」は使えるか

2025年10月に創設された制度で、教育訓練に専念するために無給で休職した期間の生活費を支えるものです（公的保険アドバイザー協会、厚労省案内資料）。教育訓練休暇の開始日から1年以内に30日以上取得した場合に、取得日数に応じて支給される仕組みとされています（freee解説）。

ただし実務上のハードルは高めです。

1. **勤務先に教育訓練休暇制度があることが前提**。厚労省「能力開発基本調査（令和4年度）」ベースの解説では、導入企業は7.4%にとどまります（勤怠打刻ファースト）。
2. **事業主が30日ごとにハローワークへ取得状況を申告する必要がある**ため、会社の協力が不可欠。
3. 受給すると、休暇開始前の被保険者期間が、離職後の基本手当（失業給付）の受給資格判定から原則除外されるという指摘があります（労務SEARCH）。学習後に退職して転職活動を想定する人には不利に働く可能性があります。

制度としては存在するが、多くの会社員にとってはまだ現実的な選択肢になりにくい——これが2026年9月時点での見立てです。まずは勤務先の就業規則を確認するところからになります。

- 受講開始前の手続き期限を過ぎる（ハローワークでの事前手続きが必要）

## 転職エージェントはいつ使い始めるべきか

「スクールに通ってから」と考えがちですが、**受講前に一度、IT特化の転職エージェントで面談しておく**ほうが判断材料は増えます。理由は3つです。

- 自分の年齢・経歴で、未経験求人がどの程度あるかの温度感がわかる
- 目指す職種（Webアプリ／インフラ／データ）によって、学ぶべき言語・技術が変わる
- そもそもスクールに行かなくても転職できるケースもある（社内SE・IT事務・テスターなど隣接職からの移行）

この情報を持ったうえで講座を選ぶほうが、数十万円規模の投資判断としては健全です。ただし前述のとおり、リスキリング事業を使う場合は受講開始後の応募経路に制約があります。受講前の情報収集フェーズであれば、この論点は基本的に発生しません。

{{aff:career-it-agent|IT・Web特化のエージェントで市場感を先に確認する}}という順番は、どちらの制度を選ぶ場合でも有効です。エージェントの使い方そのものに不安があるなら{{link:mikeiken-engineer-tenshoku-agent-how-to-use|未経験のエージェント活用手順}}も合わせて読んでおくと、面談で聞くべきことが整理できます。

### 給付金を使わない選択肢も比べておく

全員にスクールが必要なわけではありません。

| 方法 | 概算コスト | 向いている人 |
|---|---|---|
| 書籍＋無料教材 | 数千円〜2万円 | 自走できる／適性確認の段階 |
| オンライン動画講座 | 数千円〜数万円 | 体系立てて学びたいが費用を抑えたい |
| 給付金対象スクール | 実質20〜30万円前後（制度・講座による） | 期限を切って転職まで進めたい／独学で挫折した |
| 公的職業訓練（ハロートレーニング） | 原則無料（テキスト代等は自己負担） | 離職中で時間が確保できる |

離職中であれば、公共職業訓練のほうが費用面で有利なケースもあります。最寄りのハローワークでIT系コースの開講予定を確認しておく価値はあります。まずは入門書を一冊終えられるかどうかが、高額受講に進むかの目安になります。

## よくある質問

### Q. 教育訓練給付金とリスキリング事業、結局どちらが得ですか？

上限額だけ見れば専門実践教育訓練（最大80%・年間上限64万円）のほうが大きいですが、追加分の条件が違うため一概には言えません。専門実践の+10%は賃金5%以上の上昇、リスキリング事業の+20%は事業経由の転職＋1年継続就業が条件です。未経験転職で年収が下がる可能性がある人は、専門実践でも70%止まりになる想定で計算しておくと安全です。どちらが使えるかは講座側の指定にもよるので、希望する講座の対象制度を先に確認してください。

### Q. リスキリング事業を使いながら、転職エージェントに登録すること自体は禁止ですか？

登録や相談そのものを禁じる記載は確認できていません。問題になるのは内定の経路で、事業の職業紹介によらない転職の場合、追加20%（上限16万円）が対象外になるとされています（日経リスキリング）。運用の細部は事務局の判断になるため、受講前のキャリア相談で「外部で内定が出た場合の扱い」を明確に聞いておくことをおすすめします。

### Q. すでに退職しています。リスキリング事業は使えますか？

登録時・初回キャリア相談時に企業との雇用契約があることが条件とされているため、退職済みの状態からの新規申込は対象外と解説されています（スキルアップAI、日経リスキリング）。なお、受講の途中で退職した場合は支援対象のままとされています。離職中の方は、教育訓練給付（要件を満たす場合）や公共職業訓練を検討するほうが現実的です。

### Q. 副業やフリーランス独立が目的でも給付金は使えますか？

リスキリング事業は業務委託・フリーランス・経営者・役員が対象外です。教育訓練給付は雇用保険の被保険者要件で判断されますが、専門実践の追加給付は「就職」や「賃金上昇」が条件になるため、独立志向のゴールとは噛み合わない部分があります。副業目的であれば、高額なスクールより動画講座や書籍でコストを抑え、小さく実案件を取りにいくルートのほうが投資効率が良い場合があります。

### Q. 給付金の申請はいつ、どこでやりますか？

教育訓練給付（専門実践）は、受講開始前にジョブ・カードの作成と訓練前キャリアコンサルティングを経て、居住地を管轄するハローワークで手続きを行う必要があるとされています。具体的な提出期限や必要書類は変更されることがあり、本記事では一次情報を確認できていないため断定を避けます。スクールに申し込む前に、必ずハローワークへ直接問い合わせてください。リスキリング事業については、事業公式サイトからの登録とキャリア相談が起点になります。公募回によって受付期間が異なるため、最新のお知らせを確認してください。
