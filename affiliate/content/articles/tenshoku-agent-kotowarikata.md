転職エージェントに登録してみたものの、紹介される求人がどれも自分の希望と少し違う。担当者は親切にしてくれているのに、断るのが申し訳なくて、返信を先延ばしにしてしまっている。そんな場面を想定して書きました。相手の好意を感じるほど、断りにくくなるのは自然なことです。

転職エージェントの求人や面談は、**断って構いません**。断るときは、**早めに、短く、理由を一言添えて伝える**のが基本です。理由を詳しく説明する必要はなく、「希望の条件と合わない」「今回は見送りたい」と伝えれば十分です。

転職エージェントのような職業紹介事業者は、求職の申込みを受けたあと、**苦情の処理に関する事項や、個人情報の取扱いに関する事項などを明示する**ことが法律で定められています。利用をやめたいときや、連絡を止めたいときは、その案内に沿って伝えると安心です。

## 断るときの基本の考え方

転職は、自分の人生にかかわる選択です。エージェントの提案に合わせる義務はありません。断るときは、次の3つを意識しましょう。

| ポイント | 理由 |
| --- | --- |
| 早めに伝える | 返信がないと、エージェントも企業も次の動きを決められない |
| 短く伝える | 長い説明は不要。結論を最初に書くと誤解が生まれにくい |
| 理由を一言添える | 「なぜ合わないか」が伝わると、次からの紹介の精度が上がる |

結局のところ、**丁寧さより「早さ」と「はっきりさ」のほうが、お互いにとって助かる**ことが多いです。曖昧な返事を続けると、かえって紹介が増えて断りにくくなります。

:::warning 断ったことで不利になる心配は少ない
紹介された求人を断るのは、転職活動ではよくあることです。断ったからといって、その後の支援が受けられなくなるわけではありません。不安な場合は、希望の条件をあらためて伝えておくと、次からの紹介が合いやすくなります。
:::

## 場面別の断り方と例文

### 紹介された求人を断るとき

希望と合わない理由を一言添えると、次からの紹介に活かしてもらえます。

:::check 例文：紹介求人を断る
いつもご紹介ありがとうございます。
ご紹介いただいた求人について検討しましたが、勤務地が希望と異なるため、今回は応募を見送らせてください。
引き続き、通勤1時間以内の求人があればご紹介いただけると助かります。
:::

### 選考の途中で辞退するとき

選考中の辞退は、企業との日程調整にかかわるため、**決めたらすぐに連絡**しましょう。面接日が決まっている場合は、特に早めの連絡が大切です。

:::check 例文：選考を辞退する
お世話になっております。
選考を進めていただいている求人について、検討の結果、辞退させていただきたくご連絡しました。
企業の皆さまにもお時間をいただいたのに申し訳ありません。お手数ですが、先方へのお伝えをお願いいたします。
:::

### 内定を辞退するとき

内定の辞退は、企業にとっても影響が大きいため、**メールに加えて電話でも伝える**と誠実さが伝わります。理由は簡潔で構いません。

:::check 例文：内定を辞退する
お世話になっております。
このたびは内定のご連絡をいただき、ありがとうございました。
慎重に検討した結果、別の会社への入社を決めたため、内定を辞退させていただきたく存じます。
ご尽力いただいたのに申し訳ありません。企業の皆さまにもよろしくお伝えください。
:::

### 他のエージェントで転職先が決まったとき

検索では「転職エージェント 断り方 他のエージェント」も調べられています。複数のエージェントを使うのは珍しいことではないので、**正直に「他で決まった」と伝えて問題ありません**。

:::check 例文：他のエージェントで決まった
お世話になっております。
このたび、別の経路で転職先が決まりましたので、転職活動を終了することにしました。
これまでご支援いただき、ありがとうございました。今後の求人のご紹介は停止していただけますと幸いです。
:::

複数のエージェントの使い分け方は {{link:it-tenshoku-agent-multiple-registration|IT転職エージェントの複数登録は何社が正解？}} で整理しています。

### 転職活動そのものをやめるとき

今の職場に残ることにした場合も、その旨を伝えれば十分です。**「今回は転職を見送ることにした」と一言伝えれば、理由を詳しく話す必要はありません**。

## メールやLINEで伝えるときのコツ

検索では「転職エージェント 断り方 メール」「転職エージェント 断り方 line」も調べられています。メールやLINE、チャットで伝える場合は、次の点を意識しましょう。

:::point メール・LINEで断るときのコツ
- 最初の一文で結論（見送りたい、辞退したい）を書く
- 対象の求人や選考が分かるように、企業名や職種を書き添える
- 今後も紹介を受けたいか、停止してほしいかをはっきり書く
:::

**文面に迷ったら、上の例文をそのまま短くして使っても大丈夫です**。返信が遅れてしまった場合も、気にしすぎずに、気づいた時点で連絡しましょう。チャットでの相談の使い方は {{link:tenshoku-soudan-muryo-chat|転職相談を無料チャットでするには？}} で整理しています。

## 利用をやめたいとき・連絡を止めたいとき

### まずは連絡の停止をお願いする

転職エージェントのサービスをやめたい場合は、担当者に「転職活動を終了するので、連絡を停止してほしい」と伝えましょう。退会の手続きは、サービスごとにWebの退会ページや問い合わせ窓口が用意されていることが多いです。

### 苦情の窓口や、個人情報の扱いを確認する

石川労働局の「職業紹介事業の概要」によると、職業紹介事業者は、求職の申込みを受理したあと、速やかに書面や電子メールなどで、**苦情の処理に関する事項**や、**求職者の個人情報の取扱いに関する事項**などを明示しなければならないとされています（職業安定法第32条の13）。登録時に受け取った案内やメールを見返すと、問い合わせ先が書かれていることがあります。

個人情報保護委員会のよくある質問（Q9-21）では、ダイレクトメールを例に、事業者が送付を停止したあとに本人が消去を請求した場合や、送付の停止を求めたのに繰り返し送付される場合などには、**保有個人データの利用の停止や消去をする義務がある**と説明されています。また、請求に理由がない場合でも、苦情として適切かつ迅速に処理するよう努めなければならないとされています。

:::steps 利用をやめるときの流れ
1. **担当者に伝える**：転職活動を終了すること、連絡を停止してほしいことを伝えます。
2. **退会の手続きを確認する**：Webの退会ページや、案内に書かれた窓口を確認します。
3. **個人情報の扱いを確認する**：登録情報の削除を希望する場合は、その旨も伝えます。
4. **連絡が続く場合は窓口に相談する**：案内に書かれた苦情の窓口に、状況を伝えて相談します。
:::

## 断りやすいエージェントとの付き合い方

:::merit 断ることのメリット
- 希望と合わない求人に時間を使わずに済む
- 自分の希望の条件がエージェントに正しく伝わる
- 納得できる会社だけに応募できる
:::

:::demerit 返事を先延ばしにするデメリット
- 選考の日程が決まってしまい、断りにくくなる
- 企業やエージェントに迷惑をかけてしまうことがある
- 自分の中でも迷いが長引き、疲れてしまう
:::

**最初の面談で、希望の条件と「これは譲れない」という点をはっきり伝えておく**と、合わない求人の紹介が減り、断る場面そのものを少なくできます。エージェントの使い方の全体は {{link:mikeiken-engineer-tenshoku-agent-how-to-use|未経験のエンジニア転職エージェント活用法}} で整理しています。

エージェントとのやり取りに疲れてしまい、そもそも何を基準に会社を選べばいいか迷っている人は、{{aff:career-coaching|キャリナビ（無料のキャリアコーチング＋転職支援）}}で、自分の希望や大切にしたい条件を整理してもらう方法もあります。

{{aff:career-coaching}}

IT業界への転職を考えていて、希望をはっきり伝えたうえで求人を紹介してほしい人は、{{aff:career-it-agent|ユニゾンキャリア（エンジニア専門の転職エージェント）}}で相談してみる方法もあります。

編集部としては、**断ることを「迷惑をかけること」ではなく「自分の希望を伝えること」と考える**ことをおすすめします。早めにはっきり断るほうが、エージェントにとっても次の提案を考えやすくなるからです。

## 迷ったときの次の一歩

迷ったら、まずは返事を保留している求人を一つだけ選び、この記事の例文を短くして返信してみてください。一通送るだけで、気持ちがずいぶん軽くなるはずです。

エージェントやサービスは、自分に合わなければ利用をやめて構いません。自分のペースで、納得できる転職活動を進めましょう。

## よくある質問

### 転職エージェントの求人は断ってもいい？

断って構いません。紹介された求人を断るのは転職活動ではよくあることです。希望と合わない理由を一言添えると、次からの紹介に活かしてもらいやすくなります。

### 転職エージェントの断り方はメールでもいい？

メールやLINE、チャットで伝えても問題ありません。最初の一文で結論を書き、対象の求人や選考が分かるように企業名や職種を添えましょう。内定の辞退は、メールに加えて電話でも伝えると誠実さが伝わります。

### 他のエージェントで決まったことを伝えてもいい？

正直に伝えて問題ありません。「別の経路で転職先が決まったので転職活動を終了します」と伝え、今後の紹介を停止してほしいことも書き添えましょう。

### 退会したら個人情報は消してもらえる？

退会の際に、登録情報の削除を希望する旨を伝えましょう。個人情報保護委員会のよくある質問では、一定の場合に事業者が保有個人データの利用停止や消去をする義務があることが説明されています。連絡が続く場合は、登録時に案内された苦情の窓口に相談しましょう。
