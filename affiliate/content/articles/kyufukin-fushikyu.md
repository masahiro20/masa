教育訓練給付金を使って講座を受けようと考えているけれど、ネットで「申請したのにもらえなかった」という話を見かけて不安になった。せっかく受講料を払って勉強しても、最後に給付金が出なかったらどうしようと心配している。そんな場面を想定して書きました。お金が戻ってくることを前提に計画していると、不安になるのは当然です。

教育訓練給付金が不支給になる主な理由は、**雇用保険の加入期間が足りない、受講開始日の前日から3年以内に給付金を受けている、修了日の翌日から1か月以内に申請していない、講座を修了できなかった**などです。特定一般教育訓練と専門実践教育訓練では、**受講開始日の2週間前までの受給資格確認の手続き**も必要です（2026年11月時点）。

多くは、**申し込む前と受講中に確認しておけば防げるもの**です。ハローワークでは、申請に先立って**支給要件照会**で、受講開始日時点の受給資格の有無と、講座が厚生労働大臣の指定を受けているかを確認できるとされています。

## 不支給になりやすい主な理由

| 理由 | ハローワークの案内で確認できること |
| --- | --- |
| 雇用保険の加入期間が足りない | 一般教育訓練は原則3年以上（初めて受ける場合は1年以上）など、種類ごとに必要な期間がある |
| 3年以内に給付金を受けている | 受講開始日の前日から3年以内に教育訓練給付金の支給を受けたことがある場合は支給されない |
| 離職から時間が空いている | 離職している場合は、資格喪失日の翌日から受講開始日までが1年以内である必要がある |
| 申請期限を過ぎた | 一般教育訓練は、修了日の翌日から1か月以内に申請が必要 |
| 講座を修了できなかった | 給付金は、指定講座を修了した場合に支給される |
| 支給額が少なすぎる | 給付率をかけた額が4千円を超えない場合は支給されない |
| 事前の手続きをしていない | 特定一般・専門実践は、訓練前キャリアコンサルティングと受講開始日の2週間前までの受給資格確認が必要 |

結局のところ、不支給の多くは**「条件を満たしていなかった」か「手続きの期限を過ぎた」**のどちらかです。

## 加入期間と過去の受給の数え方

ハローワークの一般教育訓練の案内（PDF）では、支給要件期間について、次のように説明されています。

:::check 加入期間の数え方（一般教育訓練の案内より）
- 支給要件期間は、受講開始日までに同じ事業主に引き続いて被保険者として雇用された期間
- その前に別の事業主で被保険者だった期間があり、空白期間が1年以内なら通算する
- 過去に給付金を受けた場合、その時の受講開始日より前の期間は通算しない
- 同時に複数の講座について支給申請はできない
:::

**転職を挟んでいる人や、以前に給付金を使ったことがある人は、自分で計算せずにハローワークで確認する**のが確実です。パートで働いている人の加入条件は {{link:kyufukin-part|教育訓練給付金はパートでも使える？}}、2回目に使うときの条件は {{link:kyufukin-2kaime-jouken|教育訓練給付金の2回目の条件}} で整理しています。

## 教育訓練経費に含まれないもの

給付金の対象になる「教育訓練経費」にも決まりがあります。一般教育訓練の案内では、**入学料と受講料（最大1年分）の合計**とされ、次のようなものは含まれないと説明されています。

:::warning 教育訓練経費に含まれないもの（一般教育訓練の案内より）
- 検定試験の受講料
- 受講に必ずしも必要とされない補助教材費、補講費、行事参加費
- 交通費、パソコンなどの器材の費用
- クレジット会社に対する手数料
- 支給申請の時点で未納の額
:::

同じ案内では、**割引制度などが使われた場合は割引後の額が教育訓練経費になる**こと、スクールなどから一定額の還付が予定されている場合（パソコンなどの無償提供を含む）は、その額を差し引いて申告する必要があることも示されています。**「思っていたより給付額が少なかった」とならないよう、対象になる費用を先に確認**しておきましょう。

## 不支給を防ぐための確認点

:::steps 申し込みから申請までに確認すること
1. **支給要件照会をする**：申し込む前に、ハローワークで受給資格の有無と講座の指定を確認します。
2. **事前の手続きを済ませる**：特定一般・専門実践の場合は、訓練前キャリアコンサルティングを受け、受講開始日の2週間前までに受給資格確認を行います。
3. **修了の条件を確認する**：出席率や課題など、スクールが定める修了の基準を確認します。
4. **領収書などを保管する**：支払った入学料・受講料の領収書を、なくさないように保管します。
5. **期限内に申請する**：一般教育訓練なら、修了日の翌日から1か月以内に申請します。
:::

**修了したら、その日のうちに申請の準備を始める**のがおすすめです。一般教育訓練の案内では、郵送で申請する場合も1か月以内（消印有効）に行うよう示されています。申請の流れと必要書類は {{link:kyoiku-kunren-kyufukin-shinsei-nagare|教育訓練給付金の申請方法}} で詳しく整理しています。

:::point 支給要件照会のポイント（ハローワークの案内より）
- 受講開始（予定）日時点の受給資格の有無と、講座が厚生労働大臣の指定を受けているかを確認できる
- 照会票に記入し、本人確認書類を提示・添付して提出する（本人来所、代理人、郵送、電子申請）
- 電話による照会は受け付けていない
:::

## 受講が難しくなったときの「適用対象期間の延長」

一般教育訓練の案内では、離職後に、**妊娠、出産、育児、病気、けがなどで受講が難しい期間が30日以上続いた場合**、ハローワークに申し出ることで、受講を開始できる期間（適用対象期間）を延長できる（最大19年）と説明されています。**離職後すぐに受講できない事情がある人は、早めにハローワークに相談**しましょう。

## 給付金が使えないときの選択肢

:::merit 給付金が使えなくても検討できること
- 経済産業省の「リスキリングを通じたキャリアアップ支援事業」の対象講座を探す（在職中で転職を目指す人が対象）
- 費用を抑えた動画講座や、無料の教材で学び始める
- 加入期間が足りるまで待ってから、給付金の対象講座を受ける
:::

:::demerit 気をつけたいこと
- 制度ごとに対象者や条件が違うため、自分が当てはまるかの確認が必要
- 補助や給付があっても、受講料をいったん自分で払う場合がある
- 「最大70％」といった表示は、条件をすべて満たした場合の金額であることが多い
:::

## 迷いやすいポイント

ここで迷う方は多いので、考え方を整理しておきます。

### スクールが「給付金対象」と言っていれば大丈夫？

講座が指定を受けていても、**自分が受給資格を満たしているかは別の問題**です。スクールの説明だけで判断せず、ハローワークの支給要件照会で確認しましょう。

### 不支給になったらどうすればいい？

不支給の理由は、ハローワークで確認できます。条件を満たしていると考えられる場合は、**どの書類や条件が足りなかったのかをハローワークに確認**しましょう。

### 会社から受講料の補助を受けている場合

一般教育訓練の案内では、事業主などが受講に伴って手当などを支給する場合、**そのうち入学料や受講料に充てられる額は、教育訓練経費から差し引いて申請しなければならない**とされています。会社の研修制度などで受講料の一部を補助してもらっている人は、申請の前に金額を確認しておきましょう。

## 迷ったときの次の一歩

迷ったら、まずは今の職場で雇用保険に加入した時期と、過去に教育訓練給付金を受けたことがあるかを書き出してみてください。そのうえで、ハローワークで支給要件照会を行うと、自分が対象になるかがはっきりします。

講座や制度は、自分に合わなければ見送って構いません。条件が整う時期を待ってから受講する方法も含めて、自分に合ったやり方を選んでください。

## よくある質問

### 教育訓練給付金が不支給になる主な理由は？

雇用保険の加入期間が足りない、受講開始日の前日から3年以内に給付金を受けている、修了日の翌日から1か月以内に申請していない、講座を修了できなかった、などが主な理由です。特定一般・専門実践では事前の受給資格確認も必要です。

### 教育訓練給付金の対象にならない費用は？

ハローワークの一般教育訓練の案内では、教育訓練経費は入学料と受講料（最大1年分）の合計とされ、検定試験の受講料、交通費、パソコンなどの器材の費用、クレジット会社への手数料などは含まれないと説明されています。

### 教育訓練給付金の申請期限を過ぎたらどうなる？

一般教育訓練の場合、修了日の翌日から1か月以内に申請する必要があります。期限を過ぎると支給を受けられなくなるおそれがあるため、修了したらすぐに申請の準備を始め、迷う場合はハローワークに確認しましょう。

### 自分が教育訓練給付金の対象か確かめる方法は？

ハローワークの支給要件照会で、受講開始日時点の受給資格の有無と、講座が厚生労働大臣の指定を受けているかを確認できます。照会票に記入し、本人確認書類を提示・添付して提出します。電話での照会は受け付けていません。
