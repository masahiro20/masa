仕事が終わってから、毎日少しずつプログラミングを勉強しようと決めた。最初の一週間は順調だったのに、残業が続いたり、エラーが解決できなかったりして、気づけば教材を開かない日が増えている。このままだとまた途中でやめてしまうのではと、不安になっている。そんな場面を想定して書きました。働きながら新しいことを学ぶのは、それだけで大変なことです。

社会人がプログラミングの独学で挫折しやすいのは、**意志が弱いからではなく、「時間の確保」「教材選び」「エラーの解決」「目標のあいまいさ」という、つまずきやすい場所がある程度決まっている**からです。

対策の基本は、**学ぶ時間を小さく固定し、自分のレベルに合った教材を一つに絞り、作りたいものを一つ決める**ことです。つまずく場所を先に知っておけば、立ち止まったときにも、やめずに次の手を考えやすくなります。

## 社会人が独学で挫折しやすい理由

| 理由 | 起こりやすいこと |
| --- | --- |
| 時間が足りない | 残業や家庭の予定で、学ぶ時間が不定期になる |
| 教材が合っていない | 前提知識を求める教材を選び、最初から分からない |
| エラーが解決できない | 原因が分からず、同じところで何時間も止まる |
| 目標があいまい | 何のために学ぶのかが決まっておらず、意欲が続かない |
| 相談相手がいない | 分からないことを聞けず、一人で抱え込む |

検索では「プログラミング 独学 挫折 率」も調べられています。ただ、挫折率として出回っている数字の多くは、調査の対象や方法がまちまちです。**数字に一喜一憂するより、自分がどこでつまずきそうかを先に知っておく**ほうが、対策としては役に立ちます。

## 教材選びで挫折しないために

挫折の原因として見落とされやすいのが、**教材の対象読者と自分のレベルが合っていない**ことです。

たとえば、Pythonの公式チュートリアルには、冒頭で**「このチュートリアルは Python を初めて学ぶプログラマー向けです。プログラミングを初めて学ぶ初心者向けではありません」**と書かれています。また、**一般的なプログラミングの基礎知識があることを前提としている**とも説明されています。

:::point 教材を選ぶときに確認したいこと
- 教材が「誰向け」に書かれているか（初心者向けか、経験者向けか）
- 前提として求められている知識は何か
- 手を動かして試せる課題や練習があるか
- 最後まで進めたときに、何ができるようになるか
:::

公式の情報は正確ですが、**プログラミングがまったく初めての人が、経験者向けの資料から始めると、内容が分からず挫折しやすくなります**。最初は初心者向けの教材で基礎を固め、公式の資料は調べものや次のステップで使うと、無理なく進められます。

一方、MDNの「ウェブ開発の学習」のように、**構造化されたチュートリアルに課題や推奨リソースがついている**教材もあります。**課題がある教材は「分かったつもり」を防ぎやすい**ので、独学に向いています。

## 挫折しないための具体的な対策

### 学ぶ時間を小さく固定する

「時間があるときにやる」と決めると、忙しい日が続いたときに止まってしまいます。**平日は15分でもよいので、毎日同じ時間に教材を開く**と決めておくと、習慣になりやすくなります。

### 作りたいものを一つ決める

「プログラミングができるようになりたい」だけでは、目標として大きすぎます。**仕事の作業を自動化したい、簡単なWebページを作りたいなど、作りたいものを一つ決める**と、何を学べばよいかがはっきりします。何から始めるか迷う人は、{{link:programming-dokugaku-nanikara|プログラミングの独学は何から始める？}} も参考にしてください。

### エラーで止まる時間に上限を決める

:::warning 一つのエラーに時間をかけすぎない
エラーの解決に何時間もかけると、学ぶ意欲そのものがなくなってしまいます。30分調べても分からなければ、エラーメッセージをメモして先に進む、別の日に見直す、質問するなど、次の手を決めておきましょう。
:::

エラーメッセージは、**最初の一行と、エラーが出た行番号**に注目して読むと、原因に近づきやすくなります。

### 進んだことを記録する

学んだ内容や作ったものを、短くメモしておきましょう。**「昨日より一つできることが増えた」と目で見て分かる**と、忙しい時期でも続ける意欲を保ちやすくなります。

## 続けるための学習の進め方

:::steps 社会人が独学を続ける流れ
1. **作りたいものを一つ決める**：小さく、具体的なものを選びます。
2. **初心者向けの教材を一つに絞る**：あれこれ手を出さず、一つを最後まで進めます。
3. **毎日同じ時間に学ぶ**：短い時間でも、決まった時間に教材を開きます。
4. **教材の例を少し変えて試す**：写すだけでなく、値や処理を変えて動きを確かめます。
5. **小さな作品を完成させる**：最初に決めたものを、簡単な形でも完成させます。
:::

**教材を一つ終えるより、小さな作品を一つ完成させる**ことを目標にすると、学んだことが実際に使える形で残ります。Pythonで進めたい人は、{{link:python-dokugaku-roadmap-shakaijin|社会人のPython独学ロードマップ}} で学ぶ順番を整理しています。

## 忙しい時期を乗り切る工夫

社会人の独学では、仕事の繁忙期や家庭の事情で、どうしても学べない時期が出てきます。ここで迷う方は多いので、止まってしまったときの考え方を整理しておきます。

### 「やめた」ではなく「休んでいる」と考える

数日から数週間学べなかったとしても、それで終わりではありません。**再開するときは、前回の続きではなく、少し前の簡単な内容から復習する**と、スムーズに戻りやすくなります。

### 最低限の目標を決めておく

忙しい時期は、**「教材を開いてコードを一行だけ書く」**など、ごく小さな目標に切り替えましょう。完全に止めずに少しでも触れておくと、忙しい時期が終わったあとに戻りやすくなります。

### 週末にまとめて時間をとる

平日に時間がとれない場合は、週末に1〜2時間をまとめて確保し、平日は復習だけにするなど、**週単位で計画を組み直す**方法もあります。

## 質問できる場所をつくる

独学で挫折しやすい理由の一つが、分からないことを聞ける相手がいないことです。一人で抱え込まないために、質問できる場所を先に用意しておきましょう。

### 質問の仕方を決めておく

質問するときは、**何をしようとしたか、どんなエラーが出たか、自分で何を試したか**の3つをまとめて書くと、答えてもらいやすくなります。この3つを書き出すだけで、自分で原因に気づけることもあります。

### 同じ目標の人とつながる

学習の記録を発信したり、勉強会に参加したりして、同じように学んでいる人とつながるのも一つの方法です。**一緒に学ぶ人がいると、忙しい時期でも続ける意欲を保ちやすくなります**。

### 職場で使える場面を探す

今の仕事の中で、表計算の集計やファイルの整理など、プログラミングで楽にできそうな作業を探してみましょう。**学んだことが仕事で役立つ実感**は、続けるうえで大きな支えになります。

## 独学に限界を感じたときの選択肢

:::merit 独学を続ける良さ
- 費用を抑えて、自分のペースで進められる
- 調べながら解決する力が身につく
- 公式のドキュメントや無料の教材を活用できる
:::

:::demerit 独学だけで進めるときの注意点
- 分からないことを質問できる相手がいない
- 学ぶ順番が正しいか、自分では判断しにくい
- 一人だと、ペースが崩れたときに立て直しにくい
:::

**本で学ぶ方法と、動画で学ぶ方法を組み合わせる**と、独学でつまずきやすいところを補いやすくなります。体系的に順を追って学びたい人は、{{aff:learning-books|初心者向けのプログラミング入門書}}を一冊決めて、最後まで進めてみてください。

{{aff:learning-books}}

画面の操作やエラーの直し方を、解説を見ながら理解したい人は、{{aff:learning-online-course|オンライン動画講座}}で入門講座を一つ選ぶ方法もあります。講師が実際にコードを書く様子を見られるので、文章だけでは分かりにくいところをつかみやすくなります。

{{aff:learning-online-course}}

編集部としては、**社会人の独学は「時間を小さく固定する」「教材を一つに絞る」「作りたいものを一つ決める」の3つから始める**ことをおすすめします。完璧な計画より、続けられる仕組みのほうが、挫折を防ぐうえで大切だからです。

## 迷ったときの次の一歩

迷ったら、まずは今週の予定表を開いて、毎日15分だけ学べる時間を一つ書き込んでみてください。そのうえで、作りたいものを一行で書き出し、今使っている教材がそれにつながるかを確かめましょう。

教材や講座は、自分に合わなければ見送って構いません。無料の教材や公式のチュートリアルで学ぶ方法も含めて、続けられるやり方を選んでください。

## よくある質問

### 社会人がプログラミングの独学で挫折する理由は？

主な理由は、学ぶ時間が不定期になること、自分のレベルに合わない教材を選んでしまうこと、エラーが解決できずに止まること、学ぶ目的があいまいなことです。つまずきやすい場所を先に知っておくと、対策を立てやすくなります。

### プログラミングの独学の挫折率はどれくらい？

挫折率として出回っている数字は、調査の対象や方法がまちまちです。数字よりも、自分がどこでつまずきそうかを知り、時間の確保や教材選びなどの対策を先に考えておくほうが役に立ちます。

### 独学で挫折しないための教材の選び方は？

教材が誰向けに書かれているかを確認しましょう。たとえばPythonの公式チュートリアルは、プログラミングを初めて学ぶ初心者向けではなく、Pythonを初めて学ぶプログラマー向けと書かれています。最初は初心者向けで、課題がある教材を選ぶと続けやすくなります。

### 忙しくて独学が止まってしまったらどうすればいい？

「やめた」ではなく「休んでいる」と考え、再開するときは少し前の簡単な内容から復習しましょう。忙しい時期は、教材を開いてコードを一行書くなど、ごく小さな目標に切り替えると、戻りやすくなります。
