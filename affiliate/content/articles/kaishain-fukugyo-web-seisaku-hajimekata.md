会社員が副業でWeb制作を始めるなら、「就業規則の確認 → 基礎スキルの習得 → ポートフォリオ作成 → 小さな案件の獲得 → 税金の手続き」の順に進めるのが現実的です。

Web制作はパソコンとネット環境があれば始めやすく、在宅で平日夜や週末に作業しやすい副業です。一方で、スキルの習得と実績づくりに時間がかかり、**始めてすぐに安定した収入になるとは限りません**。

この記事では、本業と両立しながらWeb制作の副業を始めるための手順と、会社員ならではの注意点を整理します。

:::summary
- 会社員がWeb制作の副業を始める前に確認したいこと
- 学ぶべきスキルと、ポートフォリオの作り方
- 最初の案件を獲得するまでの現実的なステップ
- 副業収入が出たときの税金の手続き
:::

## 始める前に確認したいこと：就業規則と働き方

### 会社のルールを確認する

厚生労働省は「副業・兼業の促進に関するガイドライン」（令和4年7月改定）を示し、労働者が安心して副業・兼業に取り組めるよう環境整備を進めています。ただし、副業を認めるかどうかや、届出の手続きは会社ごとに定められています。

ガイドラインでは、会社が副業を制限できる場合として、労務提供上の支障がある場合や、業務上の秘密が漏れる場合、競業により会社の利益を害する場合などが挙げられています。まずは自社の**就業規則で副業の可否と届出の要否を確認**しましょう。

:::warning 会社員の副業で気をつけたいこと
- 就業規則で副業が禁止・届出制になっていないか確認する
- 本業の取引先や競合からの受注は、利益相反にあたらないか慎重に判断する
- 本業で知った情報や、会社の機材・ソフトを副業に使わない
- 睡眠時間を削りすぎず、本業に支障が出ない作業量にとどめる
:::

### 使える時間を見積もる

Web制作の副業では、学習期間と案件の作業時間の両方が必要です。平日に何時間、週末に何時間使えるかを先に見積もっておくと、受けられる案件の規模や納期の判断がしやすくなります。

## 副業Web制作の全体の流れ

:::steps 副業Web制作を始める5つのステップ
1. **会社のルールと時間を確認する**：就業規則を確認し、週に使える作業時間を見積もる。
2. **基礎スキルを身につける**：HTML・CSS、WordPress、デザインツールの基本を学ぶ。
3. **ポートフォリオを作る**：自分のサイトと、架空または知人向けの制作実績を用意する。
4. **小さな案件から受注する**：クラウドソーシングや知人の紹介で、修正や小規模サイトから始める。
5. **収入の記録と税金の手続きをする**：売上と経費を記録し、必要に応じて申告する。
:::

## ステップ2：身につけたいスキル

副業で受注しやすいWeb制作の仕事には、既存サイトの修正、ランディングページのコーディング、WordPressでのサイト制作などがあります。最初に身につけたいスキルは次のとおりです。

| スキル | 内容 | 主な使いどころ |
|---|---|---|
| HTML・CSS | ページの構造と見た目を作る | コーディング案件全般 |
| レスポンシブ対応 | スマートフォンでも崩れない表示にする | ほぼすべての案件 |
| WordPress | テーマの設定・カスタマイズ、プラグインの扱い | 中小企業や個人事業主のサイト制作 |
| デザインツール | Figmaなどでデザインデータを読み取る・作る | デザインカンプからのコーディング |
| JavaScriptの基礎 | メニューの開閉など簡単な動きをつける | コーディング案件の付加価値 |

学び方は、書籍や動画講座での独学、スクールの利用などがあります。本業がある会社員は学習時間が限られるため、**目的に直結する範囲から優先して学ぶ**のが効率的です。

{{aff:learning-online-course}}

独学で続けるのが難しい人や、作品へのフィードバックが欲しい人はスクールも選択肢になります。スクールの要否は{{link:web-designer-mikeiken-school-hitsuyou|未経験からWebデザイナーにスクールは必要？}}で詳しく整理しています。

## ステップ3：ポートフォリオを作る

実績がない段階では、ポートフォリオが自分のスキルを伝える最も重要な材料になります。

### 自分のサイトを持つ

ポートフォリオを公開する自分のサイトは、レンタルサーバーと独自ドメインを使ってWordPressで作ると、それ自体がWordPressでのサイト制作の実績になります。2026年10月時点のWordPress.org日本語版の「必須要件」では、推奨環境としてPHP 8.3以上、MariaDB 10.11以上またはMySQL 8.0以上、HTTPSが挙げられているため、サーバー選びの際に確認しておきましょう。

具体的な開設手順は{{link:wordpress-blog-start-server-domain-steps|WordPressブログの始め方}}で解説しています。

{{aff:tools-rental-server}}

### 掲載する作品の作り方

ポートフォリオには、次のような作品を3〜5点ほど用意すると、受注の際に説明しやすくなります。

- 架空の店舗や会社を想定したコーポレートサイト
- 1ページ完結のランディングページ
- 既存サイトを想定したリニューアル案
- 知人の活動を紹介するサイト（許可を得たうえで）

それぞれの作品には、「誰に向けたサイトか」「どんな工夫をしたか」「制作にかかった時間」を添えると、依頼する側が仕事のイメージを持ちやすくなります。

:::check ポートフォリオ公開前のチェックリスト
- スマートフォンで表示が崩れていない
- 作品ごとに目的・工夫した点・使用ツールを書いている
- 問い合わせ方法が分かりやすい
- 他人の画像や文章を無断で使っていない
- 本業の会社の情報や、守秘義務のある制作物を載せていない
:::

## ステップ4：最初の案件を獲得する

### 案件の探し方

副業の初案件の探し方として、主に次のような方法があります。

| 方法 | 特徴 | 注意点 |
|---|---|---|
| クラウドソーシング | 未経験可の小さな案件も見つけやすい | 手数料がかかり、単価が低めの案件も多い |
| 知人・地域のつながり | 信頼関係があり、相談しやすい | 金額や範囲があいまいになりやすい |
| SNS・ブログでの発信 | 制作物や学習過程を見てもらえる | 成果が出るまで時間がかかる |

最初は、既存サイトの修正やバナー差し替えなど、**小さく短期間で終わる案件から始める**と、本業と両立しやすく、実績も積みやすくなります。経験を積んだ後の案件獲得の方法は、{{link:freelance-engineer-how-to-get-projects|フリーランスの案件獲得方法の比較}}も参考になります。

### 契約前に決めておくこと

副業の案件では、作業範囲や修正回数をあいまいにしたまま始めてしまい、作業が膨らむケースがよくあります。金額・納期・作業範囲・修正回数・支払日・納品後の保守の有無は、着手前に文章で確認しておきましょう。

:::merit Web制作副業のメリット
- 在宅で、平日夜や週末に作業しやすい
- 制作物が実績として残り、ポートフォリオが育つ
- スキルが本業や転職に生きる場合がある
:::

:::demerit Web制作副業のデメリット
- スキル習得と実績づくりに時間がかかる
- 最初は単価が低い案件が中心になりやすい
- 納期前は本業との両立が負担になることがある
:::

### 本業と両立するための工夫

副業を長く続けるには、作業の仕組みづくりも大切です。たとえば、平日は学習や小さな修正作業、まとまった制作は週末に回すなど、曜日ごとに作業の種類を分けると予定が立てやすくなります。

案件を受けるときは、本業の繁忙期を避けた納期にする、余裕を持ったスケジュールで見積もるなど、無理のない受け方を意識しましょう。納期に追われて睡眠や本業に影響が出ると、副業そのものを続けられなくなってしまいます。

## ステップ5：税金の手続き

副業で収入が出たら、売上と経費を記録しておきましょう。国税庁の「No.1900 給与所得者で確定申告が必要な人」では、給与を1か所から受けていて、その給与の全部が源泉徴収の対象となる場合に、給与所得・退職所得以外の各種の所得金額の合計額が20万円を超える人は、確定申告が必要とされています。

ここでいう20万円は売上ではなく、売上から必要経費を引いた「所得」の金額です。

また、名古屋市の案内によると、市民税・県民税には所得税のような申告の省略範囲はなく、原則としてすべての所得を申告する必要があります（所得税の確定申告をした場合は、改めて申告する必要はありません）。**副業の所得が20万円以下でも、住民税の申告が必要になる場合がある**ため、お住まいの自治体の案内を確認してください。

## Web制作副業が向いている人・向いていない人

:::point 向き不向きの目安
コツコツ手を動かして学ぶのが苦にならず、数か月単位で実績を積み上げられる人に向いています。反対に、すぐに大きな収入が欲しい人、本業が繁忙で週に数時間も確保できない人は、学習期間の見通しを立ててから始めるほうが安心です。
:::

学習を一人で続けられるか不安な人は、副業向けのコースを用意しているスクールの無料カウンセリングで、カリキュラムや学習時間の目安を聞いてみるのも一つの方法です。

{{aff:school-general}}

## よくある質問

### 未経験の会社員でもWeb制作の副業はできますか？

できる可能性はありますが、まずは基礎スキルとポートフォリオを作る期間が必要です。学習期間の長さは、使える時間や目指す案件によって変わります。最初は小さな案件から始め、実績を積みながら受注の幅を広げていくのが現実的です。

### 副業が会社に知られることはありますか？

隠して進めることを前提にするのではなく、まず就業規則で副業が認められているか、届出が必要かを確認し、ルールに沿って進めることが大切です。

### 副業の所得が20万円以下なら何も手続きしなくていいですか？

所得税の確定申告は、給与所得者で一定の条件を満たす場合、給与以外の所得が20万円以下なら不要とされています。ただし、住民税には同じ省略の仕組みがないため、自治体への申告が必要になる場合があります。お住まいの自治体の案内を確認してください。

### 最初に用意すべき道具は何ですか？

パソコン、インターネット環境、コードエディタ（無料のものも多い）、デザインツールがあれば始められます。ポートフォリオを公開するために、レンタルサーバーと独自ドメインも用意しておくとよいでしょう。
