仕事終わりにHTMLの入門ページを開いて、「これ、いつになったら形になるんだろう」と手が止まっている。そんな場面を想定して書きました。先が見えないまま学び続けるのは、不安になって当然です。

Web制作の独学にかかる期間は、**「どこまでできるようになりたいか」と「週にどれくらい学習時間を取れるか」で大きく変わるため、誰にでも当てはまる決まった期間はありません**。HTMLとCSSで簡単なページを作れるようになるまでと、仕事として依頼を受けられるようになるまででは、学ぶ範囲がまったく違うからです。

ひとつの参考になるのが、公的な職業訓練の訓練期間です。独立行政法人高齢・障害・求職者雇用支援機構（JEED）によると、求職者支援訓練のうち、就職を希望する職種に合わせた専門的な技能を習得する「実践コース」は、**2〜6か月の訓練期間**とされています。訓練分野には、WEBクリエイターやWEBデザイナーを想定したデザイン分野も含まれています。独学の場合は、学習時間の確保や進め方によって、これより短くも長くもなると考えておきましょう。

:::summary この記事で分かること
- Web制作の独学に決まった期間がない理由
- 目的別に、どこまで学べばよいかの目安
- 独学の期間が長くなる原因と、短くする進め方
- スクールや講座を検討するタイミング
:::

## Web制作の独学に決まった期間がない理由

学習期間が人によって大きく変わるのは、次の3つが人によって異なるためです。

| 違い | 期間への影響 |
| --- | --- |
| 目的 | 趣味のサイトか、副業や就職を目指すかで、学ぶ範囲が変わる |
| 学習時間 | 平日と休日にどれくらい時間を取れるかで、進み方が変わる |
| 学び方 | 読むだけか、自分でサイトを作るかで、身につくまでの時間が変わる |

**「何か月で終わるか」より、「何をどこまで学ぶか」を先に決める**ことが、計画を立てる出発点です。ネットで見かける「何か月で習得」という数字は、その人の目的と学習時間での話です。自分と条件が違えば、同じ期間で同じところまで届かなくても、おかしなことではありません。

## 目的別：どこまで学べばいいか

Web制作で目指すことによって、学ぶ範囲は次のように変わります。

| 目的 | 学ぶ範囲の例 |
| --- | --- |
| 趣味で自分のサイトを作りたい | HTMLとCSSの基本、ページの公開方法 |
| 副業で小さな依頼を受けたい | HTML/CSSに加え、スマートフォン対応、JavaScriptの基本、WordPressの扱い |
| Web制作の仕事に就きたい | 上記に加え、デザインツールの操作、制作の流れ、ポートフォリオの作成 |

どの目的でも、**最初に学ぶのはHTMLとCSS**です。ページの構造をHTMLで作り、見た目をCSSで整える基本が身につくと、その先の学習も進めやすくなります。

:::point 目的を決めるときのコツ
- 「どんなサイトを作れるようになりたいか」を具体的に一つ決める
- 副業や就職を目指す場合は、求人や案件で求められているスキルを確認する
- 最初から多くの技術を同時に学ぼうとしない
:::

表にすると範囲が広く見えますが、全部を一度に覚える必要はありません。いま目指すゴールの行だけを見て、そこまでの道のりを考えれば十分です。

副業で始める場合の準備は {{link:kaishain-fukugyo-web-seisaku-hajimekata|会社員の副業Web制作の始め方}} で整理しています。

## 無料で使える教材：MDN Web Docs

Web制作の独学では、無料で使える教材もあります。そのひとつが、Mozillaが提供する「MDN Web Docs」の「ウェブ開発の学習」です。MDNによると、このリソースは、フロントエンド開発者に必要なスキルと実践を学べる構造化されたチュートリアルで、課題や推奨リソースも提供されています。

学習は、次のように段階別に分かれています。

- **入門モジュール**：コードエディターをインストールしたことも、コードを書いたこともない、まったくの初心者向け
- **コアモジュール**：フロントエンド開発者に必要なスキルと実践を学ぶ、構造化されたチュートリアル
- **発展モジュール**：コアモジュールを終えた人が、知識を広げるための追加スキル

MDNは、このコースが学習者を「初心者」から「エキスパート」ではなく、**「初心者」から「慣れ親しむ」ところまで導くもの**だと説明しています。また、学んだ内容を確かめる「確認テスト」や、複数の機能を組み合わせて作る「チャレンジ」も用意されています。

:::warning 無料教材を使うときの注意
無料の教材は、自分で学ぶ順番を決め、分からない点を自分で調べる必要があります。翻訳されたページでは、英語版より情報が古い場合もあるため、更新日を確認しながら進めましょう。
:::

## 独学の期間が長くなる原因

独学で予定より時間がかかる原因は、内容の難しさより、学び方にあることも少なくありません。

:::check 期間が長くなりやすい学び方
- 教材を読んだり動画を見たりするだけで、自分でコードを書いていない
- 複数の教材を行き来して、同じ基礎を何度も学び直している
- 分からないところで長く止まり、調べ方が分からない
- 学んだ内容を使って、自分でサイトを作る機会がない
:::

編集部としては、**教材は一つに絞って最後まで進め、学んだら小さなサイトを自分で作ってみる**ことをおすすめします。これが、期間を短くするいちばんの近道だと考えています。架空のお店のサイトなど、目的を決めて作ると、必要な知識も見えやすくなります。

## Web制作の独学期間を短くする進め方

:::steps 独学の進め方
1. **目的とゴールを決める**：「スマートフォンにも対応した店舗サイトを作れるようになる」のように、具体的なゴールを一つ決めます。
2. **教材を一つ選ぶ**：入門書、動画講座、無料教材などから、ゴールに合うものを一つに絞ります。
3. **HTMLとCSSの基本を学ぶ**：ページの構造と見た目の整え方を、手を動かしながら学びます。
4. **見本を見ながら一つ作る**：教材の例を参考に、一つのページを最後まで作ります。
5. **自分で考えたサイトを作る**：テーマを自分で決め、構成からデザイン、公開まで通して作ります。
6. **学習時間を記録して見直す**：かかった時間を記録し、ゴールまでの残りの期間を見直します。
:::

**実際に進めた時間をもとに、残りの期間を見積もり直す**と、自分に合った計画を立てやすくなります。画面の操作を見ながら学びたい人は、{{aff:learning-online-course|オンライン動画講座}}で、HTML/CSSの基礎から順に学ぶ方法もあります。

## 働きながら学習時間を確保する工夫

社会人が独学でWeb制作を学ぶとき、いちばんの壁になりやすいのは、内容の難しさより時間の確保です。平日は疲れて手がつかず、週末にまとめてやろうとしても、前回の内容を思い出すところから始まってしまう。ここで迷う方は多いです。

### 平日は「短く触れる」、休日は「作る」

平日は、短い時間でもエディターを開いて、前回書いたコードを読み返すだけで構いません。**毎日少しでも触れておくと、休日に作業を再開するときの負担が軽くなります**。休日は、ページを一つ作るなど、まとまった時間が必要な作業にあてると、学習にメリハリがつきます。

### 学習の記録を残す

学習した日と内容を簡単にメモしておくと、どこまで進んだかが目に見えるようになります。思ったより進んでいないと感じたときも、記録があれば、ゴールの範囲を見直すのか、学習時間を増やすのかを落ち着いて判断できます。

### 予定どおりに進まなくても気にしすぎない

仕事が忙しい時期は、計画どおりに進まないこともあります。そんなときは、新しい内容を無理に進めるより、これまで作ったページを少し直すなど、手を止めない工夫をしてみてください。続けていれば、遅れは取り戻せます。

## スクールや講座を検討するタイミング

独学で進めていて、次のような状態になったら、スクールや講座を検討するタイミングかもしれません。

:::merit スクールを使うメリット
- 学ぶ順番が決まっているため、迷わずに進められる
- 分からない点を質問でき、止まる時間を減らせる
- 作品づくりや、就職・副業の支援を受けられる場合がある
:::

:::demerit スクールを使うデメリット
- 独学より費用がかかる
- 決められたカリキュラムに合わせて学習時間を確保する必要がある
- 自分の目的と合わないコースを選ぶと、費用に見合わないことがある
:::

就職を目指す場合は、公的な職業訓練も選択肢です。JEEDによると、求職者支援訓練は雇用保険を受給できない求職者などを対象とし、受講料は原則無料（テキスト代などは自己負担）とされています。職業訓練の特徴は {{link:hello-training-hyouban|ハロートレーニングの評判}}、スクールの必要性は {{link:web-designer-mikeiken-school-hitsuyou|未経験からWebデザイナーにスクールは必要？}} で比べています。

決められた期間で集中して学びたい人は、{{aff:school-webdesign|スクールの無料カウンセリング}}で、目的に合うコースや学習期間の目安を相談してみてください。

## 迷ったときの次の一歩

どれくらいかかるか分からないまま始めるのは、誰にとっても落ち着かないものです。まずは一週間だけ、一つの教材でHTMLとCSSに触れ、かかった時間を記録してみてください。その記録があれば、自分に合う期間の見通しが立ちますし、独学で続けるか、講座やスクールを使うかも判断しやすくなります。

スクールの無料カウンセリングも、話を聞いてみて合わなければ見送って構いません。独学で進めると決めるための材料として使うのも、ひとつの使い方です。

## よくある質問

### Web制作の独学には何ヶ月かかる？

目的と学習時間によって変わるため、決まった期間はありません。参考として、公的な求職者支援訓練の実践コースは2〜6か月の訓練期間とされています。まずはゴールを決め、教材を進めた時間をもとに残りの期間を見積もりましょう。

### Web制作は独学でできる？

できます。MDN Web Docsの「ウェブ開発の学習」のように、まったくの初心者向けの入門から学べる無料の教材もあります。ただし、学ぶ順番や分からない点の調べ方を自分で決める必要があります。

### Web制作の独学は何から始めればいい？

まずはHTMLとCSSの基本から始めるのがおすすめです。ページの構造と見た目の整え方を学び、小さなページを一つ作ってみると、次に学ぶことが見えてきます。

### 独学とスクールはどちらが早く身につく？

人によって異なります。自分で調べて進められる人は独学でも進められますが、分からない点で止まりやすい人は、質問できるスクールのほうが止まる時間を減らせる場合があります。
