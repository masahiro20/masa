家電や車のように、身近な機械を動かすソフトウェアを作ってみたい。そう思って組み込み開発を調べてみると、「C言語は難しい」「ポインタで挫折する」という声ばかりが目に入ってくる。自分に続けられるのか不安になっている。そんな場面を想定して書きました。前評判に気持ちが引いてしまうのは、ごく自然なことです。

組み込み開発のC言語が難しいと言われるのは、**C言語そのものの難しさ（ポインタやメモリの扱い）に加えて、ハードウェアの知識や、限られた資源で確実に動かす工夫が求められる**からです。ただし、難しさの正体が分かれば、どこから順に学べばよいかも見えてきます。

学ぶときは、**まずパソコン上でC言語の基本を固め、次にマイコンボードなどで実際に機器を動かしてみる**順番が取り組みやすい方法です。品質の良いコードの書き方については、IPA（情報処理推進機構）が組み込み向けのコーディング作法ガイドを公開しており、学習の参考にできます。

## 組み込みのC言語が難しいと言われる理由

組み込み開発の難しさは、いくつかの要素が重なっていることにあります。

| 難しさの種類 | 内容 |
| --- | --- |
| C言語そのもの | ポインタやメモリの管理など、プログラマが自分で気をつける部分が多い |
| ハードウェアの知識 | マイコンのしくみ、電子回路、センサーなどの基礎が必要になる |
| 限られた資源 | メモリや処理能力が限られた中で、確実に動くように作る必要がある |
| 確かめにくさ | 機器の上で動くため、パソコンのアプリより動作の確認がしにくいことがある |
| 品質への要求 | 製品に組み込まれるため、不具合が大きな影響につながることがある |

結局のところ、**「C言語の難しさ」と「組み込みならではの難しさ」は分けて考える**と気持ちが楽になります。どちらも一度に覚えようとすると大変ですが、順番に一つずつ身につければ、着実に前に進めます。

組み込みエンジニアが他の職種とどう違うかは {{link:it-engineer-shokushu-shurui-chigai|ITエンジニアの職種の種類と違い}} で整理しています。

## つまずきやすいポイントと乗り越え方

### ポインタとメモリの扱い

C言語でつまずく人が多いのが、ポインタです。変数がメモリのどこにあるのかを意識する必要があり、最初は抽象的に感じやすい部分です。**図を描いて、メモリのどこに何が入っているかを書き出しながら学ぶ**と、理解しやすくなります。

### ハードウェアとの関係

組み込み開発では、プログラムでマイコンの入出力を操作し、LEDを光らせたり、センサーの値を読んだりします。ソフトウェアだけでなく、**電気やマイコンの基本的なしくみ**も少しずつ学んでいく必要があります。

### 不具合の原因が見えにくい

パソコンのプログラムと違い、機器の上では画面にエラーが表示されないこともあります。どこで止まっているのかを確かめる方法（デバッグの方法）を早めに身につけておくと、つまずいたときに立て直しやすくなります。

:::warning 「難しい」と感じるのは自然なこと
組み込みのC言語は、複数の分野の知識が組み合わさっているため、最初に難しく感じるのは当然です。分からない部分があっても、それが自分に向いていない証拠ではありません。一つずつ分けて理解していけば大丈夫です。
:::

## IPAのコーディング作法ガイド（ESCR）を活かす

IPAは、「組込みソフトウェア開発向けコーディング作法ガイド［C言語版］ESCR Ver.3.0」を公開しています。IPAのページによると、本書はC言語を用いて開発されるソフトウェアのソースコードの品質をより良いものとするために、**コーディングの際に注意すべきことやノウハウを紹介**するものです（2018年6月29日発行、PDFでダウンロード可能）。

Ver.3.0では、従来からの「ソースコードの標準化や品質の均一化を進めること」に加えて、**「ソフトウェアの脆弱性作りこみを回避すること」**も目的とし、ルールや解説、適合例・不適合例などが追加されたと説明されています。なお、同ページでは、本事業は終了しているため問い合わせには対応できないと案内されています（2024年4月時点の情報とされています）。

**初心者がいきなり全部を読む必要はありません**。C言語の基本を一通り学んだあとに、「なぜこの書き方は避けたほうがよいのか」を確かめる資料として使うと、現場で求められる品質の考え方に触れられます。

:::point ESCRを学習に使うときのコツ
- C言語の基本を一通り学んでから読む
- 適合例と不適合例を見比べ、なぜその書き方が勧められるのかを考える
- 自分の書いたコードを、ガイドの観点で見直してみる
:::

## 組み込みのC言語を学ぶ順番

:::steps 組み込み開発を目指す学び方
1. **パソコンでC言語の基本を学ぶ**：変数、条件分岐、繰り返し、関数、配列を書けるようにします。
2. **ポインタと構造体を理解する**：図を描きながら、メモリのしくみと合わせて学びます。
3. **マイコンボードを動かしてみる**：入門向けのマイコンボードで、LEDを光らせる、ボタンの入力を読むなどを試します。
4. **ハードウェアの基礎を学ぶ**：電子回路やセンサーのしくみを、作りたいものに合わせて少しずつ学びます。
5. **コードの品質を意識する**：IPAのコーディング作法ガイドなどを参考に、読みやすく安全なコードの書き方を身につけます。
:::

**パソコンで基本を固めてから機器に進む**と、つまずいたときに「C言語の問題か」「ハードウェアの問題か」を切り分けやすくなります。入門書の選び方は {{link:programming-nyumonsho-erabikata|プログラミング入門書の選び方}} で整理しています。

## 本と動画講座の使い分け

:::merit 本で学ぶ良さ
- ポインタやメモリのしくみを、図と文章でじっくり理解できる
- 組み込み向けの本なら、マイコンの話まで一冊で通して学べる
- 分からないところに何度も戻って読み返せる
:::

:::demerit 本だけで進めるときの注意点
- 開発環境の準備や、ボードへの書き込みの手順は画面で見たほうが分かりやすいことがある
- 本で使っているボードやツールが、手元のものと違う場合がある
- 一人で進めるため、つまずいたところで止まりやすい
:::

## 組み込みエンジニアとして仕事にするには

IPAには、組み込みシステムの開発に関する高度な国家試験として、エンベデッドシステムスペシャリスト試験があります。対象者像は、IoTを含む組込みシステムの開発に関係する広い知識や技能を活用して、事業戦略や製品戦略の策定、要求仕様の策定、設計・構築・製造を主導的に行う人とされています。**最初から目指す試験ではありませんが、組み込みの仕事でどんな力が求められるかを知る手がかり**になります。

未経験から組み込みの仕事を目指す場合は、学習と並行して求人を見て、求められているスキルを確認しておきましょう。組み込みの求人は、家電や自動車、産業機器などのメーカーや、その開発を担う会社で多く見られます。

編集部としては、**組み込みを目指すなら、C言語の学習を始めると同時に、メーカーの求人で求められているスキルを確認しておく**ことをおすすめします。求人に書かれている言葉を知るだけでも、何を優先して学ぶべきかが見えやすくなるからです。

組み込みの転職でエージェントを選ぶコツは {{link:kumikomi-engineer-tenshoku-agent|組み込みエンジニアの転職エージェントの選び方}} で整理しています。製造業やメーカーの求人に詳しい相談先を探している人は、{{aff:career-maker-agent|メーカーズジョブ（製造業・メーカー専門の転職エージェント）}}で、自分の経歴で応募できる組み込みの求人や、求められるスキルを聞いてみる方法もあります。

## 迷ったときの次の一歩

迷ったら、まずはパソコンでC言語の簡単なプログラムを一つ書いて動かしてみてください。画面に文字を表示するだけでも構いません。そこから少しずつポインタやマイコンへと進んでいけば、組み込み開発の難しさも一つずつ小さくなっていきます。

教材や相談サービスは、自分に合わなければ見送って構いません。自分のペースで、続けられる学び方を選びましょう。

## よくある質問

### C言語の組み込みはなぜ難しいと言われる？

C言語そのもののポインタやメモリの扱いに加えて、ハードウェアの知識や、限られた資源の中で確実に動かす工夫が求められるためです。C言語の難しさと組み込みならではの難しさを分けて、一つずつ学ぶと進めやすくなります。

### 組み込みのC言語は何から勉強すればいい？

まずはパソコンでC言語の基本（変数、条件分岐、繰り返し、関数、配列）を学び、次にポインタと構造体を理解しましょう。そのあと、入門向けのマイコンボードで実際に機器を動かしてみるのがおすすめです。

### 組み込みのC言語の練習方法は？

入門向けのマイコンボードで、LEDを光らせる、ボタンの入力を読むといった小さな課題から始める方法があります。慣れてきたら、IPAのコーディング作法ガイド（ESCR）を参考に、自分のコードを見直してみましょう。

### 組み込み開発に役立つ公的な資料はある？

IPAが「組込みソフトウェア開発向けコーディング作法ガイド［C言語版］ESCR Ver.3.0」を公開しています。コーディングの際に注意すべきことやノウハウ、適合例・不適合例などがまとめられており、PDFでダウンロードできます。

### 未経験から組み込みエンジニアになれる？

学習を進めながら、メーカーなどの求人で求められているスキルを確認し、それに合わせて準備することが大切です。製造業やメーカーに詳しい転職エージェントに相談し、自分の経歴で応募できる求人を聞いてみる方法もあります。
