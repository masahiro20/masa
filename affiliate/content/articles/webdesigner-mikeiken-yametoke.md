Webデザイナーに未経験からなるのが「やめとけ」と言われるのは、**デザインだけでなくコーディングやツールの操作など学ぶことが多いこと、未経験でも作品（ポートフォリオ）で実力を示す必要があること、思い描いていた働き方と現実に差が出やすいこと**などが理由です。

ただし、これは「未経験では無理」という意味ではありません。**学ぶ範囲と目指す働き方を具体的にし、作品を作り続けられる人**にとっては、未経験からでも目指せる仕事です。大切なのは、イメージだけで決めずに、自分に合うかどうかを判断してから進むことです。

## Webデザイナーに未経験は「やめとけ」と言われる5つの理由

主な理由を整理すると、次の5つです。

| 理由 | 内容 |
| --- | --- |
| 1. 学ぶことが多い | デザインの基礎、ツール操作、HTML/CSSなど幅広い |
| 2. 作品で実力を示す必要がある | 資格や学習歴だけでなく、ポートフォリオが重視されやすい |
| 3. 「おしゃれな仕事」のイメージとの差 | 修正対応や地道な作業も多い |
| 4. 学び続ける必要がある | ツールや表現のトレンドが変わり続ける |
| 5. 働き方の希望が叶うとは限らない | 在宅・副業などの希望は、経験や実績次第になりやすい |

### 1. 学ぶことが多い

Webデザイナーの仕事では、配色やレイアウトなどのデザインの基礎に加え、デザインツールの操作、HTML/CSSによるコーディング、スマートフォンでの見え方への対応など、幅広い知識が求められることがあります。**「絵を描くのが好き」だけでは足りず、仕組みを理解する学習も必要**です。

### 2. 作品で実力を示す必要がある

未経験からの応募では、学習した証拠として作品が見られることが多くなります。**ポートフォリオがない、または練習作品を並べただけの状態**では、選考で苦戦しやすくなります。

### 3. 「おしゃれな仕事」のイメージとの差

Webデザインの仕事は、クライアントの要望をもとに作り、修正を重ねていく地道な作業も多くあります。自分の好きなデザインを自由に作れる場面ばかりではない点は、知っておきたいポイントです。クライアントや利用者にとって分かりやすいか、目的を達成できるかを優先して考える場面が多く、自分の好みと異なるデザインを求められることもあります。こうした調整の過程を楽しめるかどうかも、向き不向きを判断する材料になります。

### 4. 学び続ける必要がある

ツールの機能や、Webサイトの見せ方の流行は変わり続けます。一度学んで終わりではなく、**仕事を始めてからも学び続ける姿勢**が求められます。

### 5. 働き方の希望が叶うとは限らない

検索では「webデザイナー やめとけ 主婦」「webデザイナー 副業 やめとけ」なども調べられています。在宅や副業で働きたいという希望は多いものの、未経験のうちは案件や求人が限られ、実績を積んでから選択肢が広がることが一般的です。副業で稼ぐことの難しさは {{link:web-seisaku-fukugyo-kasegenai|Web制作の副業が稼げないのはなぜ？}} でも整理しています。

:::warning 「簡単に在宅で稼げる」という宣伝に注意
「未経験でもすぐに在宅で稼げる」といった宣伝を見かけることがありますが、実際には学習と実績づくりに時間がかかるのが一般的です。高額な講座を契約する前に、内容と自分の目的が合っているかを冷静に確認しましょう。
:::

## Webデザイナーに向いている人・向いていない人

:::merit 向いている人
- 作ること自体が好きで、試行錯誤を楽しめる
- 相手の要望を聞き、形にすることにやりがいを感じる
- 地道な修正や細かい調整も苦にならない
- 新しいツールや表現を学び続けられる
:::

:::demerit 向いていない可能性がある人
- 自分の好きなデザインだけを作りたい
- 学習に時間をかけず、すぐに収入を得たい
- 修正の指示や意見を受けることに強いストレスを感じる
- パソコンでの細かい作業を長時間続けるのが苦手
:::

**「やめとけ」に当てはまるかどうかは、性格よりも「何を期待しているか」で決まる部分が大きい**と言えます。仕事の現実を知ったうえで、それでもやってみたいと思えるかを考えてみましょう。

30代から目指す場合の考え方は {{link:webdesigner-mikeiken-30dai-muri|Webデザイナーに未経験30代は無理？}} で詳しく解説しています。

## 独学・スクール・職業訓練の選び方

Webデザインを学ぶ方法は、主に3つあります。

| 方法 | 特徴 | 向いている人 |
| --- | --- | --- |
| 独学 | 費用を抑えられる。自分で計画を立てる必要がある | 自分で調べて学べる人 |
| スクール | カリキュラムと質問できる環境がある。費用がかかる | 短期間で体系的に学びたい人 |
| 職業訓練 | 公的な訓練。条件を満たせば受講料が抑えられる | 就職を目指していて、条件を満たす人 |

独立行政法人高齢・障害・求職者雇用支援機構（JEED）によると、求職者支援訓練は、雇用保険を受給できない求職者などを対象に、民間教育訓練機関が厚生労働大臣の認定を受けて実施する職業訓練で、**受講料は原則無料（テキスト代などは自己負担）**とされています。一定の要件を満たせば、訓練期間中に月10万円の「職業訓練受講給付金」を受けられる場合があることも案内されています。

スクールを利用する場合は、厚生労働省の教育訓練給付金の対象講座を選ぶと、受講費用の一部が支給される場合があります。たとえば一般教育訓練は、教育訓練経費の20%（上限10万円）が訓練修了後に支給されると案内されています。{{aff:school-kyufukin|給付金対象の講座}}から探すと、費用を抑えやすくなります。

スクールが必要かどうかの判断は、{{link:web-designer-mikeiken-school-hitsuyou|未経験からWebデザイナーにスクールは必要？}} で比較しています。

## 未経験者のポートフォリオで意識したいこと

未経験からWebデザイナーを目指すとき、ポートフォリオは学習の成果を伝える大切な材料です。作品の見た目だけでなく、次のような点も伝わるようにしておきましょう。

- **作品の目的**：誰に向けた、何のためのサイトなのか（架空の設定でもよい）
- **工夫した点**：配色やレイアウト、文字の大きさなどを、なぜそう決めたのか
- **担当した範囲**：デザインだけか、コーディングまで自分で行ったのか
- **制作期間と使ったツール**：どのくらいの期間で、何を使って作ったのか

**「なぜそのデザインにしたのか」を言葉で説明できると、未経験でも考える力が伝わりやすくなります**。作品の数を増やすことよりも、一つひとつの作品で意図を説明できる状態を目指しましょう。

また、他の人が作ったデザインをそのまま真似した作品を、自分のオリジナルとして載せるのは避けましょう。練習として模写をした場合は、模写であることを明記するか、自分で考えた作品を中心に掲載するのが安心です。

## 後悔しないための判断基準

「やめとけ」と言われても、目指すかどうかは自分で判断するものです。次のチェックリストで、今の自分の状況を確認してみましょう。

:::check 目指す前に確認したいこと
- Webデザイナーの仕事内容（修正対応やコーディングも含む）を理解しているか
- 学習に使える時間を、週単位で確保できるか
- 学習と作品づくりに数か月以上かかる前提で計画を立てられるか
- 目指す働き方（会社員・副業・フリーランス）が具体的になっているか
- 学習費用を、無理のない範囲で用意できるか
:::

**まずは無料の教材や短期間の学習で、実際に手を動かして作ってみる**のがおすすめです。作ることが楽しいと感じられれば続けやすく、合わないと感じたら早めに方向を見直せます。

## 未経験からWebデザイナーを目指す流れ

:::steps 目指すときの進め方
1. **仕事内容を調べる**：Webデザイナーの業務範囲や、求人で求められるスキルを確認します。
2. **小さく学び始める**：無料の教材や入門書で、デザインの基礎とHTML/CSSに触れてみます。
3. **学習方法を決める**：独学・スクール・職業訓練から、自分の状況に合うものを選びます。
4. **作品を作る**：架空のお店のサイトなど、目的が伝わる作品を複数作ります。
5. **応募・案件探し**：ポートフォリオをまとめ、求人への応募や小さな案件から始めます。
:::

スクールを検討するなら、複数のスクールで無料カウンセリングを受け、カリキュラムの内容、作品制作のサポート、就職・転職支援の有無を比べることが大切です。{{aff:school-webdesign|スクールの無料カウンセリング}}で、目指す働き方に合うコースかどうかを確認してみてください。

## よくある質問

### Webデザイナーはやめとけって本当？

学ぶことが多く、作品で実力を示す必要があるため、イメージだけで目指すと後悔しやすいのは事実です。一方で、作ることが好きで学び続けられる人にとっては、未経験からでも目指せる仕事です。

### Webデザイナーはなぜやめとけと言われる？

デザインだけでなくコーディングなど学ぶ範囲が広いこと、未経験でもポートフォリオが重視されること、修正対応など地道な作業が多いこと、在宅や副業の希望がすぐには叶いにくいことなどが理由として挙げられます。

### 主婦が未経験からWebデザイナーを目指すのはやめとけ？

時間の使い方を工夫しながら学ぶ人もいますが、在宅での仕事は実績を積んでから広がることが一般的です。学習時間を確保できるか、どのような働き方を目指すかを具体的に考えてから始めましょう。

### 職業訓練でWebデザイナーを目指すのはやめとけ？

職業訓練は、条件を満たせば受講料を抑えて学べる選択肢です。ただし、訓練期間や内容はコースによって異なるため、自分の目指す働き方に必要なスキルを学べるかを事前に確認しましょう。
