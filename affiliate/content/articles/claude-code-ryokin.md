Claude Codeの料金は、**Claudeの有料プラン（Pro・Max・Team・Enterprise）に含まれる形で使うか、Claude Consoleのアカウントで使った分だけ支払うAPI従量課金で使うか**の2通りです。公式の料金ページでは、Claude Codeは無料プランでは利用できず、すべての有料プランに含まれると案内されています。

個人なら、まずは**Proプラン（年払いで月あたり17米ドル、月払いで20米ドル）**から始め、使用量が足りなくなったらMaxプランを検討するのが基本の流れです。法人やチームで使うなら、TeamプランやEnterpriseプラン、またはAPIでの利用を比べて選びます。

:::summary この記事で分かること
- Claude Codeは無料で使えるのか、どのプランで使えるのか
- 個人向け（Pro・Max）と法人向け（Team・Enterprise）の料金と違い
- API従量課金の考え方と、公式が示すコストの目安
- 使用量の上限と確認方法、自分に合うプランの選び方
:::

※本記事の料金は、2026年10月時点のAnthropic公式料金ページに掲載された米ドル建ての金額です。料金ページには、表示価格に税金は含まれず、価格やプランは変更される場合があると記載されています。日本円での支払額は為替や税金によって変わるため、申し込み時に公式サイトで確認してください。

## Claude Codeの料金は「有料プラン」か「API従量課金」

Claude Codeの公式ドキュメント「コストを効果的に管理する」では、Claude CodeはAPIトークンの消費によって課金され、サブスクリプションプランの価格はclaude.com/pricingを参照するよう案内されています。使い方は大きく2つに分かれます。

| 使い方 | 支払い方 | 向いている人 |
| --- | --- | --- |
| Claudeの有料プランで使う | 月額（または年額）の定額。プランの使用量の範囲で利用 | 個人で日常的に使いたい人、チームでまとめて契約したい組織 |
| Claude Consoleのアカウントで使う（API） | 使ったトークン量に応じた従量課金 | 利用量に応じて支払いたい人、自社の仕組みに組み込みたい開発者 |

**定額で使用量の上限がある「プラン」か、使った分だけ払う「API」か**が、料金を考えるときの最初の分かれ道です。

## Claude Codeは無料プランで使える？

公式料金ページの機能比較表では、Claude Codeは無料（Free）プランでは「No」、Pro・Max 5x・Max 20xでは「Yes」とされています。また、よくある質問では「Claude Codeはすべての有料プランに含まれる」と説明されています。

つまり、**Claude Codeを使うには有料プランの契約か、APIの利用が必要**です。無料で試せるAIコーディングツールを探している場合は、{{link:ai-coding-muryo-osusume|AIコーディングのおすすめ無料ツール}} も参考にしてください。

## 個人向けプランの料金：ProとMax

公式料金ページに掲載されている個人向けプランは次のとおりです（税別・米ドル）。

| プラン | 料金 | 主な内容 |
| --- | --- | --- |
| Free | 0ドル | Claude Codeは利用不可 |
| Pro | 年払いで月あたり17ドル（年額200ドルを前払い）、月払いなら20ドル | Freeの内容に加え、より多くの使用量。Claude Codeを含む |
| Max | 月額100ドルから | Proの内容に加え、Proの5倍または20倍の使用量を選べる。混雑時の優先アクセスなど |

Maxプランは、使用量がProの5倍の「Max 5x」と20倍の「Max 20x」から選べます。比較表では、Max 5xには月100ドル、Max 20xには月200ドルのAPIクレジットが付くことも記載されています。

:::point 個人はどのプランを選ぶ？
- まず試したい・使用頻度が中程度：Proプラン
- 毎日長時間使い、Proの使用量では足りない：Maxプラン（5xまたは20x）
- 利用量に波があり、使った分だけ払いたい：API従量課金
:::

## 法人・チーム向けプランの料金：TeamとEnterprise

検索では「claude code 料金 法人」「claude code 料金 team」もよく調べられています。公式料金ページに掲載されている法人向けプランは次のとおりです（税別・米ドル）。

| プラン | 料金 | 主な内容 |
| --- | --- | --- |
| Team（スタンダードシート） | 年払いで1シートあたり月20ドル、月払いなら25ドル | 2〜150人のチーム向け。Proより多い使用量。Claude Codeを含む |
| Team（プレミアムシート） | 年払いで1シートあたり月100ドル、月払いなら125ドル | スタンダードシートの5倍の使用量 |
| Enterprise | 年払いで1シートあたり月20ドル＋API料金での使用量課金（20シートから） | 大規模組織向け。管理者による利用額の上限設定などの機能 |

Teamプランは、スタンダードシートとプレミアムシートを組み合わせて契約できると案内されています。Enterpriseプランは、シート料金に加えて、使ったモデルやタスクに応じてAPI料金で使用量が課金される仕組みです。

## API従量課金の考え方と、公式が示すコストの目安

API（Claude Consoleのアカウント）で使う場合は、使ったトークン量とモデルの単価で料金が決まります。モデルごとの単価は公式料金ページの「API」の項目に掲載されています。

公式ドキュメントでは、開発者あたりのコストは、モデルの選択、コードベースの大きさ、複数のインスタンスの実行や自動化などの使い方によって大きく異なると説明されています。そのうえで、**エンタープライズへの導入全体では、平均コストは開発者1人あたり1稼働日約13ドル、月額150〜250ドルで、90%のユーザーは1稼働日あたり30ドル以下**という目安が示されています。

自分やチームの支出を見積もるには、小規模なグループで試して基準を作ってから広げることが推奨されています。

:::warning 従量課金は使い方で金額が大きく変わる
API従量課金では、長い作業や大きなコードベースを扱うほど、使用するトークンが増えて料金も上がります。自動化や複数の作業を並行して動かす場合は特に、利用状況を確認しながら使いましょう。
:::

## 使用量の上限と確認方法

有料プランには使用量の上限があります。公式料金ページのよくある質問によると、使用量の上限は5時間ごとのセッション枠でリセットされ、有料プランでは週単位の上限も加わります。また、**Web・デスクトップ・モバイルのClaudeとClaude Codeの利用は、同じ使用量の枠から消費される**と説明されています。

上限に達した場合は、上位プランに切り替えるか、有料プランでは「使用量クレジット」を有効にしてAPI料金で使い続けられると案内されています。現在の利用状況は、設定の「使用量」画面で確認できます。

Claude Codeの中では、`/usage` コマンドで利用状況を確認できます。公式ドキュメントによると、ProやMaxの契約者には、プランの使用量バーや使用量の内訳が表示されます。

:::check 料金で失敗しないためのチェックリスト
- 自分の使い方は「毎日長時間」か「ときどき」か
- ChatのClaudeとClaude Codeを同じ使用量の枠で使うことを理解したか
- 使用量クレジットやAPI従量課金を使う場合、上限額の管理方法を確認したか
- 年払いと月払いのどちらにするか（年払いは前払い）
- 法人なら、必要な人数と管理機能に合うプランか
:::

## 料金に見合う使い方をするには

有料のツールである以上、料金に見合う成果を得るには使い方の工夫が欠かせません。

:::merit 有料プランで使うメリット
- 定額で、毎月の費用の見通しを立てやすい
- ChatのClaudeとClaude Codeをまとめて使える
- 上位プランに切り替えて使用量を増やせる
:::

:::demerit 気をつけたい点
- 使用量の上限があり、使い方によっては足りなくなる
- 使いこなせないと、料金に見合う効果を感じにくい
- 米ドル建てのため、為替によって日本円の支払額が変わる
:::

公式ドキュメントでは、コンテキストの管理やモデルの選択などで、トークン使用量を減らす方法も紹介されています。効果的な使い方は {{link:ai-kudou-kaihatsu-manabikata-engineer|AI駆動開発の学び方}} で、研修の選び方は {{link:claude-code-kenshu-kojin-osusume|Claude Code研修は個人でも受けられる？}} で整理しています。

**せっかく料金を払うなら、早い段階で使い方の型を身につけておく**と、同じ使用量でもできることが増えます。{{aff:learning-ai-coding|Claude Codeを実践的に学べる研修}}で、効率的な使い方を短期間で学ぶのも一つの方法です。

## よくある質問

### Claude Codeは無料で使える？

公式料金ページでは、Claude Codeは無料プランでは利用できず、すべての有料プランに含まれると案内されています。使うには、Proなどの有料プランを契約するか、Claude ConsoleのアカウントでAPI従量課金で利用する必要があります。

### Claude Codeの料金は日本円でいくら？

公式料金ページは米ドル建てで、表示価格に税金は含まれていません。日本円での支払額は為替レートや税金によって変わるため、申し込み時に公式サイトで最終的な金額を確認してください。

### Claude Codeの個人向けと法人向けの料金の違いは？

個人向けはProプランとMaxプラン、法人向けはTeamプランとEnterpriseプランがあります。Teamプランは2〜150人のチーム向けで1シートあたりの料金、Enterpriseプランはシート料金に加えてAPI料金で使用量が課金される仕組みです。

### Claude Codeの料金プランは途中で変更できる？

使用量が足りない場合は、上位プランに切り替えることができると公式に案内されています。変更や解約の手順は、Claudeのヘルプセンターで確認してください。
