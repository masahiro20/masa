仕事から帰って夕食を済ませると、もう夜の9時過ぎ。パソコンを開く気力が残っていなくて、今日もプログラミングの教材に手をつけられなかった。そんな日が続いて、自分には向いていないのではと落ち込んでいる。そんな場面を想定して書きました。働きながら学ぶのは、思っているよりずっと大変なことです。

働きながらプログラミングの学習時間を確保するには、**「新しく時間を作る」より「今ある時間の使い方を変える」**ことから始めるのが現実的です。具体的には、**学ぶ時間帯を固定する、平日と休日で役割を分ける、一回の学習を短く区切る、学習を始めるまでの手間を減らす、続けられる量で計画を立てる**、といった工夫が役立ちます。

学習時間が取れないのは、意志の弱さではなく、仕組みの問題であることがほとんどです。この記事では、社会人の学習の実態も確認しながら、時間を確保する方法を整理します。

## 統計で見る、学び続ける人の実態

総務省統計局の「令和3年社会生活基本調査」によると、学業以外で「学習・自己啓発・訓練」を過去1年間に行った人の割合（行動者率）は39.6%で、5年前より2.7ポイント上昇しています。同調査では、学習・自己啓発・訓練の種類別にみると、男性では「パソコンなどの情報処理」の行動者率が最も高いことも示されています。

なお、ここでいう「学習・自己啓発・訓練」には、社会人の職場研修や、学生が学業として行うものは含まれていません。**仕事以外の時間を使って、自分で学んでいる人は決して少なくない**ことが分かります。

一方で、学び始めた人がみな同じように続けられているわけではありません。**続けられる人と止まってしまう人の違いは、時間の量より、時間の使い方の仕組みにある**ことが多いと考えられます。

## 働きながら学習時間を確保する5つの方法

:::steps 学習時間を確保する方法
1. **学ぶ時間帯を固定する**：朝の出勤前、昼休み、帰宅後など、毎日同じ時間帯を学習にあてます。
2. **平日と休日で役割を分ける**：平日は短い時間で教材を進め、休日はまとまった作業にあてます。
3. **一回の学習を短く区切る**：長時間まとめてやろうとせず、短い単位で区切って進めます。
4. **始めるまでの手間を減らす**：教材を開いたままにする、作業の続きをメモしておくなど、すぐ再開できる状態を作ります。
5. **続けられる量で計画を立てる**：無理のない量から始め、余裕があれば増やします。
:::

### 1. 学ぶ時間帯を固定する

「時間が空いたらやろう」と考えていると、結局ほかの用事に時間を取られてしまいがちです。**毎日同じ時間帯を学習の時間と決めておく**と、習慣になりやすくなります。仕事の後は疲れて集中できないという人は、出勤前の時間を試してみるのも一つの方法です。

### 2. 平日と休日で役割を分ける

平日の短い時間は、新しい内容を少し読み進める、前回のコードを見直すといった軽い作業にあてます。休日のまとまった時間は、作品づくりや、時間のかかる課題にあてると、限られた時間を活かしやすくなります。

### 3. 一回の学習を短く区切る

「最低でも何時間はやらないと」と考えると、始めるハードルが上がります。**短い時間でも、毎日触れることを優先する**ほうが、前回の内容を忘れにくく、結果として学習が進みやすくなります。

### 4. 始めるまでの手間を減らす

パソコンを立ち上げ、教材を探し、どこまで進んだかを思い出す。この準備に時間がかかると、それだけで疲れてしまいます。学習を終えるときに「次にやること」を一行メモしておくと、次回すぐに再開できます。

### 5. 続けられる量で計画を立てる

最初から多くの量を計画すると、崩れたときに挫折しやすくなります。**「これなら毎日できる」と思える量から始め、慣れてきたら少しずつ増やす**のが続けるコツです。

## 学習時間を生み出すために見直したいこと

新しく時間を作るのが難しいときは、今の一日の中で「なんとなく使っている時間」を見直してみましょう。ここで迷う方は多いので、見直しやすいポイントを挙げておきます。

### スマートフォンを見ている時間

寝る前や移動中に、なんとなくスマートフォンを見ている時間は意外と長いものです。そのうちの一部を、学習した内容の見直しや、用語の確認にあてるだけでも、学習に触れる時間を増やせます。

### 家事や用事のまとめ方

買い物や家事をまとめて済ませる日を決めると、平日の夜に少しだけ時間が生まれることがあります。家族と分担を相談できる場合は、学習の時間帯について話し合っておくのも一つの方法です。

### 「完璧に準備してから」をやめる

机をきれいにしてから、まとまった時間が取れてから、と準備を整えようとすると、始めるまでに時間がかかります。**準備が完璧でなくても、まず教材を開いてみる**ことが、学習時間を確保するいちばんの近道です。

## 平日と休日の使い分けの例

| 時間帯 | やることの例 |
| --- | --- |
| 平日の朝 | 前日の内容を見直す、教材を少し読み進める |
| 平日の昼休み | 用語を調べる、気になったことをメモする |
| 平日の夜 | 短いコードを書いて動かす |
| 休日 | 作品づくり、まとまった課題に取り組む |

これはあくまで一例です。**自分の生活のリズムに合わせて、無理なく続けられる組み合わせを探す**ことが大切です。家族がいる人は、学習の時間帯を共有しておくと、協力してもらいやすくなります。

:::point 時間を確保するときのコツ
- 「新しい時間を作る」より「今ある時間の使い方を変える」から始める
- 学習時間の長さより、毎日触れることを優先する
- 次にやることをメモして、再開の手間を減らす
:::

## 続かなくなったときの立て直し方

仕事が忙しい時期や体調がすぐれない時期は、思うように学習できないこともあります。ここで迷う方は多いのですが、一度止まったからといって、すべてが無駄になるわけではありません。

:::warning 止まった日を責めすぎない
学習できなかった日が続くと、「自分には向いていない」と感じてしまうことがあります。ただ、働きながら学ぶ以上、計画どおりに進まない時期があるのは当然です。止まった理由を振り返り、計画を立て直すことに目を向けましょう。
:::

### 一つ前の内容から再開する

しばらく空いたあとは、新しい内容に進む前に、一つ前の内容を軽く見直してから再開しましょう。前の内容を思い出すことで、スムーズに学習の流れに戻れます。

### 計画の量を見直す

止まった原因が「計画の量が多すぎた」ことにある場合は、思い切って量を減らしましょう。続けられる量に戻すことで、再び習慣にしやすくなります。

### 学ぶ目的を思い出す

なぜプログラミングを学ぼうと思ったのかを、改めて書き出してみるのも一つの方法です。転職したい、仕事を効率化したいなど、目的を思い出すと、もう一度取り組む気持ちが戻ってくることがあります。

## 時間を短く済ませる教材の選び方

限られた時間で学ぶには、教材選びも大切です。

:::merit 動画講座が向いている場面
- 環境構築や操作の手順を、画面を見ながら確認したい
- 短い動画単位で区切って、少しずつ進めたい
- 通勤中などに内容を確認したい
:::

:::demerit 動画講座で気をつけたいこと
- 見ているだけで分かった気になりやすい
- 自分で手を動かす時間を別に確保する必要がある
- 講座ごとに内容や新しさが違う
:::

編集部としては、**教材を一つに絞り、「毎日少しでも進める」ことを最優先にする**ことをおすすめします。教材をあれこれ探す時間も、働きながら学ぶ人にとっては貴重な時間だからです。

## 迷ったときの次の一歩

今日からできることを一つ選ぶなら、明日の学習の時間帯を一つだけ決めて、手帳やスマートフォンの予定に入れてみてください。時間を決めるだけで、学習を始めるハードルは少し下がります。

教材や講座は、自分に合わなければ見送って構いません。続けられる形を、自分のペースで探していきましょう。

## よくある質問

### 働きながらプログラミングを学ぶ時間はどう作る？

学ぶ時間帯を固定する、平日と休日で役割を分ける、一回の学習を短く区切る、再開の手間を減らす、続けられる量で計画を立てる、といった方法があります。新しく時間を作るより、今ある時間の使い方を変えることから始めるのが現実的です。

### 仕事が忙しくてプログラミングの勉強が続かないときは？

計画の量を減らし、一つ前の内容から再開するのがおすすめです。止まった日を責めすぎず、続けられる形に計画を立て直しましょう。学ぶ目的を書き出して思い出すのも一つの方法です。

### 働きながらのプログラミング学習は朝と夜どちらがいい？

人によって向いている時間帯は異なります。仕事の後に疲れて集中できない人は、出勤前の時間を試してみるのも一つの方法です。大切なのは、毎日同じ時間帯に学ぶ習慣を作ることです。

### 働きながら無料でプログラミングを学べる？

無料で使える教材や公式ドキュメントもあります。ただし、教材を探す時間も貴重なため、メインの教材を一つ決めて進めることが大切です。必要に応じて、本や動画講座を組み合わせましょう。
