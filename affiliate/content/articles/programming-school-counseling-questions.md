無料カウンセリングは「説明を聞く場」ではなく、**こちらから質問して情報を取りに行く場**です。受講料が総額数十万円規模になるケースは珍しくなく、ミスマッチ時の金銭的ダメージが大きいと指摘されています（侍エンジニアブログの解説より）。

時間がない人向けに結論から言うと、最低限聞くべきは**「①総額（税込）」「②分割の条件」「③受講料に含まれないもの」「⑦質問対応の時間帯」「⑮就職率の分母と定義」「⑱中途解約時の返金計算」の6つ**。この6つが口頭と書面で一致するかどうかが、最初の判断材料になります。

:::summary この記事でわかること
- 費用／学習内容／転職支援／契約の4領域に分けた質問リスト20と、回答の見極め方
- 教育訓練給付金・リスキリング支援事業を「制度名を指定して」聞くための確認手順
- 「就職率◯%」を分母・定義まで分解して読む視点
- その場で契約しないための型と、複数校を並べる比較表のフォーマット
:::

## 無料カウンセリングの位置づけを間違えない

スクール側の目的には、受講希望者の目標をヒアリングしてコースを提案すること、そして契約前に条件を説明することが含まれます。複数のスクール比較メディアの解説では、担当者が多くの相談者と面談している場合が多く、「どの職種・どの言語を目指すか」の相談相手として活用できると紹介されています。現役エンジニアやキャリアコンサルタントが対応し、IT業界で求められるスキルの提案を受けられる点を評価する声も見られます。

一方で、**カウンセリングの内容・所要時間・担当者の職種はスクールごとに大きく異なります**。オンライン面談のみのところもあれば、校舎や自習室の見学、実際の講義の見学に対応しているスクールもあります（あるスクールの無料カウンセリング予約ページの案内より）。

所要時間や形式は予約フォームに書かれていないこともあります。予約時のメモ欄で「所要時間」「担当者は誰か」「見学は可能か」を先に確認しておくと、当日の質問時間を節約できます。

また、無料カウンセリングはあくまで検討段階のステップです。複数校を受けて比較したほうがよい、という指摘は複数の比較メディアで共通しています。

## 予約前にやること：自分の条件を“数字”で言語化する

カウンセリングの質は、こちらが渡す情報の解像度でほぼ決まります。ふわっと「エンジニアになりたいです」と伝えれば、返ってくる提案もふわっとしたものになりがちです。

| 項目 | メモの例 |
| --- | --- |
| 現状 | 事務職5年、Excel業務中心、HTML/CSSを書籍で20時間ほど |
| 目標 | 1年以内にWeb系自社開発企業へ転職／まず副業で月3万円 |
| 期限 | 来年3月までに転職活動を開始したい |
| 学習時間 | 平日1.5時間＋土日5時間＝週約12時間 |
| 予算 | 自己負担の上限は◯◯万円、分割なら月◯万円まで |
| 譲れない条件 | 完全オンライン／質問は平日夜に対応してほしい |

この6つを冒頭で伝えるだけで、「週12時間なら、このコースの標準学習時間には足りません」といった**具体的なズレの指摘**を引き出せます。

逆に、条件を伝えても「大丈夫です、やる気があれば問題ありません」としか返ってこない場合は、提案の根拠を追加で質問してみてください。

## 必ず聞くべき質問リスト20（4領域別）

質問は「エンジニア・業界について聞くこと」と「スクールについて聞くこと」に分けると整理しやすい、という切り口が既存の解説記事で紹介されています。ここではさらに実務的に、**契約判断に直結する4領域**に分けました。

### 1. 費用まわり（5問）

| 質問 | 見極めのポイント |
| --- | --- |
| ①入学金を含めた総額はいくらか（税込） | 「月々◯円」だけで答える場合は総額を再確認 |
| ②分割払いは可能か。手数料・実質年率・回数は | 分割の可否は事前確認が推奨されている |
| ③受講料に含まれないものは何か（教材、開発環境、資格試験料、延長料金など） | 「含まれないもの」を能動的に列挙できるか |
| ④期間内に終わらなかった場合の延長費用は | 延長が有料なら、標準学習時間と自分の週の学習時間を突き合わせる |
| ⑤割引・キャンペーンの適用条件と期限は | 「今日中なら」と期限を極端に切ってくる場合は要注意 |

### 2. カリキュラム・サポート（6問）

| 質問 | 見極めのポイント |
| --- | --- |
| ⑥このコースの標準学習時間は合計何時間か | 自分の週の学習時間で割って現実的か計算する |
| ⑦質問対応の時間帯・曜日、回答までの目安時間 | 平日日中のみだと社会人は使いにくい |
| ⑧メンター／講師の選考基準と実務経験 | 「現役エンジニア」の定義（職種・年数）を具体化 |
| ⑨メンターの変更は可能か | 相性の問題は起きうる前提で確認 |
| ⑩最終成果物（ポートフォリオ）はどこまで作るのか。テーマは自由か | 全員同じ課題だと転職時の差別化がしにくい |
| ⑪教材はいつまで閲覧できるか（受講終了後も見られるか） | 復習可否は実務に出てから効いてくる |

### 3. 転職・副業支援（5問）

| 質問 | 見極めのポイント |
| --- | --- |
| ⑫転職支援の具体的な中身（求人紹介／書類添削／面接対策の回数） | 「サポートあり」の中身を分解する |
| ⑬支援の対象期間はいつからいつまでか | 卒業後◯か月で終了、というケースがある |
| ⑭紹介求人の職種内訳（自社開発／受託／SES／ITサポート） | 目標職種と一致しているか |
| ⑮「就職率◯%」の分母・集計期間・定義 | 分解の観点は後述の章にまとめた |
| ⑯副業を目指す場合の支援はあるか（案件獲得サポートの有無） | 転職前提のスクールも多い |

### 4. 契約・解約（4問）

| 質問 | 見極めのポイント |
| --- | --- |
| ⑰契約書面・利用規約を事前にPDFでもらえるか | 「持ち帰って読む」ができるかは重要な判断材料 |
| ⑱途中で辞めた場合の返金計算方法と、違約金の有無 | 口頭ではなく書面の条項を確認する |
| ⑲返金保証・転職保証がある場合、適用条件と除外条件 | 「◯回以上の面談参加」など条件が付くことがある |
| ⑳休会制度の有無と手続き | 繁忙期・体調不良への備え |

:::check 20問を全部は聞けないときの優先順位
- ①総額（税込）は入学金込みか
- ②分割の手数料・実質年率・回数
- ③受講料に含まれないものの一覧
- ⑦質問対応の時間帯と回答までの目安
- ⑮就職率の分母・集計期間・定義
- ⑱中途解約時の返金計算と違約金の有無
:::

気になるスクールが複数ある場合は、同じ質問を各校にぶつけて回答を並べると差が見えます。まずは1〜2校、日程を押さえてしまうのが早道です。

## お金の話は「総額」「追加」「辞めたとき」の3点セットで

費用の話は聞きにくい、と感じる人が多い領域です。ただ、スクール比較メディアの解説でも、受講料が高額になりやすくミスマッチ時のダメージが大きいからこそ、費用に見合う内容かを確認する場としてカウンセリングを使うべきだと指摘されています。遠慮する理由はありません。

ポイントは、**「総額」「追加費用」「辞めたときの精算」を3点セットで聞く**ことです。月額表示や分割の月額だけを見ていると総額の比較ができず、延長料金・教材費・試験料が別建てかどうかで実際の支払額も変わります。

:::warning 中途解約の条件は「文面」で確認する
中途解約にどの法律（特定商取引法の特定継続的役務提供に該当するかなど）が適用されるかは、契約形態やサービス内容によって判断が分かれるため、この記事では一律に「クーリング・オフできる」とは書きません。

確実なのは、カウンセリングの場で中途解約の条項が書かれた契約書面を見せてもらい、返金の計算方法を口頭ではなく文面で確認することです。書面を出し渋られる、口頭の説明と条文が食い違う——こうした場合は、その時点で一度持ち帰る判断をおすすめします。
:::

## 給付金・補助金は制度名を指定して聞く

受講料を実質的に下げる手段として、公的制度の対象講座かどうかは大きな分岐点です。カウンセリングでは「安くなりますか」ではなく、**制度名を指定して**聞いてください。

### 教育訓練給付金（厚生労働省）

雇用保険の加入期間などの要件を満たす人が、厚生労働大臣指定の講座を修了した際に費用の一部の支給を受けられる制度で、**一般／特定一般／専門実践**の3種類があります。2024年10月1日施行の改正で給付率が拡充され、特定一般は40%と50%の2区分、専門実践は50%・70%・80%の3区分になったと解説されています（教育訓練給付金.JP、ライフィの改正解説）。

専門実践では、訓練修了後に**賃金が5%以上上昇**した場合に追加で10%分が支給され最大80%となります。賃上げ分の申請は、事業主の証明欄を含む支給申請書と給与明細の写し等を添えて**原則1年以内**に管轄ハローワークへ提出する、と労基旬報オンラインが整理しています。なお、**2024年10月1日より前に受講を開始した場合、この追加支給の対象にならない**点が政府広報オンラインで案内されています。

手続きの違いも重要です。政府広報オンラインによると、特定一般は訓練前キャリアコンサルティングを受けてジョブ・カードの交付を受け、**受講開始日の2週間前まで**にハローワークで手続きが必要。専門実践は訓練期間中**6か月ごと**に支給申請を行うため、受講中から支給を受けられます。一般は修了後の申請で、申請期限を修了日の翌日から1か月以内と整理する解説もあります（手続きプランナー）。

| 区分 | 給付率（2024年10月1日施行の改正後） | 事前手続き |
| --- | --- | --- |
| 一般 | 20%（手続きプランナーの整理） | 修了後に申請 |
| 特定一般 | 40%・50%の2区分 | 受講開始日の2週間前までにハローワークで手続き |
| 専門実践 | 50%・70%・80%の3区分（賃上げ等の要件あり） | 訓練前キャリアコンサルティング等／受講中6か月ごとに申請 |

> この表は上記の民間解説記事（教育訓練給付金.JP、手続きプランナー、ライフィ、政府広報オンライン）を整理したもので、**編集部は厚生労働省の一次資料で全項目を照合できていません**。給付率・要件・期限は改正や個別事情で変わるため、申し込み前に厚生労働省およびハローワークの公式情報で必ず確認してください。

講座が指定対象かどうかは、厚生労働省が公開している教育訓練給付制度の検索サイトでも調べられるとされています。サイト名や仕様は変わる可能性があるため、厚生労働省の公式サイトから最新の入口をたどり、講座名で検索して裏取りしておくと安心です。対象条件の全体像は{{link:programming-school-kyufukin-conditions|給付金の対象条件と申請の流れ}}も合わせて確認してください。

### リスキリングを通じたキャリアアップ支援事業（経済産業省）

在職者の転職を後押しする補助事業で、NIKKEIリスキリングの解説によれば補助上限は**56万円**。内訳は受講費用の**50%相当額（上限40万円）**に、転職後に追加で**5分の1（上限16万円）**が上乗せされる形です。ただし追加分は**本事業で実施された職業紹介による転職**に限られ、別の転職支援会社経由での転職は対象外とされています。

各スクールの公式案内（テックアカデミー、デジタルハリウッド、LINEヤフーテックアカデミー）では、次のような要件・注意点が示されています。

- 受講開始時・キャリア相談開始時に企業等と雇用契約（パート・アルバイト含む）があり、**雇用主の変更を伴う転職**を目指していること
- 社内での正社員化、派遣先の変更、社内昇進、独立開業は**対象外**
- 副業で実績を積んでから転職を目指すケースは認められる
- **法人名義の申込・支払いは対象外**（個人名義に限る）
- 割引利用時は割引適用後の税抜価格に対する還元、追加サポート費用は補助対象外
- 講座は**転職先の入社日までに修了**している必要がある
- 受講期間は最大24か月、2025年4月1日以降に受講を開始した場合は最大2027年3月31日まで（LINEヤフーテックアカデミーの案内）

これらは本記事の更新時点で各社公式ページに掲載されていた内容です。制度は年度によって募集状況や運用が変わるため、**経済産業省の事業公式サイトと、スクール公式の制度案内ページの両方で最新の条件を確認する**のが前提になります。

カウンセリングでは「この講座は対象か」「申請は誰がどのタイミングで行うか」「対象外になるケースは何か」の3点を必ず確認してください。転職エージェントの利用と組み合わせたい人は、{{link:programming-school-kyufukin-heiyo-agent|給付金と転職エージェント併用の落とし穴}}も先に読んでおくと判断しやすくなります。

給付金・補助金が使える講座に絞って検討したい人は、対象講座を扱うスクールから相談日程を押さえるのが効率的です。

## 「就職率」「転職保証」は数字の中身を分解する

カウンセリングで提示される実績値は、定義次第で印象が大きく変わります。数字そのものではなく、**分母と集計ルール**を聞いてください。

:::point 実績値を聞くときの5つの分解軸
- 分母：受講者全員か、卒業者のみか、転職活動を行った人のみか
- 集計期間：直近1年か、開校以来の累計か
- 「就職」の定義：正社員のみか、契約社員・業務委託を含むか
- 職種の内訳：開発職以外（ITサポート、営業、テスターなど）を含むか
- 転職保証の条件：年齢制限、面談参加回数、応募社数のノルマ、保証の除外条件
:::

ここで具体的な回答が得られない、あるいは「個別の事情によります」で終わる場合は、その実績値を判断材料から外して考えるのが無難です。

なお、転職市場の状況は時期によって変わります。どのスクールであっても**転職できることを保証するものではない**という前提で検討してください。

## 勧誘が不安な人へ：その場で契約しないための型

「断れずに契約してしまいそう」という不安は、事前の準備で大きく減らせます。テクニックというより、次の3つを用意しておくだけで十分です。

1. **冒頭で宣言する**：「今日は情報収集で、他社も見てから決めます」と最初に伝える。後から言うより角が立ちません。
2. **判断基準を外部化する**：「家族と相談してから決める」「予算は◯万円まで」など、その場で動かせない基準を持っておく。
3. **持ち帰り材料を頼む**：契約書面と料金の内訳をメールで送ってもらう。応じないスクールなら、それ自体が判断材料になります。

「特定商取引法があるから強引な勧誘はできない」という説明を掲げる比較メディアもありますが、**条文レベルの適用範囲までは本記事では確認できていません**。法律に守られているから大丈夫と考えるより、上記3つを自分で用意しておくほうが確実です。契約後にトラブルが起きた、納得できないまま契約してしまったという場合は、お住まいの自治体の消費生活センターなど公的な相談窓口に相談する方法もあります（名称・受付時間は各機関の公式サイトで確認してください）。

複数校を比較するときは、聞いた内容を同じフォーマットで並べます。

## スクールが向いていない人と、無料で済ませる代替手段

正直に書くと、全員にスクールが必要なわけではありません。

:::merit 費用対効果が出やすい人
- 「◯年◯月までに転職したい」と期限が決まっている
- 独学で挫折した経験がある
- ポートフォリオのレビューを受けたい
- 給付金・補助金の対象講座を使える立場にある
:::

:::demerit まず別の手段を試したい人
- 学習時間を週5時間以上確保できない（延長費用がかさむリスク）
- 目的が「とりあえず何か学びたい」で職種が未定
- 入門書1冊・動画講座1本を独学でやり切れた経験がある
- 予算の上限が明確に低く、無理な分割になりそう
:::

無料〜低コストの代替手段も十分に存在します。公式ドキュメントやチュートリアル、無料で公開されている学習サービス、公的な職業訓練（ハローワークで相談可能）などです。

有料でも、まずは数千円〜数万円の{{aff:learning-online-course|オンライン動画講座}}で「コードを書く作業が苦痛でないか」を確かめてから、数十万円の投資を判断する順序は合理的です。制度面の全体像を先に押さえたい人は{{link:reskilling-hojokin-kojin-hikaku|リスキリング補助金を個人で使う場合の比較}}も参考になります。

## カウンセリング後にやること

:::steps 面談当日〜翌日の手順
1. **比較表を埋める**：その日のうちに記入し、曖昧な項目は「未確認」と書いて残す。
2. **書面をもらう**：契約書面・利用規約・料金内訳をメールで受け取り、中途解約条項を読む。
3. **給付の対象を自分で照合**：教育訓練給付の対象講座と説明されたら、厚生労働省の公式情報で講座名を確認する。
4. **補助事業の条件を確認**：経済産業省の事業公式サイトで最新の条件・期限を確認する。
5. **追加質問を送る**：未確認項目をまとめて質問し、返信の速さと丁寧さも判断材料にする。
6. **1日以上寝かせる**：最低でも一晩置いてから決める。
:::

よくある失敗は、**給付制度の受講開始日要件や事前手続きの期限を見落とすこと**です。特定一般は受講開始日の2週間前までの手続きが必要とされ（政府広報オンライン）、補助事業側では入社日までの修了や名義の条件が案内されています。「申し込みを急ぐ」と「制度の期限を守る」は別物なので、カレンダーに逆算して書き込んでおきましょう。

## よくある質問

### 無料カウンセリングは複数校受けてもいいですか？

問題ありません。スクール比較メディアの解説でも、複数校を受けて比較することが推奨されています。同じ質問を各校に投げて回答を並べると、料金表では見えない差（質問対応の体制、転職支援の中身、担当者の回答の具体性）が浮かび上がります。ただし1日に何校も詰め込むと記憶が混ざるので、1日1〜2校にとどめ、終了直後にメモを埋めるのがおすすめです。

### その場で契約を迫られたらどうすればいいですか？

「今日は情報収集で、他社も見てから決めます」と冒頭で宣言しておくのが最も効果的です。それでも決断を求められた場合は、契約書面と料金内訳をメールで送ってもらうよう依頼して持ち帰りましょう。金額が大きい契約ほど、1日置いて読み返す価値があります。契約後に不安が残る場合は、お住まいの自治体の消費生活センターなど公的な相談窓口に相談する方法もあります。

### プログラミング未経験でも相談していいのでしょうか？

未経験者の相談は一般的な利用シーンです。むしろ、どの職種・どの言語を目指すかという方向性の相談ニーズが強いことは、複数の解説記事で共通して挙げられています。ただし「何もわかりません」だけだと提案も抽象的になります。本文の6項目（現状・目標・期限・週の学習時間・予算・譲れない条件）を数字でメモして臨んでください。

### 所要時間や形式はどのくらいですか？オンラインでも受けられますか？

スクールによって異なり、一律の目安は本記事では確認できていません。オンライン面談に対応するところが多い一方、校舎・自習室の見学や実際の講義の見学に対応しているスクールもあります。予約時に「所要時間」「オンライン／対面」「担当者の職種」「見学の可否」を確認しておくと、当日の時間配分を立てやすくなります。

### 給付金が使えるかどうかは、カウンセリングで聞けばわかりますか？

スクール側から案内は受けられますが、**自分でも裏取りする**ことを強くおすすめします。教育訓練給付は厚生労働省の公式情報で指定講座を確認でき、リスキリング支援事業は経済産業省の事業公式サイトで条件を確認できます。特に、受講開始日の要件、事前手続きの期限、名義や転職経路の条件は見落としやすいポイントです。制度は改正されることがあるため、申し込み直前の時点で一次情報を確認してください。
