在職中の転職活動は、**「転職の目的と条件を決める → 書類と成果物を準備する → 応募と面接 → 内定・条件確認 → 退職の申し出と引き継ぎ」の順に、内定が出るまで今の会社には伝えずに進める**のが基本です。エンジニア転職の場合は、これに「学習やポートフォリオの準備」が加わるため、時間の使い方を最初に決めておくことが大切です。

在職中に活動するメリットは、収入が途切れないため焦って転職先を決めずに済むことです。一方で、仕事と並行するため「疲れる」「面接の時間が取れない」「休めない」といった悩みが出やすく、計画なしに始めると長引きやすいのがデメリットです。

この記事では、働きながらエンジニア転職を進める手順と、面接日程の調整、会社に伝えるタイミング、退職の申し出のルールを整理します。

## 在職中に転職活動をするメリット・デメリット

まずは、在職中と退職後のどちらで活動するかを考えるために、在職中に活動する場合の良い点と注意点を整理しておきましょう。

:::merit 在職中に転職活動をするメリット
- 収入が続くため、生活の不安から妥協した転職先を選びにくい
- 「良い求人がなければ今の会社に残る」という選択肢を持てる
- 職歴に空白期間ができない
- 今の仕事で実績を積みながら、それを応募書類に書ける
:::

:::demerit 在職中に転職活動をするデメリット
- 活動や学習に使える時間が限られ、疲れやすい
- 平日の面接に合わせて休みを取る必要がある
- 活動が長引くと、仕事と両立する気力が続かなくなることがある
- 職場に知られないよう気を配る必要がある
:::

### 転職で何が変わるかも確認しておく

厚生労働省の「令和６年雇用動向調査結果の概況」によると、令和6年に転職した人のうち、前職と比べて賃金が「増加」した割合は40.5％、「変わらない」は28.4％、「減少」は29.4％でした。転職すれば条件が良くなるとは限らないため、在職中のうちに条件を比べて、納得できる転職先を選べるのは大きな利点です。

## 働きながらエンジニア転職を進める5ステップ

:::steps 在職中の転職活動の進め方
1. **目的と条件を決める**：なぜ転職するのか、譲れない条件（職種、年収の最低ライン、勤務地、働き方）を書き出す。
2. **書類と成果物を準備する**：職務経歴書と志望動機、エンジニア志望なら学習の成果物（ポートフォリオ）を用意する。
3. **応募と面接を進める**：応募先を絞りすぎず、面接の日程をまとめて調整する。
4. **内定と条件を確認する**：給与、仕事内容、入社日などを書面で確認する。
5. **退職を申し出て引き継ぐ**：内定承諾後に上司に伝え、引き継ぎ計画を立てる。
:::

### 1. 目的と条件を決める

在職中の活動は時間が限られるため、「とりあえず求人を見る」から始めると、応募先が定まらないまま時間が過ぎがちです。最初に、転職で解決したいことと、譲れない条件を決めておきましょう。

エンジニア転職の場合は、「未経験からエンジニアになりたい」のか、「エンジニアとして別の会社・分野に移りたい」のかで準備が大きく変わります。未経験の場合は学習と成果物づくりに時間がかかるため、応募開始の時期を逆算して計画を立てる必要があります。

### 2. 書類と成果物を準備する

ハローワークインターネットサービスの応募書類のガイドでは、志望動機に「なぜその会社を選んだか」「自分のどんなところを仕事に生かせるか」「どんな仕事をしてその会社に役立ちたいか」の3点を盛り込むよう案内されています。

在職中の人は、今の仕事で取り組んでいることを具体的に書けるのが強みです。担当業務の内容や工夫したこと、成果を書き出しておきましょう。未経験からエンジニアを目指す場合の志望動機の書き方は{{link:engineer-tenshoku-mikeiken-shiboudouki|未経験からのエンジニア転職の志望動機}}で詳しく解説しています。

### 3. 応募と面接を進める

働きながらの活動では、応募のタイミングをある程度まとめると、面接の日程も集中させやすくなります。1社ずつ順番に受けると、結果を待つ時間が長くなり、活動期間が延びやすくなります。

## 面接の日程調整と「休めない」ときの工夫

在職中の転職活動でよくある悩みが、面接の時間をどう確保するかです。次のような方法を組み合わせると、仕事への影響を抑えやすくなります。

- **オンライン面接を希望する**：移動時間がなくなり、昼休みや終業後にも対応しやすくなる
- **終業後や土日の面接を相談する**：在職中であることを伝え、対応できる時間帯を相談する
- **有給休暇を計画的に使う**：面接が重なる日に半日休などをまとめて取る
- **一次面接と二次面接を同じ日にできないか相談する**：休む回数を減らせる

面接の日程調整を自分ですべて行うのが大変な場合は、転職エージェントに調整を任せる方法もあります。IT業界に特化したエージェントなら、エンジニア職の求人紹介に加え、応募先とのやり取りや面接日程の調整を代わりに進めてもらえることがあります。

### 疲れる・しんどいと感じたときは

仕事と転職活動の両立は、思っている以上に体力と気力を使います。「疲れる」「しんどい」と感じたら、次の点を見直してみましょう。

- 応募先を広げすぎていないか（条件に合う求人に絞る）
- 学習と応募を同時に詰め込みすぎていないか（時期を分ける）
- 休む日を決めているか（週に1日は活動しない日を作る）

活動の期間に正解はありませんが、無理なペースで続けると今の仕事にも影響が出かねません。期限を決めて取り組み、見直しの時期を設けておくと、だらだらと長引くのを防げます。

## 会社に伝えるタイミングと退職のルール

### 伝えるのは内定を承諾した後

転職活動をしていることを、内定が出る前に今の会社に伝える必要はありません。早い段階で伝えると、引き止めにあったり、転職先が決まらなかった場合に職場に居づらくなったりする可能性があります。内定を受け、労働条件を確認して承諾した後に、直属の上司に伝えるのが一般的な流れです。

なお、在職中の転職活動は、勤務時間外に行うのが基本です。勤務時間中に応募先とやり取りしたり、会社のパソコンやメールアドレスを使ったりするのは避けましょう。

### 退職の申し出に関するルール

茨城労働局の「よくあるご質問」では、民法第627条により、労働者からの退職の申し入れは、使用者の承諾がない場合でも2週間を経過すれば効力が発生すると説明されています。会社から「新しい人が見つかるまで待て」と言われた場合でも、退職の意思表示をしていれば、伝わった日の翌日から起算して14日が経過すれば法律上退職は成立するとされています（期間の定めのない雇用で、純然たる「完全月給制」などの例外を除く）。

ただし同じページでは、就業規則に退職の申出期間の定めがあり、その期間が社会通念上著しく長くない場合（例えば1か月前までの申出を定めている場合など）は、トラブル防止のために、まずは就業規則の定めに沿って申し出たほうがよいとされています。

:::warning 退職・入社日の調整で注意したいこと
- 就業規則で退職の申出期間を確認してから、転職先と入社日を相談する
- 引き継ぎにかかる期間を見込んで、無理のない入社日を設定する
- 有給休暇の残日数を確認し、消化の計画を上司と相談する
- 退職の話し合いがこじれた場合は、総合労働相談コーナーなどに相談できる
:::

## 在職中の転職活動が向いている人・向いていない人

| 向いている人 | 退職してから活動したほうがよい場合もある人 |
|---|---|
| 収入を途切れさせたくない | 心身の不調があり、まず休む必要がある |
| 今の会社に残る選択肢も持っておきたい | 長時間労働で、活動の時間がまったく取れない |
| 計画的に時間を作れる | 職業訓練などで学習に専念したい事情がある |

退職してから活動する場合は、収入が途絶える期間が生じるため、生活費の見通しを立てておくことが大切です。どちらがよいか迷う場合は、キャリアの専門家に相談して整理するのも一つの方法です。

:::point 判断のポイント
在職中の転職活動は、収入を保ちながら納得のいく転職先を選べるのが最大の利点です。目的と条件を最初に決め、応募や面接をまとめて進め、内定を承諾してから会社に伝える。この順番を守るだけでも、両立の負担と職場とのトラブルを減らせます。
:::

転職するかどうか自体に迷っている段階なら、無料のキャリアコーチングで方向性を整理してから動き出すのも選択肢です。{{aff:career-coaching|無料のキャリアコーチングで転職の方向性を整理する}}

## よくある質問

### 在職中の転職活動は違法や非常識になりませんか？

在職中に転職活動をすること自体は、一般的に行われています。ただし、勤務時間中に活動したり、会社の設備や情報を使ったりするのは避け、勤務時間外に進めるのが基本です。就業規則に定めがある場合は、その内容も確認しておきましょう。

### 在職中の転職活動の期間はどれくらいを見込めばいいですか？

職種や本人の状況によって大きく異なります。未経験からエンジニアを目指す場合は、学習や成果物づくりの期間も必要になるため、応募開始までの準備期間を含めて計画を立てましょう。期限を決めて取り組み、途中で進み具合を見直すことが大切です。

### 転職活動していることを会社に伝えるタイミングはいつですか？

内定を受け、労働条件を確認して承諾した後に、直属の上司に伝えるのが一般的です。退職の申し出については、就業規則に申出期間の定めがあれば、それに沿って伝えるとトラブルを防ぎやすくなります。

### 在職中で面接に行く時間が取れない場合はどうすればいいですか？

オンライン面接や終業後・土日の面接を相談する、有給休暇を計画的に使う、複数の面接を同じ日にまとめられないか相談するといった方法があります。日程調整を転職エージェントに任せるのも一つの方法です。
