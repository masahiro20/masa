クラウドの仕事に興味を持ち、まずはAWSの資格を取ろうと考えたものの、未経験の自分が資格を取っても本当に転職につながるのか、確信が持てずにいる。そんな場面を想定して書きました。時間とお金をかける前に迷うのは、慎重で健全な判断です。

AWS資格は、**未経験からの転職で「クラウドの基礎を学んだ証拠」として役立つ**ことがあります。ただし、**資格だけで採用が決まるわけではなく、実際に手を動かした経験とセットで示すこと**が大切です。

未経験者なら、まず入門向けの「AWS Certified Cloud Practitioner」で基礎を固め、次に「AWS Certified Solutions Architect - Associate」に進む順番が、AWS公式の案内にも沿った進め方です。この記事では、公式情報をもとに、資格の選び方と転職につなげる進め方を整理します。

## 未経験者が最初に受けるAWS資格は？

AWSの公式ページによると、「AWS Certified Cloud Practitioner」は、**クラウドを初めて使用する、IT関連の経歴を持たない受験者向けに設計された試験**とされています。セールス、マーケティング、製品やプロジェクト管理といった役割を担う人が、AWSクラウドの基礎を理解するためのものとも説明されており、AWSクラウドの使用経験は必須ではないとされています。

一方、「AWS Certified Solutions Architect - Associate」について、AWSは、IT業務の経験がまったくない人は、受験する前にまずCloud Practitionerを取得してAWSクラウドの基礎知識を習得することを勧めています。

:::point 未経験者の受ける順番
- まずは「Cloud Practitioner」でクラウドとAWSの基礎を学ぶ
- 次に「Solutions Architect - Associate」で、設計の考え方を学ぶ
- 資格の勉強と並行して、実際にAWSを触ってみる
:::

## 2つの資格の試験概要の違い

AWS公式ページの情報（2026年10月時点）をもとに、2つの資格を比べると次のとおりです。

| 項目 | Cloud Practitioner | Solutions Architect - Associate |
| --- | --- | --- |
| カテゴリ | Foundational | Associate |
| 試験時間 | 90分 | 130分 |
| 問題数 | 65問（択一選択または複数選択） | 65問（択一選択または複数選択） |
| 費用 | 100 USD | 150 USD |
| 受験方法 | テストセンターまたはオンライン監督付き試験 | テストセンターまたはオンライン監督付き試験 |
| 有効期間 | 3年 | 3年 |
| 想定する受験者 | クラウドを初めて使う、IT関連の経歴を持たない人 | AWSを使った設計の実務経験が1年以上あることが望ましい |

費用は米ドルで表示されており、為替レートなどを含む料金の詳細は公式の「試験の料金」ページで確認するよう案内されています。また、どちらも日本語で受験できる試験として案内されています。

Solutions Architect - Associateについて、AWSは、試験ガイドではAWSサービスを使ったクラウドソリューションの設計で1年以上の実務経験があることが望ましいとしつつ、1〜3年のIT経験がある場合は、学習と認定の出発点としてこの資格に取り組むことも可能だとしています。**未経験者にとっては、Cloud Practitionerより一段難しい資格**と考えておきましょう。

## 資格だけでは転職が難しい理由

AWS資格は、クラウドの知識を持っていることを示す材料になります。それでも、資格だけで転職が決まるとは限りません。理由は主に次の3つです。

### 実務では「手を動かせるか」が見られる

採用では、資格の有無に加えて、実際にサーバーやネットワークを設定した経験があるかが見られることが多いです。資格の勉強だけで終わっていると、面接で具体的な経験を聞かれたときに答えにくくなります。

### インフラの基礎知識も必要になる

クラウドの仕事では、AWSのサービスの知識に加えて、ネットワーク、サーバー、Linuxなどの基礎知識が求められる場面があります。**AWSの資格はクラウドの入り口であって、ITインフラ全体の知識を代わりに証明するものではない**点に注意しましょう。

### 未経験可の求人は職種や条件が限られやすい

クラウドを扱う求人は、経験者向けの条件になっていることもあります。未経験から応募する場合は、運用・保守などの業務から始める求人も含めて検討すると、選択肢が広がります。インフラエンジニアの求人の見極め方は {{link:infra-engineer-mikeiken-tenshoku-kyujin|インフラエンジニア未経験転職｜求人の探し方と求人票の見極め方}} で解説しています。

:::warning 「資格さえあれば転職できる」という宣伝に注意
「AWS資格を取れば未経験でもすぐ転職できる」といった宣伝を見かけることがありますが、採用は資格だけで決まるものではありません。講座や教材を選ぶときは、実際にAWSを操作する演習があるかなど、内容をよく確認しましょう。
:::

## 資格を転職につなげる学び方

AWSの公式ページでは、試験準備として、オンライン学習センター「AWS Skill Builder」の試験準備プランに沿って学ぶ流れが紹介されています。試験ガイドの確認、公式の練習問題、知識やスキルのギャップを埋めるデジタルコースの受講、ハンズオン形式の演習、模擬試験といった段階で進める内容です。

:::steps 未経験からの進め方
1. **ITの基礎を押さえる**：ネットワーク、サーバー、Linuxの基本など、インフラの基礎知識を学びます。
2. **Cloud Practitionerを学ぶ**：試験ガイドを確認し、公式の学習コンテンツや練習問題で準備します。
3. **実際にAWSを触る**：学んだサービスを実際に操作し、簡単な構成を自分で作ってみます。
4. **作ったものを記録する**：何を作り、どう設定したか、つまずいた点をどう解決したかをまとめます。
5. **Associateレベルに進む**：基礎が固まったら、Solutions Architect - Associateなどに挑戦します。
:::

ステップ4の記録は、面接で「何ができるか」を説明する材料になります。作ったものの構成や工夫した点をまとめておくと、資格と実践の両方を示せます。作品のまとめ方は {{link:engineer-portfolio-tsukurikata|エンジニアのポートフォリオの作り方}} も参考にしてください。

画面を見ながらAWSの操作を学びたい人は、{{aff:learning-online-course|オンライン動画講座}}で、ハンズオン形式の講座を選ぶ方法もあります。

## よくある質問

### AWS資格は未経験の転職に役立つ？

クラウドの基礎を学んだ証拠として役立つことがあります。ただし、資格だけで採用が決まるわけではないため、実際にAWSを触った経験や、インフラの基礎知識とあわせて示すことが大切です。

### 未経験者はどのAWS資格から受ければいい？

AWSは、Cloud PractitionerをIT関連の経歴を持たない受験者向けの試験としています。IT業務の経験がない人は、Solutions Architect - Associateの前にCloud Practitionerを取得することが勧められています。

### AWS資格の勉強方法は？

AWS公式では、AWS Skill Builderの試験準備プランに沿って、試験ガイドの確認、練習問題、デジタルコース、ハンズオン演習、模擬試験の順に進める方法が紹介されています。あわせて、実際にAWSを操作してみると理解が深まります。

### AWS資格の有効期間は？

AWS公式ページによると、Cloud PractitionerもSolutions Architect - Associateも、認定資格の有効期間は3年です。有効期限が切れる前に再認定を受ける方法も案内されています。
