SNSで「未経験から短期間でエンジニアに」という広告を見て、無料カウンセリングを申し込んでみた。話を聞くうちに、今日中に申し込めば割引になると言われ、高額な受講料に心が揺れている。でも、どこか怪しい気もする。そんな場面を想定して書きました。急かされると、立ち止まって考えるのが難しくなるのは当然です。

プログラミングスクールが「怪しい」と感じたら、**その場で契約せず、契約内容を書面で確認してから判断する**のが基本です。すべてのスクールが怪しいわけではありませんが、**根拠の分からない成果の約束や、契約を急がせる勧誘**があるときは、いったん持ち帰りましょう。

また、パソコンの操作に関する知識や技術を教える「パソコン教室」は、一定の期間・金額を超える場合、特定商取引法の**「特定継続的役務提供」**の対象とされています。対象になる契約では、契約前の書面の交付、**書面を受け取った日から8日以内のクーリング・オフ**、中途解約のルールなどが定められています。

## 「怪しい」と感じやすい場面

プログラミングスクールを検討するとき、次のような場面で「怪しい」と感じる人が多いようです。感じた違和感は、判断を急がないためのサインとして大切にしましょう。

| 場面 | 確認したいこと |
| --- | --- |
| 短期間での高収入や転職を約束するような広告 | 成果の根拠や、条件がどこに書かれているか |
| 「今日中なら割引」など契約を急がせる勧誘 | 持ち帰って検討できるか、割引の条件は何か |
| 料金の総額がはっきりしない | 入学金・教材費などを含めた総額と支払方法 |
| 無料カウンセリングのはずが、長時間の勧誘になった | 断ったときにどうなるか、書面の交付があるか |
| 解約や返金の説明があいまい | クーリング・オフと中途解約の条件 |

結局のところ、**判断の材料が書面で示されないまま契約を迫られることが、いちばん注意したい点**です。説明を聞いて納得できても、書面で確かめてから決める習慣をつけましょう。

スクールが「やめとけ」と言われる理由は {{link:programming-school-yametoke|プログラミングスクールはやめとけ？}} で、契約前に聞きたい質問は {{link:programming-school-counseling-questions|プログラミングスクール無料カウンセリングで聞くべき質問20}} で整理しています。

## 特定商取引法の「特定継続的役務提供」とは

消費者庁の「特定商取引法ガイド」によると、特定継続的役務提供とは、長期・継続的な役務（サービス）の提供と、これに対する高額の対価を約する取引のことです。現在は、エステティック、美容医療、語学教室、家庭教師、学習塾、結婚相手紹介サービス、**パソコン教室**の7つの役務が対象とされています（2026年11月時点）。

このうち「いわゆるパソコン教室」は、**電子計算機又はワードプロセッサーの操作に関する知識又は技術の教授**で、期間が2か月を超え、金額が5万円を超えるものとされています。金額は、入学金、受講料、教材費、関連商品の販売など、契約金の総額で判断され、インターネットなどを使って提供される場合も広く含まれると説明されています。

:::warning 自分の契約が対象になるかは確認が必要
プログラミングを教えるスクールの契約が、この「パソコン教室」にあたるかどうかは、契約の内容によって判断されます。対象になるかが分からない場合は、スクールに確認するとともに、後で紹介する消費生活相談窓口に相談しましょう。また、営業のためや営業として結ぶ契約などは、特定商取引法の適用が除外されると案内されています。
:::

## 対象になる契約で知っておきたいルール

特定継続的役務提供にあたる契約では、消費者を守るための主なルールが定められています。

### 契約前と契約後の書面の交付

事業者は、契約の締結前に契約の概要を記載した**「概要書面」**を、締結後には遅滞なく契約内容を明らかにした**「契約書面」**を渡さなければならないとされています。概要書面には、役務の内容、支払う金銭の概算額、支払時期と方法、提供期間、クーリング・オフや中途解約に関する事項などを記載することが定められています。

**書面を受け取ったら、まず料金の総額と、クーリング・オフ・中途解約の欄を確認しましょう**。

### クーリング・オフ

契約を結んだ場合でも、法律で決められた書面を受け取った日から数えて**8日以内**であれば、書面または電磁的記録で契約を解除（クーリング・オフ）できるとされています。関連商品の販売契約も含まれ、パソコン教室については、電子計算機やその部品・附属品、書籍などが関連商品として指定されています。

消費者庁のガイドでは、クーリング・オフを行うときは、後々のトラブルを避けるため、書面なら特定記録郵便や書留、内容証明郵便など、電子メールなら送信したメールを保存しておくなど、**証拠を残しておくことが望ましい**と案内されています。

### 中途解約

クーリング・オフの期間を過ぎた後でも、将来に向かって契約を解除（中途解約）できるとされています。その際に事業者が請求できる損害賠償などの額には上限があり、パソコン教室の場合は次のとおりです。

| 解約の時期 | 事業者が請求できる額の上限（パソコン教室） |
| --- | --- |
| 役務の提供開始前 | 1万5000円 |
| 役務の提供開始後 | 提供された役務の対価に相当する額＋「5万円」または「契約残額の20％」のいずれか低い額 |

**中途解約できることを知っておくだけでも、「もう解約できない」と思い込まずに済みます**。ただし、実際の返金額は契約内容によって変わるため、契約書面をもとに確認しましょう。

### 禁止されている勧誘

特定商取引法では、誇大広告や、著しく事実と相違する表示が禁止されています。また、勧誘の際に事実と違うことを告げること、故意に事実を告げないこと、相手を威迫して困惑させることなども禁止行為とされています。事実と違うことを告げられて誤認して契約した場合などには、意思表示を取り消せることがあるとも説明されています。

## 契約前に確認したいチェックリスト

:::check プログラミングスクールの契約前チェックリスト
- 入学金・受講料・教材費などを含めた料金の総額が書面で示されているか
- 契約前に概要書面を受け取れるか
- クーリング・オフと中途解約の条件が書面に書かれているか
- 「転職保証」「返金保証」などの条件が具体的に書かれているか
- 分割払いやローンを使う場合、総支払額と手数料が分かるか
- その場で決めず、持ち帰って検討できるか
:::

特に「転職保証」や「返金保証」は、**条件を満たした場合にだけ適用される**ことが多い仕組みです。保証の条件が自分に当てはまるかを確認しておきましょう。詳しくは {{link:programming-school-tenshoku-hosho-demerit|プログラミングスクールの転職保証のデメリット}} で整理しています。

:::point 勧誘を受けたときの心がけ
- 「今日だけ」と言われても、書面を確認するまでは決めない
- 説明の内容は、メモや書面で残しておく
- 断りたいときは、理由を詳しく説明しなくても構わない
:::

## 困ったときの相談先

契約やトラブルで困ったときは、一人で悩まずに相談しましょう。消費者庁の案内では、**消費者ホットライン「188」**に電話すると、地方公共団体が設置している身近な消費生活センターや消費生活相談窓口を案内してもらえるとされています。相談は無料ですが、相談窓口につながった時点から通話料金がかかると案内されています。

**クーリング・オフの期限が迫っている場合は、早めに相談することが大切です**。契約書面や広告の画面、やり取りのメッセージなどを手元に用意しておくと、相談がスムーズに進みます。

## 怪しくないスクールを選ぶには

不安を感じたからといって、スクールそのものを避ける必要はありません。大切なのは、**情報を比べて、納得できるところを選ぶ**ことです。

:::merit 納得して選ぶためにできること
- 複数のスクールの無料カウンセリングを受けて、説明を比べる
- 料金の総額や解約の条件を、書面で比べる
- 給付金の対象講座かどうかなど、公的な情報で確認できる点を確かめる
:::

:::demerit 比べるときに気をつけたいこと
- 広告の「実績」や「満足度」は、条件や調査方法を確認する
- 割引の期限に合わせて、比較を急がない
- 口コミだけで判断せず、書面の内容を優先する
:::

公的な制度で確認できる点として、教育訓練給付金の対象講座かどうかがあります。対象講座は厚生労働大臣の指定を受けた講座です。給付金の対象講座から探したい人は、{{aff:school-kyufukin|給付金対象のプログラミング講座}}で、講座の種類や受講開始日を確認してみてください。

{{aff:school-kyufukin}}

AIの開発などを学べるオンラインスクールも比べたい人は、{{aff:school-general|byTech（未経験からAI開発を学ぶオンラインスクール）}}の無料カウンセリングで、料金の総額や解約の条件を書面で確認する方法もあります。

編集部としては、**どのスクールでも「書面で確認できないことは、確認できるまで契約しない」**ことをおすすめします。説明が丁寧なスクールほど、書面での確認にも快く応じてくれるはずだからです。

## 迷ったときの次の一歩

迷ったら、まずは受けたカウンセリングの内容と、示された料金の総額をメモに書き出してみてください。そのうえで、概要書面を受け取り、クーリング・オフと中途解約の欄を確認しましょう。不安が残るなら、消費者ホットライン「188」に相談するのも一つの方法です。

スクールは、自分に合わなければ見送って構いません。独学や公的な職業訓練など、ほかの学び方も選べます。焦らず、納得できる方法を選んでください。

## よくある質問

### プログラミングスクールが怪しいと感じたらどうすればいい？

その場で契約せず、料金の総額やクーリング・オフ・中途解約の条件を書面で確認してから判断しましょう。不安が残る場合は、消費者ホットライン「188」で身近な消費生活相談窓口を案内してもらえます。

### プログラミングスクールはクーリング・オフできる？

特定商取引法では、パソコン教室（電子計算機の操作に関する知識や技術の教授）で、期間が2か月を超え、金額が5万円を超えるものが特定継続的役務提供の対象とされ、書面を受け取った日から8日以内ならクーリング・オフできるとされています。自分の契約が対象かは、契約内容によるため確認が必要です。

### クーリング・オフの期間を過ぎたら解約できない？

特定継続的役務提供にあたる契約では、クーリング・オフの期間を過ぎた後でも中途解約ができるとされています。事業者が請求できる額には上限があり、パソコン教室の場合は、役務の提供開始前なら1万5000円とされています。

### 怪しいプログラミングスクールの見分け方は？

根拠の分からない成果の約束、契約を急がせる勧誘、料金の総額や解約条件があいまいな説明には注意しましょう。書面での確認に応じてくれるか、持ち帰って検討できるかも、判断の目安になります。
