転職エージェントとキャリアコーチングの違いは、**「どこに転職するか」を一緒に探すのが転職エージェント、「そもそも何をしたいか」を一緒に考えるのがキャリアコーチング**という役割の違いです。

使い分けの目安はシンプルです。やりたい仕事や業界がある程度決まっているなら転職エージェント、転職するかどうかや方向性から迷っているならキャリアコーチングが向いています。方向性が固まっていない段階でいきなり求人を見始めると、条件だけで選んでしまい、転職後に後悔することもあります。

この記事では、両者の違いを比較したうえで、段階ごとの使い分けと、併用するときの進め方を整理します。

:::summary
- 転職エージェントとキャリアコーチングの違いが分かる比較表
- 自分の段階に合わせた使い分けの判断基準
- 両方を併用するときの進め方と注意点
- キャリアコンサルタント（国家資格）との違い
:::

## 転職エージェントとキャリアコーチングの違いを比較

| 比較項目 | 転職エージェント | キャリアコーチング |
|---|---|---|
| 主な目的 | 求人の紹介と、内定・入社までの支援 | 自己分析とキャリアの方向性づくり |
| 求人紹介 | あり（中心的なサービス） | 有料型は基本的になし。無料型は求人紹介まで一体のものもある |
| 利用者の費用 | 原則無料 | 有料型は利用者が支払う。無料型もある |
| 向いている段階 | やりたい職種や業界がある程度決まっている | 転職するか、何をしたいかから迷っている |
| 得られるもの | 求人情報、書類・面接対策、条件交渉 | 自己理解、判断の軸、行動計画 |

### 転職エージェントの仕組み

転職エージェントは、法律上は「職業紹介」を行う事業者です。厚生労働省の地方機関である石川労働局のページによると、職業紹介は職業安定法で「求人及び求職の申し込みを受け、求人者と求職者との間における雇用関係の成立をあっせんすること」と定められており、有料職業紹介事業を行うには厚生労働大臣の許可が必要です。

同ページでは、有料職業紹介事業者が求職者から受け取れる手数料は、芸能家やモデルなど特定の職業に限られると説明されています。転職エージェントが一般的に求職者には無料なのは、主な収入が採用企業から支払われる紹介手数料だからです。

### キャリアコーチングの仕組み

キャリアコーチングは、面談を通じて価値観や強みを整理し、キャリアの方向性を一緒に考えるサービスです。キャリナビのコラムでは、転職エージェントは求人紹介に軸足がある一方、キャリアコーチングは求人紹介をせずに自己分析とキャリア設計に伴走することに特化していると説明されています。

ただし、最近は無料で自己分析から求人紹介までを一体で支援するサービスもあります。たとえばキャリナビの公式サイトでは、採用企業からの成功報酬で運営する仕組みのため求職者は完全無料とし、45日間のキャリアコーチングで自己分析から求人提案、面接対策、条件交渉、入社後の定着支援まで伴走すると案内しています（2026年10月時点）。無料と有料のキャリアコーチングの違いは{{link:career-coaching-muryo-yuryo-chigai|キャリアコーチングの無料と有料の違い}}で詳しく整理しています。

## 段階別の使い分け方

どちらを使うべきかは、今の自分が転職のどの段階にいるかで判断するのが分かりやすい方法です。

| 今の状態 | おすすめ | 理由 |
|---|---|---|
| 今の仕事に不満はあるが、何がしたいか分からない | キャリアコーチング | まず判断の軸をつくる必要がある |
| 転職したい業界や職種の候補はあるが、絞れない | キャリアコーチング、または両方 | 候補を比べる軸を整理しつつ、求人の実態も知りたい |
| やりたい職種が決まっていて、求人を探したい | 転職エージェント | 求人紹介と選考対策が中心の支援が合う |
| 転職するか、今の会社に残るかで迷っている | キャリアコーチング（有料型や公的な相談も含む） | 転職を前提にしない相談が合う |

:::point 使い分けの判断ポイント
「どの求人に応募するか」で悩んでいるなら転職エージェント、「なぜ転職したいのか」「何を大事にしたいのか」で悩んでいるならキャリアコーチングが向いています。迷う場合は、方向性を整理してから求人を探す順番にすると、遠回りに見えて結果的に早く決まりやすくなります。
:::

### 転職エージェントが向いている人

すでに目指す職種がはっきりしていて、求人の比較や選考対策を進めたい人には転職エージェントが合っています。IT・Web業界のように専門性の高い分野では、業界に詳しい担当者から求人の傾向や選考のポイントを聞けるのが利点です。

使い方のコツは{{link:mikeiken-engineer-tenshoku-agent-how-to-use|未経験のエンジニア転職エージェント活用法}}で、複数のエージェントを使うときの考え方は{{link:it-tenshoku-agent-multiple-registration|IT転職エージェントの複数登録}}で整理しています。

### キャリアコーチングが向いている人

「何がしたいか分からない」「転職エージェントに求人を紹介されたけれど、どれもピンとこない」という人は、キャリアコーチングで方向性を整理するところから始めるのが向いています。自分の判断軸がはっきりすると、求人を見たときに迷いにくくなります。転職をするかどうかを含めて考えたい人や、異動や学び直しなど転職以外の選択肢も検討したい人にも向いています。

## 併用するときの進め方

転職エージェントとキャリアコーチングは、どちらか一方だけを選ぶ必要はありません。段階に合わせて併用すると、それぞれの強みを生かせます。

:::steps 併用する場合の進め方
1. **キャリアコーチングで方向性を整理する**：価値観、強み、譲れない条件を言葉にする。
2. **判断の軸を書き出す**：仕事内容、年収、働き方などの優先順位を決める。
3. **転職エージェントに登録する**：整理した軸を伝え、条件に合う求人を紹介してもらう。
4. **求人を軸に照らして比べる**：紹介された求人を、自分の優先順位で評価する。
5. **迷ったら軸に立ち返る**：選考中に迷ったときも、最初に決めた軸をもとに判断する。
:::

無料で自己分析から求人紹介まで一体で支援するタイプのサービスであれば、この流れを一つのサービスの中で進めることもできます。

:::warning 併用するときの注意点
- 同じ求人に複数の窓口から応募しないよう、応募状況を自分で管理する
- 各サービスに伝える希望条件や転職時期を揃えておく
- 有料のキャリアコーチングは、総額・回数・解約条件を契約前に確認する
- 無料面談で高額な契約を即決しない
:::

### 面談で確認しておきたいこと

どちらのサービスでも、最初の面談で次のような点を確認しておくと、自分に合うかどうかを判断しやすくなります。

- 面談の回数や期間、担当者が途中で変わることはあるか
- 求人紹介がある場合、どのような業界・職種の求人が多いか
- 転職の時期を急かされないか、自分のペースで進められるか
- 有料の場合は総額と支払い方法、途中でやめたときの扱い
- 担当者がどのような資格や業界経験を持っているか

面談を受けたあとは、「話していて考えが整理されたか」「自分の希望を尊重してくれたか」を振り返ってみましょう。合わないと感じたら、別のサービスを試すのも一つの方法です。複数のサービスを比べることで、自分に合う相談相手の条件も見えてきます。

## キャリアコンサルタントとの違い

キャリアコーチングと似た言葉に「キャリアコンサルタント」があります。キャリアコンサルタントは国家資格で、厚生労働省によると職業能力開発促進法に基づく名称独占資格です。登録を受けていない人は「キャリアコンサルタント」やこれに紛らわしい名称を使うことができず、違反すると30万円以下の罰金の対象になります。登録は5年間有効とされています。

一方、「キャリアコーチ」という呼び方には、こうした国家資格の制度はありません。相談相手を選ぶときは、担当者がキャリアコンサルタントの資格を持っているか、人材業界でどのような経験があるかを確認すると、判断の材料になります。

## まずは自分の段階に合う窓口から始める

方向性に迷っている段階なら、無料のキャリアコーチングで自己分析から始めるのが負担の少ない方法です。自己分析から求人紹介まで一体で支援してもらえるサービスであれば、方向性が固まったときにそのまま転職活動へ進めます。

## よくある質問

### 転職エージェントとキャリアコーチングはどちらを先に使うべきですか？

方向性が決まっていないならキャリアコーチング、決まっているなら転職エージェントから始めるのが基本です。迷う場合は、先に方向性を整理してから求人を探すと、条件だけで選んで後悔するリスクを減らせます。

### 転職エージェントでもキャリア相談はできますか？

できます。多くの転職エージェントでは、面談で経歴や希望を聞いたうえで求人を提案します。ただし、求人紹介が中心のサービスのため、転職するかどうかから時間をかけて考えたい場合は、キャリアコーチングや公的なキャリア相談のほうが合うことがあります。

### キャリアコーチングとキャリアコンサルタントの違いは何ですか？

キャリアコンサルタントは職業能力開発促進法に基づく国家資格で、登録を受けた人だけが名乗れる名称独占資格です。キャリアコーチングはサービスの呼び方で、国家資格の制度はありません。担当者の資格や経歴を確認して選ぶと安心です。

### 両方を同時に使っても問題ありませんか？

問題ありません。キャリアコーチングで方向性を整理しながら、転職エージェントで求人の実態を知るという使い方もできます。ただし、応募状況や希望条件は自分で管理し、同じ求人に重複して応募しないよう注意しましょう。
