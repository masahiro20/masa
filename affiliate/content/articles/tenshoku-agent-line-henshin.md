転職エージェントに登録したら、LINEで担当者から連絡が来た。友だちとのやり取りのように返していいのか、ビジネスメールのように堅く書くべきなのか分からず、既読のまま半日が過ぎてしまった。そんな場面を想定して書きました。仕事に関わる相手だからこそ、言葉づかいに迷うのは当然です。

転職エージェントからのLINEには、**ビジネスメールほど堅くせず、丁寧語で簡潔に返す**のが基本です。返信の目安は、**できればその日のうち、遅くとも翌日まで**と考えておくと、日程調整などがスムーズに進みます。すぐに答えられない内容でも、「確認して明日までにお返事します」と一言返しておけば十分です。

連絡が負担に感じる場合は、返信の頻度や時間帯の希望を伝えることもできます。転職エージェントは、あなたの転職活動を支えるための相手なので、**無理のないやり取りの形を相談して構いません**。

## LINE返信の基本の考え方

LINEは気軽に使える連絡手段ですが、転職エージェントとのやり取りは仕事に関わる連絡です。次のポイントを押さえておくと、迷わずに返信できます。

| ポイント | 考え方 |
| --- | --- |
| 言葉づかい | 丁寧語で簡潔に。ビジネスメールのような長い挨拶文は不要 |
| 返信の早さ | できればその日のうち。難しければ「いつまでに返すか」を伝える |
| 内容 | 結論を先に書く。日程なら候補を2〜3つ挙げる |
| 絵文字・スタンプ | 基本は控えめに。相手が使っていれば、軽く合わせる程度でよい |

結局のところ、**「丁寧語」「結論から」「早めに」の3つを守れば、大きく外れることはありません**。完璧な文章を書こうとして返信が遅れるより、短くても早く返すほうが相手にとって助かります。

## 場面別の返信例文

### 最初の挨拶への返信

検索では「転職エージェント line 挨拶」も調べられています。最初の連絡には、お礼と、今後のやり取りへの一言を添えれば十分です。

:::check 例文：最初の挨拶への返信
ご連絡ありがとうございます。
これからどうぞよろしくお願いいたします。
平日は19時以降、土日は日中に返信しやすいです。
:::

**返信しやすい時間帯を最初に伝えておく**と、担当者もそれに合わせて連絡してくれるようになり、やり取りが楽になります。

### 面談や面接の日程調整への返信

日程調整は、候補日を具体的に挙げると一度で決まりやすくなります。

:::check 例文：日程調整への返信
ご調整ありがとうございます。
以下の日程でしたら対応可能です。
・11月13日（金）19時以降
・11月14日（土）10時〜15時
・11月16日（月）19時以降
ご確認をお願いいたします。
:::

### 紹介された求人への返信

応募したい場合も、見送りたい場合も、理由を一言添えると次の紹介に活かしてもらえます。

:::check 例文：求人紹介への返信
求人のご紹介ありがとうございます。
1件目は業務内容に興味があるので、応募を進めたいです。
2件目は勤務地が希望と異なるため、今回は見送らせてください。
:::

求人や選考を断る場面の例文は {{link:tenshoku-agent-kotowarikata|転職エージェントの断り方}} で詳しく整理しています。

## 絵文字やスタンプは使っていい？

検索では「転職エージェント line 絵文字」も調べられています。絵文字やスタンプは、**基本は控えめにする**のが無難です。担当者が絵文字を使っている場合でも、使うなら一つ程度にとどめ、内容が分かりにくくならないようにしましょう。

:::point LINE返信で気をつけたいこと
- 「了解です」より「承知しました」「かしこまりました」のほうが無難
- 了解のスタンプだけで返すより、短くても文章で返す
- 書類や企業名などの大切な情報は、あとで見返せるように文章で残す
:::

**LINEは気軽な分、文章が短くなりすぎて誤解を生むこともあります**。日程や応募の意思など、大切な内容は文章ではっきり伝えましょう。

## 返信が遅れてしまったときは

仕事が忙しく、返信が遅れてしまうこともあります。そのときは、**気づいた時点で一言お詫びを添えて返信**すれば大丈夫です。

:::check 例文：返信が遅れたとき
返信が遅くなり申し訳ありません。
ご連絡いただいた件ですが、以下のとおりお返事します。
:::

連絡の頻度が多くて負担に感じる場合は、「平日は夜にまとめて確認します」「急ぎの場合は電話でお願いします」など、**自分の都合に合わせた連絡の方法を伝える**のも一つの方法です。働きながらの転職活動の進め方は {{link:zaishokuchu-tenshoku-katsudou-engineer|在職中の転職活動の進め方}} で整理しています。

## LINE交換を求められたときの考え方

検索では「転職エージェント line 交換」も調べられています。面談のあとなどに、担当者からLINEでのやり取りを提案されることがあります。

### 使うかどうかは自分で決めてよい

LINEは便利ですが、仕事と私生活の連絡が同じアプリに混ざるのが気になる人もいます。**メールや電話のほうがやり取りしやすい場合は、そのまま伝えて構いません**。「連絡はメールでお願いします」と一言伝えれば、多くの場合は対応してもらえます。

### 公式のアカウントか確認する

LINEでやり取りする場合は、エージェントの公式アカウントなのか、担当者個人のアカウントなのかを確認しておきましょう。履歴書や職務経歴書などの書類を送るときは、**どの方法で送るのが安全か**を担当者に確認してから送ると安心です。

### 通知の設定を工夫する

LINEでやり取りする場合は、通知の設定を調整しておくと、仕事中に気を取られにくくなります。返信できる時間帯にまとめて確認する習慣をつけると、返信の負担も減らせます。

## 連絡をやめたいとき：ブロックする前に知っておきたいこと

検索では「転職エージェント line ブロック」も調べられています。転職活動を終えた、サービスが合わないと感じたなどの理由で連絡をやめたい場合は、**まずは担当者に「転職活動を終了するので、連絡を停止してほしい」と伝える**のが基本です。

LINEヘルプセンターによると、LINEで相手をブロックすると、相手の名前は友だちリストに表示されなくなってブロックリストに移動し、**相手からのメッセージや通話は受信しなくなります**。また、非表示・ブロック・削除を行っても、**相手に通知されることはない**とされています。ブロックリストから解除すれば、友だちリストに戻すこともできます（2026年11月時点）。

:::warning ブロックだけでは登録は消えない
LINEでブロックしても、転職エージェントのサービスへの登録や、選考中の手続きが自動で終わるわけではありません。選考が進んでいる場合は、ブロックする前に辞退の連絡をしておきましょう。職業紹介事業者は、苦情の処理や個人情報の取扱いに関する事項を求職者に明示することが定められているため、退会や登録情報の扱いは、登録時の案内に沿って問い合わせると安心です。
:::

:::merit 先に連絡してから利用をやめるメリット
- 選考中の企業への辞退連絡などを、きちんと済ませられる
- 不要な連絡や求人紹介を、確実に止めてもらえる
- 将来また利用したくなったときに、気まずさが残りにくい
:::

:::demerit 何も伝えずにブロックするデメリット
- 選考中の場合、企業やエージェントに迷惑をかけることがある
- メールや電話など、LINE以外の方法で連絡が続くことがある
- サービスへの登録や個人情報の扱いは、別に手続きが必要になる
:::

IT業界への転職を考えている人は、{{aff:career-it-agent|ユニゾンキャリア（エンジニア専門の転職エージェント）}}で、連絡の方法や頻度の希望を最初に伝えたうえで相談してみる方法もあります。

編集部としては、**LINEでのやり取りは「丁寧さ」より「早さとはっきりさ」を優先する**ことをおすすめします。短くても早い返信のほうが、日程調整や選考がスムーズに進み、自分の負担も減らせるからです。

## 迷ったときの次の一歩

迷ったら、まずは未返信のLINEに「ご連絡ありがとうございます。確認して明日までにお返事します」と一言だけ返してみてください。それだけで、相手も自分も次の動きを決めやすくなります。

転職エージェントやサービスは、自分に合わなければ利用をやめて構いません。無理のないやり取りの形を選びながら、転職活動を進めましょう。

## よくある質問

### 転職エージェントのLINEにはいつまでに返信すればいい？

できればその日のうち、遅くとも翌日までを目安にするとやり取りがスムーズです。すぐに答えられない場合は、「確認して明日までにお返事します」と一言返しておきましょう。

### 転職エージェントへのLINEはどのくらい丁寧に書けばいい？

丁寧語で簡潔に書けば十分です。ビジネスメールのような長い挨拶文は必要ありません。結論を先に書き、日程調整なら候補日を2〜3つ挙げると一度で決まりやすくなります。

### 転職エージェントのLINEで絵文字やスタンプは使っていい？

基本は控えめにするのが無難です。スタンプだけで返すより、短くても文章で返しましょう。日程や応募の意思などの大切な内容は、文章ではっきり伝えることが大切です。

### 転職エージェントのLINEをブロックしたら相手に分かる？

LINEヘルプセンターによると、非表示・ブロック・削除を行っても相手に通知されることはないとされています。ただし、ブロックしてもサービスへの登録や選考中の手続きは終わらないため、先に連絡の停止や辞退を伝えておきましょう。
