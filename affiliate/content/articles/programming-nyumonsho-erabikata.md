プログラミングを始めようと本屋に行ったら、言語ごとに入門書が何十冊も並んでいた。Pythonの棚もJavaScriptの棚も同じように「初心者向け」と書いてあって、どれを選べばいいのか分からないまま帰ってきた。そんな場面を想定して書きました。最初の一冊で失敗したくないと思うのは、とても自然なことです。

プログラミングの入門書は、**「何を作りたいか」で言語を決め、その言語の中で「練習環境の作り方が載っているか」「今のバージョンに合っているか」「最後まで読めそうか」で選ぶ**のが失敗しにくい方法です。言語が変わっても、この基準はほとんど変わりません。

そのうえで、言語ごとに見ておきたいポイントは少しずつ違います。また、多くの言語には**公式のチュートリアルやドキュメント**があり、入門書と組み合わせると、古い情報に振り回されにくくなります。

- 買う前に確認したいチェックリスト
:::

## まずは「何を作りたいか」で言語を決める

入門書選びで迷う理由の一つは、言語が決まっていないことです。言語によって得意な分野が異なるため、**作りたいものから逆算して言語を選ぶ**と、入門書も選びやすくなります。

| 作りたいもの・やりたいこと | 候補になりやすい言語 |
| --- | --- |
| Webサイトの見た目や動き | HTML・CSS・JavaScript |
| データの集計や作業の自動化 | Python |
| Webサービスのサーバー側の処理 | PHP、Java、Pythonなど |
| 業務システムや大規模な開発 | Javaなど |
| データベースの操作 | SQL |

これはあくまで一例で、一つの言語で複数の分野をこなせることもあります。**迷ったときは、仕事で使いたいのか、趣味や作業効率化に使いたいのかを先に決める**と、選択肢をしぼりやすくなります。何から始めるかの全体像は {{link:programming-dokugaku-nanikara|プログラミング独学は何から始める？}} で整理しています。

## どの言語にも共通する入門書の選び方

言語が決まったら、次の基準で入門書を見比べましょう。

:::check 入門書を選ぶときのチェックリスト
- 練習環境（インストールやエディタの準備）の作り方から書かれているか
- 扱っている言語やツールのバージョンが、今と大きくずれていないか
- サンプルコードを自分で打って動かせる構成になっているか
- 章の最後に、自分で考える練習問題があるか
- 数ページ読んでみて、言葉づかいや説明の細かさが自分に合っているか
:::

特に大切なのは、**最後の「自分に合っているか」**です。評判の良い本でも、説明が詳しすぎて進まない人もいれば、簡潔すぎて分からない人もいます。書店やオンライン書店の試し読みで、最初の数ページを読んでみましょう。

:::warning 発行年とバージョンを確認する
プログラミングの世界は更新が早く、数年前の入門書の手順がそのまま使えないこともあります。奥付の発行年や、本で使っている言語・ツールのバージョンを確認し、公式の情報と大きくずれていないかを見ておきましょう。
:::

## 言語別に見たいポイント

### Python

Pythonには、公式ドキュメントの一部として日本語の「Python チュートリアル」が公開されています。入門書を選ぶときは、**Python 3を前提にしているか**、データ分析や自動化など自分の目的に近い例題が載っているかを確認しましょう。目的が決まっていない場合は、文法を基礎から順に説明している本のほうが応用しやすくなります。

Pythonの入門書選びは {{link:python-dokugaku-osusume-hon|Python独学のおすすめ本の選び方}} で詳しく整理しています。

### HTML・CSS・JavaScript

Webの分野では、MDN（Mozillaが運営するWeb技術の情報サイト）に「ウェブ開発の学習」というガイドがあり、日本語でも読めます。入門書を選ぶときは、**HTML・CSS・JavaScriptを別々に学ぶ本か、まとめて学ぶ本か**を確認しましょう。初心者は、HTMLとCSSで画面を作り、そこにJavaScriptで動きを加える流れの本が取り組みやすい傾向があります。

### Java

Javaには、公式の学習サイト「Dev.java」があり、チュートリアルが公開されています（英語）。Javaの入門書は、文法に加えて**オブジェクト指向の考え方をどこまで丁寧に説明しているか**で読みやすさが大きく変わります。図を使ってクラスやオブジェクトを説明している本を選ぶと、つまずきにくくなります。

### PHP

PHPの公式マニュアルには、日本語の「簡易チュートリアル」があります。PHPの入門書は、**Webサーバーやデータベースと組み合わせて動かす手順**が載っているかを確認しましょう。PHPはWebページと組み合わせて使うことが多いため、画面に結果を表示するところまで体験できる本のほうが、学ぶ意味を実感しやすくなります。

### SQL

SQLは、データベースを操作するための言語です。入門書を選ぶときは、**どのデータベース（PostgreSQLやMySQLなど）を使って解説しているか**と、練習用のデータを自分で用意できるかを確認しましょう。SQLの本の選び方は {{link:sql-dokugaku-hon|SQLを独学するなら本はどう選ぶ？}} で整理しています。

## 公式チュートリアルと入門書の組み合わせ方

公式のチュートリアルやドキュメントは、言語を作っている人たちがまとめた正確な情報です。一方で、初心者向けに丁寧に説明されているとは限りません。入門書と組み合わせると、それぞれの弱いところを補い合えます。

:::merit 入門書で学ぶ良さ
- 初心者がつまずきやすいところを、順を追って丁寧に説明している
- 練習環境の作り方から、一冊で通して学べる
- 図や例題が多く、全体像をつかみやすい
:::

:::demerit 入門書だけで進めるときの注意点
- 発行から時間がたつと、手順やバージョンが古くなることがある
- 本に載っていない内容は、別に調べる必要がある
- 自分で調べる習慣がつきにくいことがある
:::

:::steps 入門書と公式情報を組み合わせる進め方
1. **入門書を一冊決める**：言語が決まったら、チェックリストで選んだ一冊をメインにします。
2. **本のとおりに手を動かす**：サンプルコードを自分で打ち、動くことを確かめます。
3. **分からない用語は公式で確かめる**：本の説明で分かりにくいところは、公式のドキュメントで確認します。
4. **本と違う動きをしたら公式を見る**：バージョンの違いで動かないときは、公式の情報を基準にします。
5. **一冊を終えてから次へ進む**：途中で別の本に乗り換えず、まず最後まで読み切ります。
:::

**入門書は「地図」、公式の情報は「最新の道路情報」**と考えると使い分けやすくなります。

## 本と動画講座の使い分け

入門書で進めにくいと感じたら、動画講座を組み合わせる方法もあります。

:::point 動画講座を組み合わせたほうがよい場面
- 開発環境のインストールや設定で手が止まってしまう
- エディタの操作など、画面の動きを見ないと分かりにくい
- 文章を読み続けるのが苦手で、短い単位で区切って進めたい
:::

文章で順を追って学びたい人は、{{aff:learning-books|言語別のプログラミング入門書}}から、チェックリストに合う一冊を選ぶところから始めましょう。

{{aff:learning-books}}

環境づくりや操作の流れを画面で確認したい人は、{{aff:learning-online-course|オンライン動画講座}}で、入門書と同じ言語の講座を一つ選び、つまずいたところだけを補う使い方もあります。

編集部としては、**最初の一冊は「練習環境の作り方が載っていて、試し読みで読みやすいと感じた本」に絞る**ことをおすすめします。評判やランキングより、自分が最後まで読み切れるかどうかのほうが、独学の成果を大きく左右するからです。

## 入門書を読み終えたあとの進み方

入門書を一冊読み終えたら、次は**小さなものを自分で作ってみる**段階です。本の例題を少し変えてみる、身の回りの作業を自動化してみるなど、小さな目標から始めましょう。

作りたいものが決まると、必要な知識もはっきりしてきます。そのときに、より専門的な本や公式のドキュメントに進むと、目的を持って学べます。**入門書を何冊も読むより、一冊を終えて手を動かす時間を増やす**ほうが、力はつきやすくなります。

## 迷ったときの次の一歩

迷ったら、まずは作りたいものを一つだけ書き出し、そこから言語を一つ決めてみてください。言語が決まったら、書店やオンライン書店で入門書を2〜3冊試し読みし、いちばん読みやすいと感じた本を選びましょう。

本や講座は、自分に合わなければ見送って構いません。公式の無料チュートリアルから始めることもできるので、自分のペースで続けられる方法を選んでください。

## よくある質問

### プログラミングの入門書はどう選べばいい？

まず作りたいものから言語を決め、その言語の中で、練習環境の作り方が載っているか、バージョンが古すぎないか、試し読みで読みやすいかを確認して選ぶのがおすすめです。

### プログラミングの入門書は何冊必要？

最初は一冊で十分です。途中で別の本に乗り換えず、一冊を最後まで読み切ってから、作りたいものに合わせて次の本や公式のドキュメントに進みましょう。

### 言語が決まっていないときはどの入門書を選ぶ？

まずは、Webサイトを作りたいのか、作業を自動化したいのかなど、やりたいことを一つ決めましょう。やりたいことが決まると、候補の言語がしぼられ、入門書も選びやすくなります。

### 古い入門書でも勉強できる？

基本的な文法は学べることもありますが、インストールの手順やツールのバージョンが今と違う場合があります。発行年と使っているバージョンを確認し、動かないときは公式のドキュメントを基準にしましょう。

### 公式のチュートリアルだけで勉強できる？

Python、PHPなどには日本語で読める公式のチュートリアルがあります。ただし、初心者向けに丁寧に説明されているとは限らないため、分かりにくいところは入門書や動画講座で補うと進めやすくなります。
