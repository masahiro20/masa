# masa

## affiliate/

人手なしで回るアフィリエイトサイトの自動運用システムです。設定方法・仕組み・収益の見通しは [affiliate/README.md](affiliate/README.md) を参照してください。

## gaihi/

設計図書から外皮面積を自動で拾い、UA・ηAC・ηAH と計算書を一発で出力する外皮計算ツールです。使い方は [gaihi/README.md](gaihi/README.md) を参照してください。

## meet/

COMPASS のカレンダーから使うオンライン通話（Google カレンダーと Meet のような関係）です。予定ごとに通話リンクを発行し、リンクを開くだけで参加できます。使い方と COMPASS とのつなぎ方は [meet/README.md](meet/README.md) を参照してください。
